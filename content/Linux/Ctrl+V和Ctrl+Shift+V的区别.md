# 通俗版解释

Linux 的终端（kitty、alacritty 这类）快捷键和浏览器、记事本不一样，这点很容易搞混。

## Ctrl+V

 浏览器/编辑器：粘贴文字，大家都熟悉 **终端里面不能用来粘贴！** 在终端按 Ctrl+V，不会把复制的文字贴进来，只会打出 `^V`。 这个功能本来是用来输入 Tab、Esc 这种特殊按键的，不是粘贴。

## Ctrl+Shift+V

 **终端里的粘贴键！** 想要把复制的内容贴进终端，就按这个。 配套：终端里复制文字，要用 `Ctrl+Shift+C`

### 简单对照表

| 快捷键          | 终端里干什么         | 浏览器里干什么    |
| ------------ | -------------- | ---------- |
| Ctrl+V       | 打出 ^V，**不能粘贴** | 正常粘贴       |
| Ctrl+Shift+V | 粘贴剪贴板内容        | 粘贴不带格式的纯文本 |
| Ctrl+C       | 停止正在跑的程序       | 复制文字       |
| Ctrl+Shift+C | 复制选中文字         | 没作用        |

### 举个例子

1. 浏览器复制命令：`sudo pacman -S swww`
2. 切到终端
3. 按 Ctrl+V → 出来 `^V`，粘贴失败 
4. 按 Ctrl+Shift+V → 命令粘贴成功 

## Linux 有两套“复制板”，简单理解

1. **剪贴板（日常用）** 按 Ctrl+C 复制的内容。终端粘贴用 `Ctrl+Shift+V`。
2. **鼠标选区（很方便）** 你用鼠标拖选一段文字，**自动就复制好了，不用按任何复制键**。 想粘贴的时候，直接点一下鼠标滚轮（中键），内容就出来了。
