# Linux 给"免安装/便携"应用创建桌面图标——通用教程

> 适用:GNOME 桌面(Debian/Ubuntu 等)。
> 免安装 = 便携包(官方压缩包直接解压就能跑,不需要 `apt/dpkg` 装),常见形态:
> - **tar.gz 便携版**(解压后里面通常有可执行文件,如 Zotero、VS Code、Obsidian)
> - **AppImage**(单个文件,`chmod +x` 就能跑)

---

## 1. 原理:.desktop 文件是什么

- GNOME 的"应用图标"本质上是一个 **`.desktop` 文本文件**,里面写了"名字、执行哪个命令、用哪个图标"。
- GNOME 会扫描下面这些目录,把每个 `Type=Application` 的文件显示在应用网格里:

| 目录 | 说明 |
|---|---|
| `~/.local/share/applications/` | **用户级(推荐、无需 root)** |
| `/usr/share/applications/` | 系统级(root,一般不碰) |
| `/usr/local/share/applications/` | 系统级 |

- 放到用户目录之后,应用列表立刻会出现这个图标(个别情况需注销重登刷新缓存)。

---

## 2. 通用流程四步

### 第 1 步:把程序放到固定目录
便携程序别放在 `~/Downloads`(容易被清理),挪到固定位置,例如:
```bash
mkdir -p ~/Applications
mv ~/Downloads/某程序-x.x.x_linux-x86_64 ~/Applications/
```
> 先记住它的绝对路径,后面 `Exec=` 要用。

### 第 2 步:写 `.desktop` 文件
新建 `~/.local/share/applications/程序名.desktop`:

```ini
[Desktop Entry]
Name=程序名
Comment=一句话说明
Exec=/绝对/路径/到/可执行文件 %U
Icon=图标名或图标文件绝对路径
Type=Application
Terminal=false
Categories=Utility;
StartupWMClass=程序窗口类名
```

### 第 3 步:放图标(推荐装进主题)
```bash
mkdir -p ~/.local/share/icons/hicolor/128x128/apps
cp /程序目录/icons/icon128.png ~/.local/share/icons/hicolor/128x128/apps/程序名.png
```
并把 `.desktop` 里写成 `Icon=程序名`(让系统按名字去图标主题里找)。

### 第 4 步:验证 + 刷新 + 重登
```bash
desktop-file-validate ~/.local/share/applications/程序名.desktop   # 语法检查,没输出=通过
update-desktop-database ~/.local/share/applications/               # 刷新索引
```
注销重新登录(Wayland 下系统代理/图标缓存更新必须重登)。

## 3. `.desktop` 关键字段详解

| 字段 | 作用 | 注意事项 |
|---|---|---|
| `Name` | 显示的名字 | 可加 `Name[zh_CN]` 中文覆盖 |
| `Exec` | **核心**,启动命令 | 用**绝对路径**;带空格路径要加引号;带 `%U`(打开文件参数)/`%F` |
| `Comment` | 鼠标悬停显示的一句话说明 | 可选 |
| `Icon` | 图标 | 写**图标主题里的名字**(如 `zotero`)最稳,或 PNG 绝对路径 |
| `Type` | 固定写 `Application` | 写错就不显示 |
| `Terminal` | 是否在终端里启动 | GUI 程序写 `false` |
| `Categories` | 应用分类 | 常见:`Utility;Development;Office;Network;` |
| `StartupWMClass` | 让 GNOME 把运行中的窗口"归位"到这个图标(停靠栏不出现第二个图标) | 值的来源见下文 |
| `MimeType` | 支持的扩展名列表 | 想让"双击 .md 就打开它"就写;需要再配默认关联 |

### 3.1 怎么确定 `Exec=` 写哪个可执行文件
先 `ls` 看解压目录里有哪些可执行文件:
```bash
ls -l ~/Applications/某程序/
```
- 有 **`bin`** 结尾的文件通常是主程序;
- 很多便携包带一个 **`xxx` 启动脚本**(设置环境变量后再去调真正的二进制,如 `zotero` → `zotero-bin`),优先用**启动脚本**;
- 不确定就进目录 `./xxx` 直接跑一下,能启动的就是它。

### 3.2 怎么确定 `StartupWMClass`
程序运行起来后执行:
```bash
xprop WM_CLASS        # X11 下,然后点窗口
```
Wayland 下看不到,直接去程序目录里搜一下程序名,或者留空(不影响图标显示,只影响窗口归位)。

## 4. 图标的规范做法(两种)

- **方式 A(简单)**:`Icon=` 直接写 PNG 绝对路径。
  - 缺点:偶尔因 GNOME 缓存显示成空白图标。
- **方式 B(推荐)**:
  ```bash
  mkdir -p ~/.local/share/icons/hicolor/{16x16,32x32,64x64,128x128,256x256}/apps
  cp 程序目录/icons/icon128.png ~/.local/share/icons/hicolor/128x128/apps/程序名.png
  ```
  `.desktop` 里写 `Icon=程序名`。多个尺寸都有的话按尺寸放全更清晰。
  > 若目录里没有现成图标,可以自己做个:用任意图片工具导出 128×128 的 PNG,或直接从系统里找个近似图标拷贝。

## 5. 避坑清单(最容易踩的)

1. **⚠️ 便携包自带的 `.desktop` 不能直接复制用**
   很多官方包里的 `.desktop` 用 `%k`/相对路径小技巧,只在"它待在程序目录里、被双击"时有效,拷到 `applications/` 后 `Exec` 就找不到文件了。**要自己重写绝对路径。**
2. **⚠️ 绝对路径少写一层目录**
   解压目录通常有嵌套(`App-x.x.x/bin/app`),路径写错会启动报 "No such file or directory"。写完后先用 `ls` 确认目录真实存在。
3. **⚠️ 路径含空格**
   `Exec=/path/my app/run` 要写成 `Exec="/path/my app/run"`。
4. **⚠️ 图标空白**
   用绝对路径 PNG 显示空白时,改用"装进图标主题 + `Icon=名字` + 注销重登"。
5. **⚠️ 改了不生效**
   - 先 `desktop-file-validate` 查语法;
   - 再 `update-desktop-database`;
   - 最后注销重登。
6. **⚠️ 版本更新路径变了**
   便携程序更新后解压目录名字可能变(如版本号),要同步改 `.desktop` 里的路径。

## 6. AppImage 特殊说明

AppImage 是单个文件,做法更简单:
```bash
chmod +x ~/Applications/MyApp.AppImage
```
`.desktop` 里:
```ini
Exec=/home/用户名/Applications/MyApp.AppImage
Icon=/home/用户名/Applications/MyApp.AppImage 图标(常需从包内提取或替换)
```
> AppImage 也可用 `appimagetool`/`AppImageLauncher` 自动生成桌面项。

## 7. 完整示例(以 Zotero 便携版为例)

```bash
# 1. 固定位置
mkdir -p ~/Applications
mv ~/Downloads/Zotero-10.0.2_linux-x86_64 ~/Applications/

# 2. 写 desktop(注意目录有两层嵌套)
mkdir -p ~/.local/share/applications
tee ~/.local/share/applications/zotero.desktop >/dev/null <<'EOF'
[Desktop Entry]
Name=Zotero
Comment=参考文献管理
Exec=/home/debian/Applications/Zotero-10.0.2_linux-x86_64/Zotero_linux-x86_64/zotero %U
Icon=zotero
Type=Application
Terminal=false
Categories=Office;Science;
StartupWMClass=zotero
EOF

# 3. 装图标
mkdir -p ~/.local/share/icons/hicolor/128x128/apps
cp /home/debian/Applications/Zotero-10.0.2_linux-x86_64/Zotero_linux-x86_64/icons/icon128.png \
   ~/.local/share/icons/hicolor/128x128/apps/zotero.png

# 4. 验证刷新
desktop-file-validate ~/.local/share/applications/zotero.desktop
update-desktop-database ~/.local/share/applications/
```

以后遇到任何新的便携程序,套用上面的四步即可。
