# 文本和字体，把字排得好看

一篇文章好不好读，八成取决于这一篇里的几个属性。

## 字体

```css
body {
  font-family: system-ui, -apple-system, "Microsoft YaHei", sans-serif;
}
```

`font-family` 后面可以写一串，浏览器从左往右找，用第一个装了的。

这叫"字体栈"。写法上有三条规矩：

- 英文单词和中文名字要用引号包起来：`"Microsoft YaHei"`
- 最后一个一定是通用族名：`sans-serif`（无衬线）、`serif`（衬线）、`monospace`（等宽）——兜底用
- 中文字体放最后，因为它体积大，放在前面会拖慢加载

常用的几个：

| 字体 | 特点 |
| --- | --- |
| `system-ui` | 用系统默认字体，最快也最协调 |
| `"Microsoft YaHei"` | Windows 的微软雅黑 |
| `"PingFang SC"` | macOS / iOS 的苹方 |
| `"Noto Sans SC"` | 安卓和 Linux 上常见 |
| `monospace` | 等宽字体，代码用 |

只写 `system-ui` 就够了，它在你当前系统上会挑出最合适的中文字体。

## 字号

```css
html { font-size: 16px; }       /* 基准 */
body { font-size: 1rem; }
h1 { font-size: 2rem; }          /* 32px */
small { font-size: 0.875rem; }   /* 14px */
```

正文最小别低于 16px。手机上小于 16px 的字，用户会不自觉地把页面放大。

## 字重

```css
font-weight: 400;   /* 正常 */
font-weight: 700;   /* 加粗 */
font-weight: 300;   /* 细体，需要字体本身有这个字重 */
```

也可以用 `normal` 和 `bold` 这两个词。

注意：如果字体文件里没有 300 这个字重，浏览器会拿最近的代替，或者用算法假装变细，效果很差。

## 行高

```css
body { line-height: 1.6; }
```

行高是"一行文字占的高度"，**不带单位**时表示字号的倍数。

正文 1.5–1.8 之间最舒服。中文比英文需要更大的行高，1.7 左右是常见选择。

行高太小时，两行字会挤在一起；太大时，眼睛扫下一行会找不到位置。

为什么推荐不带单位：`line-height: 1.6` 会按**每个元素自己的字号**重新计算；写成 `160%` 或 `26px`，子元素会继承一个算好的固定值，字号变了行高不跟着变。

## 对齐和缩进

```css
text-align: left;      /* 左对齐，正文默认 */
text-align: center;    /* 居中，标题和按钮用 */
text-align: right;     /* 右对齐，数字列用 */
text-align: justify;   /* 两端对齐 */

text-indent: 2em;      /* 首行缩进两个字 */
```

中文正文习惯首行缩进两字，`text-indent: 2em` 正好是两个汉字宽（`em` 相对当前字号）。

`justify` 在中文里效果不错，在英文里会出现难看的"河流"（词距被拉得忽大忽小），慎用。

## 字间距和字母间距

```css
letter-spacing: 0.5px;   /* 字与字之间 */
word-spacing: 2px;       /* 单词之间 */
```

中文小标题加一点 `letter-spacing` 会显得透气，正文不要加，读起来会累。

## 装饰

```css
a { text-decoration: none; }             /* 去掉链接下划线 */
u { text-decoration: underline; }
.del { text-decoration: line-through; }
```

去掉链接下划线之后，记得用别的办法（颜色、加粗、hover 效果）让链接还能被认出来，否则用户根本不知道哪里能点。

## 换行控制

```css
.title {
  white-space: nowrap;      /* 不换行，超出的部分被切掉 */
  overflow: hidden;
  text-overflow: ellipsis;  /* 超出的部分显示成 … */
}
```

这三行合起来就是网页上最常见的"文字太长自动省略号"。

还有一个中文排版里常用的：

```css
p {
  word-break: break-all;   /* 长串英文/网址强制换行，防止撑破容器 */
}
```

如果只想让长单词在实在放不下时才断开，用 `overflow-wrap: break-word`，更温和。

## 完整的一组正文样式

```css
body {
  font-family: system-ui, sans-serif;
  font-size: 1rem;
  line-height: 1.75;
  color: #2b2b2b;
  max-width: 42rem;      /* 一行 40 个字左右最好读 */
  margin: 0 auto;        /* 居中 */
  padding: 2rem 1rem;
}

h1, h2, h3 {
  line-height: 1.3;      /* 标题的行高要比正文小 */
  margin-top: 2em;
  margin-bottom: 0.6em;
}
```

最后那条 `max-width: 42rem` 是全文最重要的一个数字。

一行文字太长，眼睛从行尾扫回行首会串行。限制在 40 个汉字左右（约 42rem），可读性立刻上一个台阶。
