# 列表、表格和链接的样式

这三个东西浏览器给了很重的默认样式，实际项目里几乎每一个都要重写。

## 列表

```css
ul { list-style: none; }            /* 去掉小圆点 */
ol { list-style: decimal; }         /* 数字 */
ul.square { list-style: square; }   /* 方块 */
ul.circle { list-style: circle; }   /* 空心圆 */
```

`list-style` 是简写，拆开是：

```css
.list {
  list-style-type: none;      /* 符号长什么样 */
  list-style-position: inside; /* 符号在内容里还是外面 */
  list-style-image: url("dot.png"); /* 用小图片当符号 */
}
```

导航栏要去圆点还要去掉左边距——浏览器给 `<ul>` 默认加了约 40px 的 `padding-left`，圆点虽然看不到了，缩进还在：

```css
nav ul {
  list-style: none;
  margin: 0;
  padding: 0;
}
```

这三行是导航栏样式里最常见的开头。

## 用伪元素自定义符号

`list-style-type` 只能选那几个内置符号。想要五角星、对勾、箭头这种，用 `::before`：

```css
ul.custom {
  list-style: none;
  padding-left: 0;
}
ul.custom li {
  position: relative;
  padding-left: 1.5em;
}
ul.custom li::before {
  content: "▸";
  position: absolute;
  left: 0;
  color: #84a59d;
}
```

↓ 渲染出来是这样：

<style>
.wbd-list-demo { list-style: none; padding-left: 0; margin: 0; }
.wbd-list-demo li { position: relative; padding-left: 1.5em; line-height: 2; }
.wbd-list-demo li::before { content: "▸"; position: absolute; left: 0; color: #2f8f6f; font-weight: bold; }
</style>

<ul class="wbd-list-demo">
  <li>用伪元素做的自定义符号</li>
  <li>可以自由换颜色和大小</li>
  <li>也不影响原来的缩进</li>
</ul>

## 表格

表格默认长得很难看：每个单元格一圈边框、有间距、还没法控制。一行样式就能救回来：

```css
table {
  border-collapse: collapse;   /* 相邻边框合并成一条 */
  width: 100%;
}
th, td {
  padding: 8px 12px;
  border: 1px solid #ddd;
  text-align: left;
}
th {
  background: #f4f4f4;
}
```

`border-collapse: collapse` 是表格样式的第一步。不加它，每个单元格的边框各画各的，格子之间还有缝。

## 表格斑马纹

隔行变色，长表格好读很多：

```css
tbody tr:nth-child(odd) {
  background: #f8f8f8;
}
```

↓ 效果：

.wbd-table-demo { border-collapse: collapse; width: 100%; }

.wbd-table-demo th { background: #eef2f4; }
.wbd-table-demo tbody tr:nth-child(odd) { background: #f8f8f8; }
.wbd-table-demo tbody tr:hover { background: #e6eef3; }

上面那张表里还加了一条悬停变色，鼠标划过去能看见：

```css
tbody tr:hover { background: #e6eef3; }
```

## 表格的其他样式

```css
table { table-layout: fixed; }   /* 列宽按第一行分配，渲染更快 */
td { vertical-align: middle; }   /* 单元格内垂直居中 */
caption { caption-side: bottom; } /* 表标题放底下 */
```

做移动端表格时，`overflow-x: auto` 套一层外层容器，让窄屏可以横向滚动：

```css
.table-wrap { overflow-x: auto; }
```

## 链接的四个状态

链接有四种状态，**顺序不能乱**：

```css
a:link    { color: #284b63; }   /* 没访问过 */
a:visited { color: #6b4c9a; }   /* 访问过 */
a:hover   { color: #c0392b; }   /* 鼠标悬停 */
a:active  { color: #ff8c00; }   /* 正被按下 */
```

顺序记法：**L**o**V**e **HA**te（爱恨）。写反了，后面的会盖住前面的，效果就不对了。

原因是这四者的优先级一样，谁写在后面谁生效。`:hover` 写在 `:link` 前面的话，悬停时颜色根本不会变。

## 去掉下划线

```css
a { text-decoration: none; }
```

去掉之后必须用别的办法让人看出这是链接，否则用户找不到入口。常见组合：

```css
a {
  color: #284b63;
  text-decoration: none;
  border-bottom: 1px solid rgba(40,75,99,.3);
  transition: border-color .2s;
}
a:hover {
  border-bottom-color: currentColor;  /* 悬停时下划线变实 */
}
```

这叫"默认浅下划线、悬停变实"，既清爽又能看出可点。

## 鼠标指针

```css
button, a, .clickable { cursor: pointer; }
```

`<div>` 加 `onclick` 当按钮时不会变成小手，得手动加。这也是"该用 `<button>` 就用 `<button>`"的一个理由。

其他常用值：`default`（箭头）、`text`（文本光标）、`not-allowed`（禁止）、`grab`（可拖动）。
