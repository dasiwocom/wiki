# 颜色和单位，写颜色和尺寸的几种方式

CSS 里每个值都要写清楚"是什么颜色""多长"。

## 颜色的四种写法

**① 颜色名**

```css
color: red;
color: tomato;
color: steelblue;
```

CSS 里有一百多个颜色名，好记，但选择少，做设计时不够用。

**② 十六进制**

```css
color: #ff0000;   /* 红 */
color: #f00;      /* 同上的简写：每两位相同就能缩成一位 */
color: #333333;
color: #333;
```

`#` 后面六位，两位一组分别是红、绿、蓝，取值 `00` 到 `ff`。

`#f00`、`#ffffff` 这种每两位重复的可以缩写，`#f0a1b2` 就不行。

**③ rgb / rgba**

```css
color: rgb(255, 0, 0);
color: rgba(255, 0, 0, 0.5);   /* 半透明 */
```

三个数字是红绿蓝，取值 0–255。`rgba` 的第四个值是透明度，0 是全透明，1 是不透明。

**④ hsl / hsla**

```css
color: hsl(0, 100%, 50%);        /* 色相, 饱和度, 亮度 */
color: hsla(210, 40%, 30%, 0.8);
```

色相是 0–360 的色环角度（0 红、120 绿、240 蓝），调颜色比 rgb 直观。

调色的时候用 `hsl`，写死在代码里用 `#` 或 `rgb`，是常见习惯。

## 全透明

```css
background: transparent;   /* 完全透明 */
```

## 顺便记一下：颜色对比度

浅灰字配白底，看着"设计师风"，实际看不清。

正文文字和背景的对比度至少要满足无障碍标准（正文 4.5:1，大标题 3:1）。

在浏览器 F12 里选中文字，色板里会显示对比度数值，直接告诉你合不合格，比肉眼判断靠谱。

## 长度单位

| 单位 | 相对谁 | 用在哪 |
| --- | --- | --- |
| `px` | 绝对 | 边框、小图标、固定尺寸 |
| `%` | 父元素的同种属性 | 宽度、高度 |
| `em` | **当前元素的字号** | 内边距、行高 |
| `rem` | **根元素（html）的字号** | 字号、间距 |
| `vw` / `vh` | 视口宽 / 高的 1% | 全屏区块 |
| `ch` | 数字 0 的宽度 | 限制行宽 |

## px 和 rem 怎么选

`px` 是写死的。用户把浏览器字号调大，`px` 的字不会跟着变大。

`rem` 相对根元素。用户调大字号，用 `rem` 的地方全都会跟着变大。

所以：

- **字号、间距用 `rem`**（可访问性好）
- **边框、1px 的线用 `px`**（它们本来就该是固定的）

浏览器默认根字号是 16px，所以 `1rem` = 16px，`1.5rem` = 24px。

## em 的坑

`em` 是相对**当前元素的字号**算的，而元素的字号本身又可能是从父元素继承的，于是会层层相乘：

```css
.parent { font-size: 20px; }
.child  { font-size: 1.5em; }   /* 30px */
.grandchild { font-size: 1.5em; } /* 45px，不是 30px */
```

写嵌套组件时很容易翻车，所以字号优先用 `rem`。

## 百分比相对谁

`%` 是"相对父元素的同一个属性"，但每种属性的参照物不一样：

- `width: 50%` → 父元素宽度的一半
- `height: 50%` → 父元素高度的一半（**父元素没定高时算不出来**）
- `padding: 10%` → 父元素**宽度**的 10%（上下也是按宽度算，这点反直觉）
- `line-height: 150%` → 自身字号的 1.5 倍

## vw 和 vh

```css
.hero { height: 100vh; }   /* 占满一屏高度 */
.full { width: 100vw; }    /* 横向占满，注意可能有滚动条宽度问题 */
```

`100vh` 做首屏横幅很方便。但手机上地址栏收起/展开会改变视口高度，`100vh` 可能被挡住一截，新的 `100dvh` 单位解决了这个问题（老浏览器不支持）。

## 有些属性不能带单位

这几类写了单位反而不生效：

```css
line-height: 1.6;      /* 倍数，不带单位 */
opacity: 0.5;          /* 0 到 1 */
z-index: 10;           /* 整数 */
font-weight: 700;      /* 数字 */
flex: 1;               /* 倍数 */
grid-template-columns: 1fr 1fr;   /* fr 已经是单位 */
```

`line-height` 不带单位时，是按**自身字号**的倍数算的，而且会逐层重新计算——比带 `px` 和 `%` 都稳，所以推荐不带单位。
