# 选择器，怎么精确指到要改的那个元素

写 CSS 一半的时间花在"怎么把样式加到对的那个元素上"。

## 最基础的四种

```css
p { color: #333; }          /* 标签选择器：所有 p */
.card { border: 1px solid; } /* 类选择器：class="card" 的元素 */
#header { height: 60px; }    /* id 选择器：id="header" 的那个元素 */
* { margin: 0; }             /* 通配：所有元素 */
```

对应的 HTML：

```html
<p class="card" id="header">内容</p>
```

- **类**用点号 `.`，一个元素可以有多个类（`class="card big"`），同一个类可以用在很多元素上
- **id** 用井号 `#`，一个页面里只能出现一次

所以样式基本都挂在类上，id 留给"跳转到某一节"和 JS 用。

## 组合选择器

| 写法 | 名字 | 选中谁 |
| --- | --- | --- |
| `div p` | 后代 | div 里面的所有 p（不管隔了几层） |
| `div > p` | 子代 | 只有 div 的亲儿子 p |
| `h1 + p` | 相邻兄弟 | 紧跟在 h1 后面的那个 p |
| `h1 ~ p` | 通用兄弟 | h1 后面的所有同级 p |
| `h1, h2` | 分组 | h1 和 h2，各写一条太啰嗦时用 |

分组选择器最实用：想给所有标题统一加字体，写 `h1, h2, h3, h4, h5, h6 { font-family: serif; }` 比写六条省事。

## 属性选择器

按属性来挑，专门对付表单：

```css
input[type="text"] { border: 1px solid #ccc; }
a[href^="https"] { color: green; }   /* 以 https 开头 */
a[href$=".pdf"] { color: red; }      /* 以 .pdf 结尾 */
a[target="_blank"] { font-weight: bold; }
```

`^=` 是"开头是"，`$=` 是"结尾是"，`*=` 是"包含"，`~=` 是"其中一个词是"。

## 伪类：按状态挑

元素在不同状态下样式不一样，用伪类：

```css
a:hover { color: #c0392b; }        /* 鼠标悬停 */
input:focus { outline: 2px solid #284b63; }  /* 获得焦点 */
li:first-child { font-weight: bold; }        /* 第一个 */
li:last-child { border-bottom: none; }       /* 最后一个 */
li:nth-child(odd) { background: #f6f6f6; }   /* 奇数行 */
li:nth-child(2n) { background: #fafafa; }    /* 偶数行 */
input:disabled { opacity: 0.5; }             /* 被禁用 */
.card:not(.featured) { opacity: 0.8; }       /* 排除某一类 */
```

`:nth-child(2n+1)` 里的 `2n+1` 就是一个公式，`n` 从 0 开始代入，得到 1、3、5……做斑马纹表格最常用。

## 伪元素：往元素里塞东西

`::before` 和 `::after` 会在元素内容的前后各加一个"虚拟元素"，用来做装饰：

```css
.price::before { content: "¥"; }
.required::after { content: "*"; color: red; }
.clearfix::after {
  content: "";
  display: block;
  clear: both;
}
```

伪元素必须写 `content`，哪怕它是空的。没有 `content` 就什么都不显示。

## 真实的悬停效果

把鼠标放到下面两个方块上试试：

<style>
.wbx-hover-demo {
  padding: 12px 20px;
  border: 1px solid #b8b8b8;
  border-radius: 6px;
  display: inline-block;
  margin-right: 12px;
  transition: all 0.2s;
}
.wbx-hover-demo:hover {
  background: #284b63;
  color: #fff;
  border-color: #284b63;
  transform: translateY(-2px);
}
</style>

<p><span class="wbx-hover-demo">鼠标放上来</span><span class="wbx-hover-demo">这个也会变</span></p>

上面这段效果的全部代码：

```css
.demo {
  padding: 12px 20px;
  border: 1px solid #b8b8b8;
  border-radius: 6px;
  transition: all 0.2s;
}
.demo:hover {
  background: #284b63;
  color: #fff;
  transform: translateY(-2px);
}
```

`transition` 让变化有个过渡，不加的话颜色是"啪"一下变的。

## 优先级：两条规则打架时谁赢

先看一个例子：

```css
p { color: blue; }
.text { color: red; }
```

```html
<p class="text">什么颜色？</p>
```

答案是**红色**。因为类选择器比标签选择器"更具体"。

优先级大致按这个顺序（从高到低）：

| 级别 | 写法 | 权重（粗略） |
| --- | --- | --- |
| 1 | 标签上的 `style="…"` | 最高 |
| 2 | id 选择器 `#a` | 100 |
| 3 | 类、属性、伪类 `.a` `[type]` `:hover` | 10 |
| 4 | 标签、伪元素 `p` `::before` | 1 |
| 5 | 通配 `*` | 0 |

规则很简单：**从左往右比，谁的某一级高谁赢，平了就比下一级**。

`.nav a` 是 10+1=11，`a.link` 也是 11，打平。

## 打平了怎么办

同权重时，**后写的赢**。这就是"层叠"这个词的由来。

```css
p { color: blue; }
p { color: red; }   /* 红色生效 */
```

所以样式表的顺序有意义，引入的顺序颠倒一下，结果可能就变了。

## 别把优先级用成玄学

真正写代码时，避免打架比打赢更重要：

- 尽量只用类选择器，别写 `#header .nav ul li a` 这种一长串
- 别用 `!important`，它是"我必须赢"的强制手段，用多了以后只能靠更多的 `!important` 去覆盖
- 选择器写到"刚好够用"就行

一组完整的优先级规则见 [MDN 的层叠与继承](https://developer.mozilla.org/zh-CN/docs/Web/CSS/CSS_cascade/Cascade)，所有选择器的清单见 [菜鸟教程的 CSS 选择器参考手册](https://www.runoob.com/cssref/css-selectors.html)。
