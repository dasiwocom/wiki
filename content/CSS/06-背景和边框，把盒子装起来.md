# 背景和边框，把盒子装起来

盒子的"装修"就在这两个属性上。做卡片、按钮、横幅，全靠它们。

## 背景色

```css
body { background-color: #faf8f8; }
.card { background-color: #fff; }
```

最基础的一条，也是最容易忘记的一条。

## 背景图

```css
.hero {
  background-image: url("cover.jpg");
  background-repeat: no-repeat;         /* 不重复 */
  background-position: center;          /* 居中 */
  background-size: cover;               /* 铺满，可能裁掉边缘 */
}
```

`background-size` 的两个常用值，特别容易搞混：

| 值 | 效果 |
| --- | --- |
| `cover` | 铺满整个盒子，**保持比例**，多出来的部分被裁掉 |
| `contain` | 图片**完整**显示，保持比例，盒子可能留白 |

做整屏横幅用 `cover`，做 logo 用 `contain`。

`background-position` 可以用关键词（`center` `top left`）、百分比或长度：

```css
background-position: center center;   /* 正中 */
background-position: 50% 30%;         /* 水平居中，垂直靠上 30% */
background-position: right 16px top 8px;  /* 右上方，各偏移 16px / 8px */
```

`background-position` 默认是 `0 0`（左上角），`background-repeat` 默认是 `repeat`（平铺）——**这两个默认值很反直觉**，是小图铺满整屏的常见原因。

## 简写

```css
/* 顺序：颜色 图片 重复 位置/大小 */
background: #333 url("cover.jpg") no-repeat center/cover;
```

注意 `position/size` 中间那个斜杠，是简写里唯一有点怪的地方。

## 渐变

渐变其实就是背景图，不用图片文件：

```css
.a { background: linear-gradient(to right, #284b63, #84a59d); }
.b { background: linear-gradient(45deg, #ff7e5f, #feb47b); }
.c { background: radial-gradient(circle, #fff, #d9e2e8); }
```

↓ 渲染出来是这样：

<div style="height:56px;border-radius:6px;margin-bottom:8px;background:linear-gradient(90deg,#284b63,#84a59d)"></div>
<div style="height:56px;border-radius:6px;margin-bottom:8px;background:linear-gradient(45deg,#ff7e5f,#feb47b)"></div>
<div style="height:56px;border-radius:6px;background:radial-gradient(circle,#ffffff,#d9e2e8)"></div>

`linear-gradient(方向, 起色, 止色)`，中间可以插多个色标：

```css
background: linear-gradient(90deg, #f00 0%, #ff0 50%, #0f0 100%);
```

不加方向就默认从上到下。

## 多重背景

```css
background:
  linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5)),  /* 上面一层：半透明遮罩 */
  url("cover.jpg") center/cover;                       /* 下面一层：图 */
```

写法是先写的在上面。上面这个组合常用来"给图加一层暗色遮罩，让白字看得清"。

## 边框

```css
border: 1px solid #ddd;
```

三个值：宽度、样式、颜色。

样式不能省，**只写 `border: 1px #ddd` 是不生效的**——这是新手最常踩的一个坑。

常用样式：`solid`（实线）、`dashed`（虚线）、`dotted`（点线）、`double`（双线）、`none`（无）。

单边：

```css
border-left: 4px solid #84a59d;
border-bottom: none;
```

## 圆角

```css
.card { border-radius: 8px; }
.pill { border-radius: 999px; }        /* 胶囊形 */
.circle { border-radius: 50%; }        /* 正圆，元素得是正方形 */
```

四个角可以分别设：

```css
border-radius: 8px 8px 0 0;   /* 左上 右上 右下 左下 */
```

## 阴影

```css
.card {
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}
```

`box-shadow` 最多五个值：

```text
box-shadow: 水平偏移  垂直偏移  模糊半径  扩散半径  颜色
               0        2px      8px       0      rgba(0,0,0,.1)
```

- 偏移为正，阴影往右下走
- 模糊越大越柔和
- 想要"浮起来"的效果，就用小偏移大模糊

多层阴影能做出更自然的效果（一层当实物投影，一层当扩散）：

```css
box-shadow: 0 1px 2px rgba(0,0,0,.08), 0 8px 24px rgba(0,0,0,.06);
```

↓ 两张卡片对比：

<div style="padding:16px;border-radius:8px;background:#fff;border:1px solid #e5e5e5;margin-bottom:12px">只有边框，平平的</div>
<div style="padding:16px;border-radius:8px;background:#fff;box-shadow:0 1px 2px rgba(0,0,0,.08),0 8px 24px rgba(0,0,0,.12)">加了阴影，浮起来了</div>

文字阴影是另一个属性：

```css
text-shadow: 1px 1px 2px rgba(0,0,0,.3);
```

## 轮廓 outline

```css
input:focus { outline: 2px solid #284b63; }
```

轮廓和边框长得像，但有三点不同：

- 不占空间，不影响布局
- 不能只设一边，要么全有要么全无
- 不能设圆角（新版浏览器可以了）

所以它最适合做聚焦提示和调试（`* { outline: 1px solid red; }`）。

删掉默认聚焦框要谨慎：

```css
input:focus { outline: none; }   /* 别忘了自己补一个可见的替代样式 */
```

键盘用户全靠这个框知道自己现在在哪，删了不给替代方案，等于把他们挡在门外。
