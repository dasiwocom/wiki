# 盒子模型，一个元素到底占多大地方

页面上每个元素都是一个矩形盒子。搞不清这个盒子怎么算大小，布局就永远调不对。

## 一个盒子有四层

从里到外：

```text
┌─────────────────────────────────────┐  ← margin（外边距，透明）
│  ┌───────────────────────────────┐  │
│  │        border（边框）          │  │
│  │  ┌─────────────────────────┐  │  │
│  │  │   padding（内边距）      │  │  │
│  │  │  ┌───────────────────┐  │  │  │
│  │  │  │  content（内容）   │  │  │  │
│  │  │  └───────────────────┘  │  │  │
│  │  └─────────────────────────┘  │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

看下面这个盒子，四层都调成了不同厚度：

<div style="background:#d9e2e8;padding:16px;border:4px solid #284b63;margin:8px 0">
  <div style="background:#f4f7f6;padding:20px;border:2px dashed #84a59d">内容</div>
</div>

外面那圈淡蓝是 margin，深色实线是 border，浅色区域是 padding，中间内容。

## 四层各管什么

| 层 | 属性 | 说明 |
| --- | --- | --- |
| 内容 | `width` `height` | 文字、图片实际占的地方 |
| 内边距 | `padding` | 内容和边框之间的空隙，**会撑大盒子** |
| 边框 | `border` | 边框本身有厚度，**也算进盒子尺寸** |
| 外边距 | `margin` | 盒子和别的盒子之间的距离，透明 |

## width 到底算哪一层

默认情况下，`width: 200px` 指的是**内容区** 200px。

加上 padding 和 border 之后，盒子在页面上实际占的宽度变成：

```text
200px（内容）+ 20px×2（左右内边距）+ 2px×2（左右边框）= 264px
```

你想要 200，得到 264，布局就崩了。

## box-sizing：让 width 说了算

```css
.box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 2px solid;
}
```

加上这一行，`width: 200px` 就变成"整个盒子的宽度是 200"，padding 和 border 从里面挤，内容区自动缩小。

这样宽度配上 padding 不用再算数，几乎所有项目都会在开头统一设一遍：

```css
*, *::before, *::after {
  box-sizing: border-box;
}
```

这三行是现在 CSS 文件里最常见的一段。

## padding 和 margin 写几个值

```css
margin: 10px;                  /* 上下左右都是 10 */
margin: 10px 20px;             /* 上下 10，左右 20 */
margin: 10px 20px 30px;        /* 上 10，左右 20，下 30 */
margin: 10px 20px 30px 40px;   /* 上 右下 左（顺时针） */
```

单边也能单独写：

```css
margin-top: 10px;
padding-left: 16px;
```

简写和单边最好别混着写，顺序上容易互相覆盖。

## 两个小知识点

**padding 不能为负**，margin 可以是负的。

**margin 会合并**：上下相邻的两个块，它们的 margin 不会相加，而是取较大的那个。

```css
.a { margin-bottom: 20px; }
.b { margin-top: 30px; }
```

两个元素之间实际是 30px，不是 50px。这就是"外边距塌陷"，很多人第一次遇到会以为写错了。

用 flex 或 grid 布局时不会出现这个问题（它们用 `gap` 控制间距），这也是现在推荐用它们布局的原因之一。

## padding 撑大 vs 撑开

一个按钮：内容是"确定"两个字，加上左右 padding 就变宽，加上上下 padding 就变高。

```css
button {
  padding: 10px 24px;
  border: none;
  border-radius: 6px;
  background: #284b63;
  color: #fff;
}
```

↓ 渲染出来是这样：

<p><span style="display:inline-block;padding:10px 24px;border-radius:6px;background:#284b63;color:#fff">确定</span></p>

## margin 用来推开别人

想让某块内容离上一段远一点，用 margin：

```css
section {
  margin-top: 3rem;
}
```

但注意：**margin 的垂直方向在父元素里会跑出去**。给子元素加 `margin-top`，父元素可能被一起推下去，而不是子元素在里面下移。

这时候改用父元素的 `padding-top` 就对了。

## 调试盒子最快的方法

临时加一条：

```css
* { outline: 1px solid red; }
```

页面上每个盒子的边界立刻看得见。

用 `outline` 而不是 `border`，是因为 outline 不占空间、不影响布局。调完记得删掉。

更好的办法是按 F12，选中元素后在页面上就能看到它的 padding（绿色）和 margin（橙色）色块，还能直接改数值看效果。
