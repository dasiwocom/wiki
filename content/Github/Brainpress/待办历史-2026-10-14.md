## 一、当前项目方向

- 完全自研、独立运行，借鉴 WordPress 内容管理思路和 Zibll 前台布局、交互，不依赖它们运行。
- 只有一套 `post` 文章体系，不另建论坛帖子体系；当前采用单层分类，每篇文章属于一个分类。
- Markdown 原文是正文的权威来源，保存在数据库中，前台渲染；图片保存在独立目录。
- 初期个人测试，不做用户注册、登录、投稿身份验证或审核；发布状态分为草稿与发布。
- 项目界面、源码说明和新增技术文档使用英文；本目录保留中文产品讨论和任务记录。
- Markdown 逐步对齐 Obsidian，当前已超出 CommonMark 基础范围，但不声称完整兼容 Obsidian。
- 先完善个人发布、管理与阅读流程；AI、消息、用户系统、App 等留到后续。

## 六、部署与验收边界

- 当前没有登录，草稿和 `/admin` 等编辑入口不构成权限隔离。个人云端测试可在服务器侧加密码或 IP 限制，尚未实际配置。
- 部署网站根目录必须为 `public`，需要 PHP 8.2+ 及相应扩展，`storage` 和 `public/uploads` 需要可写。
- 切换到 MySQL 不会自动搬运现有 SQLite 文章与图片。
- 每轮功能修改后，分别检查代码、页面和部署包；“已实现”“已验收”“已部署”三个状态不能混用。
- 最近一次成品：`brainpress-admin-2026-10-14.zip`，后续修改后须重新生成。
