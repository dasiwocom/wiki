# 页面布局与顶部菜单当前方案

更新日期：2026-10-14

## 页面布局

所有布局上下文均可使用：顶部全宽、主内容顶部、主内容、主内容底部、侧栏、底部全宽、页脚。空区域不显示、不占位。

首页、所有文章详情、分类列表、分类／标签／搜索归档各有独立布局；自定义页面使用独立配置。后台「页面 → 站点布局」进入对应实际页面编辑。配置可预览、排序、选择区域、保存和恢复默认。

小工具只有帖子列表、分类列表、个人信息卡、文章目录。个人信息卡可重复；每种列表和目录只允许一个，避免多个分页冲突。目录仅用于文章侧栏；文章正文是固定核心，不依赖可删除的小工具。

用户明确：不新增 Markdown 文本小工具，也不新增独立页面 Markdown 正文编辑器。头像、封面、名称、简介仍由个人信息卡设置。

## 顶部菜单

一级菜单有二级菜单时，桌面展开横向宽面板；无二级菜单时保持普通条目。二级菜单作为各列标题，其下可添加文字条目。

每个文字条目有「文字」和「链接（可选）」两个字段。链接留空显示普通文字，填入本地路径或 HTTP(S) 地址时显示可点击链接。列内容与二级标题左对齐，不增加截图左侧的描述列。

菜单管理保留增删、排序、父级选择与显示／隐藏。手机侧栏使用同一菜单层级，改为纵向排列。手机底部 Tab 独立管理，不读取顶部菜单配置。

本轮只做顶部菜单的二级展现；分类数据的二级关系仍保持现有实现，分类页树状展示另行讨论。

## 范围与验收

布局接口和菜单渲染已通过隔离数据库测试；浏览器视觉验收继续单独记录。部署包本轮不生成。当前完整任务状态以 [[待办]] 为准。

## 2026-10-15：编辑入口与响应式控制区

已按最新决定实现顶部编辑入口：桌面使用固定左侧小工具面板，右侧实际页面预览；手机复用侧菜单抽屉显示小工具设置，退出后恢复普通菜单。按区域组织添加、配置、移动、排序和移除，保存才生效，退出提醒未保存修改。后台不另建重复的小工具数据体系，继续沿用已有页面作用范围和布局配置。页脚全局信息在系统设置维护，与页脚模块区域区分。
