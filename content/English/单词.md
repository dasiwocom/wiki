## Kernel 内核
计算机操作系统的核心程序
The kernel manages memory and processes. 内核管理内存和进程。/Linux is a kernel, not a complete operating system.Linux 是一个内核，不是完整的操作系统。/A kernel panic causes the system to crash.内核崩溃会导致系统崩溃。/The kernel communicates directly with the hardware.内核直接与硬件通信。/You can compile your own kernel.你可以编译自己的内核。

## Modular 模块化的
模块化的，指将程序拆分成独立模块进行设计和管理的方法
Modular programming makes code easier to maintain.模块化编程使代码更易于维护。/This project uses a modular design.这个项目采用了模块化设计。/The code is divided into modular units.代码被划分成模块单元。/A modular system is easier to upgrade.模块化系统更容易升级。

编译器，一种将源代码翻译成机器可执行代码的程序
The compiler converts source code into machine code.编译器将源代码转换为机器代码。/This code compiles without errors.这段代码编译没有错误。/The compiler reported a syntax error.编译器报告了一个语法错误。/Write clean code to avoid compiler warnings.编写整洁的代码以避免编译器警告。/The compiler generates a hex file for the MCU.编译器为单片机生成hex文件。
