# 开发记录

## 2026-10-16 · 0.2

用户原话：

> 可以正式开始写了 继续优化

本轮继续迭代可运行的 Windows 版本；仍采用 PowerShell/WPF + 独立编写的 Win32 API 逻辑，未将其描述为完成的 Rust 正式版。

### 已实现

- 16 毫秒调度的三次缓出窗口动画；新布局覆盖旧动画，暂停或关闭立即取消。
- 动画开关、80–400 毫秒时长、30%–70% 分割比例设置。
- 程序目录 settings.json 自动保存设置，使用临时文件替换写入；读取时限制数值范围。
- 删除每 500 毫秒强制移动所有窗口的逻辑，仅在布局或主屏工作区变化时重排。
- 鼠标没有命中区域时优先活动窗口，再回退最后一个区域。
- 恢复使用 GetWindowPlacement / SetWindowPlacement，保存窗口正常位置和最大化状态；暂停时保持用户当前最小化状态。
- 恢复前核对窗口所属进程，删除已关闭窗口的缓存，降低句柄重用导致误操作的风险。
- 单实例互斥、错误日志、导航选中背景、按分割比例计算最小区域保护。

### 检查结果

Windows PowerShell 实际执行 -Check 成功：Win32 定义编译、WPF XAML 加载、叶子遍历、关闭补位、横向二分、纵向二分和非等比分割通过。

渲染了真实 WPF 控件树并检查概览页面：深色背景、左侧导航、设置卡片和蓝色按钮显示正常。此检查没有启动真实桌面平铺，不等于跨应用兼容性验收。
