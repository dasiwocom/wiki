# Superwin

更新：2026-10-16

## 用户目标

做一个 Windows 窗口管理工具，参考 Hyprland 的动态平铺体验。没有必要为了区别现有项目而修改用户想要的机制。遇到不会实现的部分，查阅 Hyprland、komorebi 的设计和代码，遵守相应许可证。

## 已确认需求

- 第一个普通应用窗口占满工作区，保留任务栏。
- 第二个窗口沿区域长边平分；宽大于高时左右分，高大于宽时上下分。
- 后续窗口在鼠标所在窗口区域继续分割。
- 窗口关闭后相邻区域补位。
- 动画丝滑，后续支持调整分割比例。
- 先做窗口布局，不优先做快捷键。
- 必须提供独立管理窗口，采用 Windows 11 设置应用的 UI 风格。
- UI 参考用户提供的截图：深色背景、左侧导航、蓝色选中指示、右侧标题与设置卡片、圆角和清晰层级。
- 文档、待办、问题及用户原话持续记录在本目录。

## 参考项目

- [Hyprland](https://github.com/hyprwm/Hyprland)：公开源码，仓库标示 BSD-3-Clause；主要参考 Dwindle 行为，不能把 Linux 合成器直接当作 Windows 窗口管理实现。
- [Dwindle 文档](https://wiki.hypr.land/0.55.0/Configuring/Layouts/Dwindle-Layout/)：二叉树布局、宽高比决定分割方向、活动窗口或鼠标决定分割目标。
- [komorebi](https://github.com/LGUG2Z/komorebi)：参考 Windows 窗口管理设计。当前许可证限制再分发及基于代码发布新作品，不直接复制其实现。

## 实现阶段

桌面程序目录：`C:\Users\windows\Desktop\superwin`。

本机未发现 cargo/rustc，dotnet 没有可用 SDK。先用 Windows 自带 PowerShell + WPF + Win32 API 做可运行验证版本，验证 UI、窗口枚举、区域分割和恢复。此选择是当前开发决策，不代表用户放弃 Rust；正式技术栈仍待确定。

原型只在点击“启用自动平铺”后管理当前主显示器上的可见普通窗口；管理界面自身不参与平铺。暂停或退出时恢复记录的位置。第一版采用轮询发现窗口，不是最终事件驱动架构。
