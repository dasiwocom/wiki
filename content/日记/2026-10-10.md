## 想法 / 随记

> [!tip] 核心主张（本人原话提炼）
> 1. 别只写普通 md —— mermaid、HTML、SVG、图片、双链都用起来
> 2. 别一成不变 —— 命名、结构随时可调，用户会通过对话调整
> 3. 别让下一个 agent 误以为现有结构是固定规范
> 4. 这里不只放知识点 —— 日记、单词、资料、提示词、项目都装
> 5. 最终目标是**知识网络**，不是文件夹

## 学到的

- 回收站是虚拟 shell 命名空间对象 → [[Windows 回收站]]
- 我早期用的 `分类-标题.md` 命名被否掉了 → 见 [[知识库手册]] 命名章节

## 今天的决策

| 决策 | 结果 |
|---|---|
| 命名 | 废弃前缀式，改自然语言短标题 |
| 分区 | 手册 / 笔记 / 日记 / 日常 / 词库 / 项目 / 提示词 / 资料 |
| 规则 | 「写」= 写入 wiki；无指示不动手 |
| 元文档 | `知识库手册.md` 里写了「给接手的 agent」章节 |
| 角色 | 升级为**贴身秘书**：管知识网络，也管日常事务；授权「放心大胆记录」 |
| 权限 | 三级：🟢 库内记录自主 / 🟡 结构调整先做后报 / 🔴 对外与不可逆动作必须问 |
