Desktop: 桌面
开机后看到的整个屏幕界面，是系统的主工作区

Taskbar: 任务栏
屏幕底部（或侧边）的横条，放开始按钮、正在运行的程序和系统托盘

File Explorer: 文件资源管理器
Windows 的文件管理工具，用来浏览、复制、移动、删除文件和文件夹

Control Panel: 控制面板
Windows 系统设置与管理工具的集合界面，可配置硬件、程序和网络等

Recycle Bin: 回收站
删除文件的临时存放处，在清空之前可随时还原

Shortcut: 快捷方式
指向文件、程序或文件夹的图标链接，双击即可快速打开目标

Driver: 驱动程序
让操作系统识别并控制硬件设备的底层软件

Command Prompt: 命令提示符
Windows 自带的命令行界面，通过输入命令来操作电脑

Registry: 注册表
Windows 存储系统配置和软件设置的中央数据库

Backup: 备份
把数据复制保存到其他位置，防止文件丢失

## Driver: 驱动程序 /ˈdraɪvər/

例句:

You need to install the graphics driver.你需要安装显卡驱动程序。（graphics 指"图形/显卡"）
The printer won't work because the driver is outdated.打印机无法工作，因为驱动程序太旧了/（outdated = 过时的）
Make sure to update your drivers regularly.记得定期更新你的驱动程序。（make sure = 确保）
This device driver controls the sound card.这个设备驱动控制声卡。（device = 设备；sound card = 声卡）
A missing driver can cause hardware to malfunction.缺少驱动程序会导致硬件故障。（malfunction = 出故障/失灵）

搭配:

install a driver 安装驱动程序
update the driver 更新驱动程序
printer driver 打印机驱动程序
graphics driver 显卡驱动程序
device driver 设备驱动程序

助记:

drive（驱动/驾驶）→ driver（驱动程序）
就像一个"驱动机器运转的司机"，它是让硬件工作起来的底层软件。
