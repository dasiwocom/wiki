## Kernel: 内核 /ˈkɜːrnl/

例句:
1. The kernel manages memory and processes.
   内核管理内存和进程。（manage = 管理；process = 进程）
2. Linux is a kernel, not a complete operating system.
   Linux 是一个内核，不是完整的操作系统。（kernel 只是内核，操作系统是完整系统）
3. A kernel panic causes the system to crash.
   内核崩溃会导致系统崩溃。（kernel panic = 内核崩溃/内核恐慌）
4. The kernel communicates directly with the hardware.
   内核直接与硬件通信。（communicate = 通信；hardware = 硬件）
5. You can compile your own kernel.
   你可以编译自己的内核。（compile = 编译）

搭配:
- Linux kernel Linux 内核
- kernel panic 内核崩溃
- kernel module 内核模块
- kernel space 内核空间
- operating system kernel 操作系统内核

助记:
kernel（谷粒/种子仁）→ 内核
就像种子的"核"，是系统最中心、最核心的部分，负责管理硬件和资源。

## Driver: 驱动程序 /ˈdraɪvər/

例句:
1. You need to install the graphics driver.你需要安装显卡驱动程序。（graphics 指"图形/显卡"）
2. The printer won't work because the driver is outdated.打印机无法工作，因为驱动程序太旧了/（outdated = 过时的）
3. Make sure to update your drivers regularly.记得定期更新你的驱动程序。（make sure = 确保）
4. This device driver controls the sound card.这个设备驱动控制声卡。（device = 设备；sound card = 声卡）
5. A missing driver can cause hardware to malfunction.缺少驱动程序会导致硬件故障。（malfunction = 出故障/失灵）

搭配:
- install a driver 安装驱动程序
- update the driver 更新驱动程序
- printer driver 打印机驱动程序
- graphics driver 显卡驱动程序
- device driver 设备驱动程序

助记:
drive（驱动/驾驶）→ driver（驱动程序）
就像一个"驱动机器运转的司机"，它是让硬件工作起来的底层软件。
