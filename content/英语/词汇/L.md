## loop 循环
This loop keeps running because the exit condition is wrong.这个循环一直运行，因为退出条件写错了。
The loop runs ten times before it stops.这个循环运行十次后停止。
An infinite loop will cause the program to freeze.无限循环会导致程序卡死。
Nested loops significantly increase time complexity and should be used with caution.嵌套循环会显著增加时间复杂度，应谨慎使用。
