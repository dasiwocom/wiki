## RAM 随机存取存储器
My computer is slow because the RAM is almost full.电脑卡是因为内存快满了。
Variables are stored in RAM.变量存储在RAM中。
RAM loses all data when the power is turned off.断电时RAM会丢失所有数据。
RAM provides volatile high-speed storage essential for the runtime execution of programs.随机存取存储器提供易失的高速存储，是程序运行的基础。

## ROM 只读存储器
The firmware is burned into ROM, so you can't easily change it.固件烧录在只读存储器里，不容易改动。
The program is stored in ROM.程序存储在只读存储器中。
ROM keeps data even after the power is off.断电后只读存储器仍保留数据。
Read-only memory preserves boot code that executes before the operating system loads.只读存储器保存操作系统加载前执行的启动代码。

It is essential to read academic papers critically to conduct a rigorous literature review.批判性阅读学术论文对严谨的文献综述至关重要。
