## driver 驱动程序
You should update your graphics driver to fix the display glitches.你应当更新显卡驱动程序来修复画面故障。
This printer won't work because the driver is not installed.打印机无法工作，因为没有安装驱动程序。
A faulty device driver may cause the whole system to crash.故障的设备驱动程序可能导致整个系统崩溃。
The device driver acts as an intermediary that translates high-level system commands into hardware-specific instructions.设备驱动程序作为中间层，将高层系统指令转化为硬件专用指令。

We use a debugger to find bugs in the code.我们用调试器查找代码中的错误。
The software remains in debug mode during the testing phase.测试阶段该软件仍处于调试模式。
Effective debugging requires systematic isolation of variables and rigorous log analysis.有效调试需要系统化隔离变量，并进行严谨的日志分析。

## declaration 声明
You can't use a variable without declaring it first.不先声明就不能使用变量。
A function declaration must end with a semicolon.函数声明必须以分号结尾。
Missing a declaration will trigger a compiler warning.缺少声明会触发编译器警告。
In header files, function declarations enable separate compilation across multiple source files.头文件中的函数声明使多个源文件能够分别编译。
