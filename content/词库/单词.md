## Driver 驱动程序
驱动程序是一种特殊的软件程序，充当计算机操作系统与硬件设备之间的通信桥梁
You need to install the graphics driver.你需要安装显卡驱动程序。/The printer won't work because the driver is outdated.打印机无法工作，因为驱动程序太旧了。/This device driver controls the sound card.这个设备驱动控制声卡。/This device driver controls the sound card.这个设备驱动控制声卡。

## Kernel 内核
计算机操作系统的核心程序
The kernel manages memory and processes. 内核管理内存和进程。/Linux is a kernel, not a complete operating system.Linux 是一个内核，不是完整的操作系统。/A kernel panic causes the system to crash.内核崩溃会导致系统崩溃。/The kernel communicates directly with the hardware.内核直接与硬件通信。/You can compile your own kernel.你可以编译自己的内核。

## Argument 参数
参数，指传给命令或函数的输入值；也指论据、争论
The command requires two arguments.该命令需要两个参数。/"/" was already used for command arguments."/" 已经被用作命令行参数。/You can pass arguments to the function.你可以向函数传递参数。/He made a convincing argument.他提出了令人信服的论据。

## Debug 调试
调试，指发现并修复程序错误（bug）的过程
I used the debugger to find the error.我使用调试器来查找错误。/Debug the code line by line.逐行调试代码。/The software is still in debug mode.该软件仍处于调试模式。/The error only appears when debugging.这个错误只在调试时出现。

---
## Modular 模块化的
模块化的，指将程序拆分成独立模块进行设计和管理的方法
Modular programming makes code easier to maintain.模块化编程使代码更易于维护。/This project uses a modular design.这个项目采用了模块化设计。/The code is divided into modular units.代码被划分成模块单元。/A modular system is easier to upgrade.模块化系统更容易升级。

---
## Compiler 编译器
编译器，一种将源代码翻译成机器可执行代码的程序
The compiler converts source code into machine code.编译器将源代码转换为机器代码。/This code compiles without errors.这段代码编译没有错误。/The compiler reported a syntax error.编译器报告了一个语法错误。/Write clean code to avoid compiler warnings.编写整洁的代码以避免编译器警告。/The compiler generates a hex file for the MCU.编译器为单片机生成hex文件。

## Loop 循环
循环，指重复执行某段代码的结构（如 while、for）
The loop runs ten times.这个循环运行十次。/An infinite loop never stops.无限循环永远不会停止。/The delay function uses a nested loop.延时函数使用了嵌套循环。/Exit the loop when the condition is false.当条件为假时退出循环。

---
## Pin 引脚
引脚，芯片上用于连接外部的金属针脚
Connect the LED to pin P1.0.将LED连接到P1.0引脚。/The chip has 40 pins.这颗芯片有40个引脚。/Set the pin to high level.将该引脚设置为高电平。/Each pin has a specific function.每个引脚都有特定功能。

## Schematic 原理图
原理图，用符号表示电路连接关系的图纸
Check the schematic before wiring.接线前先查看原理图。/The schematic shows the pin connections.原理图显示了引脚连接。/Draw a schematic for the circuit.为电路绘制原理图。/Refer to the schematic to find the error.参考原理图查找错误。

## Variable 变量
变量，程序里用于存储数据的可改变的量
Declare a variable before using it.使用变量前先声明它。/This variable stores the counter value.这个变量存储计数值。/Use meaningful variable names.使用有意义的变量名。/The variable increases by one each loop.每次循环变量加一。

## Declaration 声明
声明，告诉编译器某个函数或变量的名字和类型
The header file contains function declarations.头文件包含函数声明。/A declaration ends with a semicolon.声明以分号结尾。/Missing declaration causes a warning.缺少声明会导致警告。/Declaration and definition are different.声明和定义是不同的。
