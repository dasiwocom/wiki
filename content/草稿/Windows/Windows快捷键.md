# Windows 快捷键

以 Windows 11 为主。`Win` 指键盘上的 Windows 徽标键，`+` 表示组合按键。部分快捷键会受应用、系统版本和键盘设置影响。

## 先记这几个

| 快捷键                  | 用途                        |
| -------------------- | ------------------------- |
| `Win + Z`            | 打开分屏布局选择                  |
| `Win + ← / →`        | 将当前窗口贴靠屏幕左侧／右侧            |
| `Alt + Tab`          | 切换应用窗口；按住 Alt 再连续按 Tab 选择 |
| `Win + Tab`          | 打开任务视图，查看窗口和虚拟桌面          |
| `Win + Ctrl + D`     | 新建并切换到虚拟桌面                |
| `Win + Ctrl + ← / →` | 切换左侧／右侧虚拟桌面               |
| `Win + Shift + S`    | 选取区域截图                    |
| `Win + V`            | 打开剪贴板历史，首次需启用             |
| `Win + E`            | 打开文件资源管理器                 |
| `Win + I`            | 打开设置                      |

## 窗口与多显示器

| 快捷键 | 用途 |
| --- | --- |
| `Win + ↑` | 最大化当前窗口 |
| `Win + ↓` | 还原或最小化，取决于当前窗口状态 |
| `Win + Shift + ← / →` | 将当前窗口移到另一台显示器 |
| `Win + D` | 显示桌面，再按一次返回 |
| `Alt + F4` | 关闭当前应用／窗口 |
| `Win + P` | 选择复制、扩展等投影模式 |

左右贴靠后可继续用上下方向键组合安排角落窗口；具体效果取决于窗口状态。若分屏无效，检查“设置 → 系统 → 多任务处理 → 贴靠窗口”。

## 虚拟桌面

| 快捷键 | 用途 |
| --- | --- |
| `Win + Ctrl + F4` | 关闭当前虚拟桌面 |

关闭虚拟桌面不会关闭其中的应用，窗口会移到其他桌面。用 `Win + Tab` 后可拖动窗口到目标桌面，也可右键窗口选择“移动到”。

适合把开发、查资料、聊天分成不同桌面；需要同时对照内容时，在同一桌面分屏。虚拟桌面用于整理窗口，不会让后台程序停止运行。

## 截图与剪贴板

| 快捷键 | 用途 |
| --- | --- |
| `Win + PrtScn` | 全屏截图并保存到“图片 → 屏幕截图” |
| `Alt + PrtScn` | 当前窗口截图，复制到剪贴板 |
| `Win + .` | 打开表情符号面板 |

部分笔记本需要配合 `Fn` 使用 PrtScn。单独按 PrtScn 的行为可能受截图设置影响。

## 文件与文字

| 快捷键 | 用途 |
| --- | --- |
| `Ctrl + C / X / V` | 复制／剪切／粘贴 |
| `Ctrl + Z` | 撤销；文件操作后也可能生效 |
| `Ctrl + A` | 全选 |
| `F2` | 重命名选中文件 |
| `Ctrl + Shift + N` | 在资源管理器中新建文件夹 |
| `Alt + Enter` | 打开选中文件的属性 |
| `Alt + ← / →` | 在资源管理器中后退／前进 |
| `Alt + ↑` | 转到上一级文件夹 |
| `Ctrl + L` | 选中资源管理器地址栏 |
| `Ctrl + Shift + V` | 在支持的应用中粘贴纯文本 |

## 系统与故障处理

| 快捷键 | 用途 |
| --- | --- |
| `Win + L` | 锁屏 |
| `Win + R` | 打开“运行” |
| `Win + X` | 打开开始按钮的快捷菜单 |
| `Ctrl + Shift + Esc` | 打开任务管理器 |
| `Ctrl + Alt + Delete` | 打开安全选项界面 |
