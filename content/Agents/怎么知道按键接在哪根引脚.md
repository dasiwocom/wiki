# 怎么知道按键接在哪根引脚

## 一句话

丝印上写的「P30-P33」是**范围说明**（这四颗键占用 P3.0 到 P3.3），**不等于**「第一颗键接 P3.0」。实际对应关系要实测一次才确定。

## 为什么丝印不能直接照抄

丝印给的是范围，而每颗键具体焊到哪根脚，是画电路板走线时决定的。走线为了方便可能会绕一下，于是出现「编号顺序」和「引脚号顺序」对不上的情况——比如第一颗键实际接在 P3.1、第二颗接在 P3.0。

这不是故障，只是编号和引脚号没有对齐。**以实测为准。**

## 镜子程序：一次测出全部对应关系

思路很直白：把每根引脚的状态，原样复制到对应的一颗 LED 上（LED 是低电平点亮，按键按下是低电平，正好一致）。

```c
#include <REGX52.H>

void main()
{
    while(1)
    {
        P2_0 = P3_0;   // D1 照 P3.0
        P2_1 = P3_1;   // D2 照 P3.1
        P2_2 = P3_2;   // D3 照 P3.2
        P2_3 = P3_3;   // D4 照 P3.3
    }
}
```

烧进去后**逐个按住按键，看哪颗灯亮**：

| 现象 | 结论 |
| --- | --- |
| 按 K1 → **D2** 亮 | K1 接的是 **P3.1** |
| 按 K2 → **D1** 亮 | K2 接的是 **P3.0** |
| 按 K3 → D3 亮 | K3 接 P3.2，编号和引脚号对得上 |
| 按 K4 → D4 亮 | K4 接 P3.3 |

**读法**：哪颗灯亮，那颗键就接在那颗灯所照的那根引脚上。灯和键的编号对不上没关系，看的是「灯照的是哪根脚」。

> [!tip] 这招不只用于按键
> 任何"不知道某个零件接在哪根脚"的情况，都可以写一段镜子程序把引脚状态映射到 LED 上，比翻原理图快得多。

## 完整的按键翻转程序

```c
#include <REGX52.H>

void Delay(unsigned int xms)
{
    unsigned char i, j;
    while(xms)
    {
        i = 2; j = 239;
        do { while (--j); } while (--i);
        xms--;
    }
}

void main()
{
    while(1)
    {
        if(P3_1==0)                    // 按下的那颗键
        {
            Delay(20);                 // ① 按下消抖
            while(P3_1==0) Delay(20);  // ② 等松手
            Delay(20);                 // ③ 松手消抖
            P2_0=~P2_0;                // 翻转一颗灯
        }
    }
}
```

## 为什么要消抖三次

机械按键在闭合和断开的瞬间，金属触点会**弹跳几毫秒**，电平会来回抖好几次。单片机跑得很快，会把这些抖动当成好几次按下。

| 步骤 | 作用 |
| --- | --- |
| ① 延时 20ms 再判断 | 跳过按下瞬间的抖动，确认是真的按下了 |
| ② 等松手 | 按住不放时只算一次 |
| ③ 松手后再延时 20ms | 跳过松手瞬间的抖动 |

少了第 ③ 步也能跑，但松手瞬间有几率被当成第二次按下，表现是「按一次却翻了两下」。
