# STC-ISP 卡在检测目标单片机的原因

## 一句话

STC 单片机**不是点下载就立刻烧录**，而是「点下载 → 给芯片重新上电」。芯片只在上电后的极短时间内接受烧录握手，错过这个窗口就再也不响应了。

## 为什么会一直卡住

- 每次上电，芯片先跑一段出厂自带的引导程序（bootloader），它会**等很短暂的一会儿**（几十到几百毫秒），看有没有烧录指令过来
- **收到了** → 进入烧录模式，开始擦除、写入
- **没收到** → 立刻跳转去执行上次烧进去的用户程序，此后**再也不理会**烧录命令

所以只要芯片一直在通电跑程序，软件就永远检测不到它，界面一直停在「正在检测目标单片机」。

> [!warning] 按复位键没用
> 必须是**断电再上电**（冷启动）。按复位键属于热复位，不会重新打开那个等待窗口。

## 正确的操作顺序

1. 软件里选好芯片型号、串口号，打开 hex 文件
2. 点**下载/编程**，等界面出现「正在检测目标单片机」
3. **这时候**给开发板断电 → 停 1 秒 → 再通电
4. 接着就会看到握手 → 擦除 → 编程 → 完成

## 断电用板载开关，别拔 USB 线

| 做法 | 结果 |
| --- | --- |
| 按板载**电源开关**（自锁开关：按下去卡住、再按弹起） | 推荐 |
| 拔插 USB 线 | 经常失败 |

原因是两个时间差得太远：芯片的等待窗口只有几百毫秒，而拔掉 USB 后操作系统要**好几秒**才把串口重新准备好。等串口能用的时候，窗口早就关掉了。

板载电源开关通常**只切断单片机、不动 USB 转串口芯片**，串口全程在线，握手指令能在上电瞬间立刻发出去。

> [!tip] 怎么判断你的板属于哪种
> 按开关的时候，如果电脑上那个 COM 口没有消失，说明开关只切单片机——这是最理想的情况，用开关下载就行得通。

## 还是不行，按顺序查这几项

- **芯片型号选对**：丝印写 `STC89C52RC` 就要选 `STC89C52RC/LE52RC`，不要选没有 RC 后缀的老条目（见 [[STC 芯片型号怎么看]]）
- **串口号选对**：设备管理器里看 USB-SERIAL CH340 占的是哪个 COM
- **跳线帽**：USB 转串口和单片机之间的跳线帽掉了，就永远握不上手
- **数据线**：换一根，直接插机箱后面的 USB 口，不要经过集线器或前面板延长线
