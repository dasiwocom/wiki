# 侧边栏目录名太长折成好几行，怎么截断和加宽

知识库用久了，目录会越建越深，文件夹名和笔记名也越来越长。

打开网页一看，左边侧栏里不再是整齐的一列，而是有的名字占一行、有的占两三行，参差不齐，找个文件眼睛要在不同高度上跳来跳去。

这一篇讲三件事：**为什么会折行**、**怎么改成一行加省略号**、**以及怎么把栏调宽**。

## 为什么会折行

两个原因叠在一起：**插件没写这个功能**，加上**栏太窄**。

### 原因一：目录插件自带样式里就没有截断规则

我把这个目录插件（Quartz 的 Explorer）编译出来的 CSS 翻了一遍，`text-overflow` 和 `ellipsis` **出现 0 次**。

它自带的样式只管颜色、层级缩进、折叠动画这几类东西，**一条跟文字截断有关的规则都没有**。

所以条目文字走的是浏览器最默认的行为：一行装不下，就折到下一行接着排。

这一点值得记住，因为它决定了排查方向——**这不是"少开了一个开关"，而是这个功能作者压根没做**。所以在配置文件里找不到任何相关选项，只能自己写样式补上。

### 原因二：侧边栏本身就窄

栏宽写在 `quartz/styles/variables.scss` 里：

```scss
$sidePanelWidth: 320px; //380px;
```

目前是 320px。那一行末尾的注释 `//380px` 是官方的原生默认值，说明现在这个值是被特意改窄过的。

320px 还要扣掉左右各 2rem 的内边距（一共 64px），真正留给文字的只有 **256px 左右**。

而目录每往下一层，还会再吃掉大约 19px 的缩进：

| 缩进来源 | 大约宽度 |
| --- | --- |
| 每层的 `margin-left` | 6px |
| 每层的 `padding-left` | 约 13px |
| 左侧那条层级竖线 | 占位若干 |

| 在第几层 | 大约剩余可用宽度 |
| --- | --- |
| 第 1 层 | 256px |
| 第 2 层 | 237px |
| 第 3 层 | 218px |
| 第 4 层 | 199px |

到第三、第四层只剩两百来像素，一个「第9章 多元函数微分法及其应用」这样的名字，两三个字就得换行。

所以长名字折行这件事，**层级越深越明显**。

## 怎么改成一行加省略号

改一个文件：`quartz/styles/custom.scss`。

这个文件是官方留给写自定义样式的地方，至于为什么写这里比改别的地方好，下面单独说。

### 需要三个属性配合，缺一个都不生效

| 属性 | 作用 | 少了它会怎样 |
| --- | --- | --- |
| `white-space: nowrap` | 禁止折行 | 文字照旧折成好几行 |
| `overflow: hidden` | 允许把装不下的部分裁掉 | 文字直接冲出容器边界，压到旁边内容上 |
| `text-overflow: ellipsis` | 在被裁掉的位置画省略号 | 文字被硬生生切断，看不出后面还有内容 |

这三条不是我总结的经验，是 CSS 规范本身的要求。MDN 上写得很直白：

> `text-overflow` 属性并不会强制"溢出"事件的发生，因此为了能让文本能够溢出容器，你需要在元素上添加几个额外的属性：`overflow` 和 `white-space`。

出处：[MDN · text-overflow](https://developer.mozilla.org/zh-CN/docs/Web/CSS/text-overflow)

### 还有一条最容易漏：`min-width: 0`

这条最坑，也是"我明明写了代码却没效果"的头号原因。

目录里的每一项，都是 flex 布局里的一个子项（左边一个小图标或箭头，右边是文字块）。

而 **flex 子项有一条默认规则：`min-width: auto`**。

它的意思是：**"我拒绝被压缩到比我的内容更窄。"**

于是问题来了——父容器只有 256px，文字却有 300px 宽，按理说该溢出、该被裁掉，然后画省略号。但因为 `min-width: auto`，浏览器会认为"350px 才是我的最小宽度"，文字块就保持 350px 不缩，**根本不产生溢出**。

没有溢出，`text-overflow: ellipsis` 就永远不触发。你写的规则明明在样式表里，页面上看起来却跟没改一样。

所以必须显式写 `min-width: 0`，**把这条默认规则关掉**，告诉浏览器"我可以被压到任意窄"。

> [!warning] 记住这条通用规则
> 给 flex 子项加省略号，`min-width: 0` 基本是必需品。
> 只要是"flex 里放一段想省略的文字"，就要连这个一起写。

### 完整代码

下面这段就是现在 `custom.scss` 里生效的内容：

```scss
.explorer-content {
  // 可收缩的层级，全部放开压缩限制
  li,
  .folder-container,
  .folder-container > div {
    min-width: 0;
  }

  // 文件夹名那一行：让文字块吃掉箭头之外的剩余宽度
  .folder-container > div {
    flex: 1 1 auto;
  }

  // 笔记文件名
  a.nav-file-title,
  .folder-container > div > a {
    display: block;
    min-width: 0;
    max-width: 100%;
    overflow: hidden;
    white-space: nowrap;
    text-overflow: ellipsis;
  }

  // 文件夹名（可折叠的那些）
  .folder-button,
  .folder-title {
    min-width: 0;
    max-width: 100%;
  }

  .folder-title {
    display: block;
    overflow: hidden;
    white-space: nowrap;
    text-overflow: ellipsis;
  }

  // 左边的小文件夹图标 / 展开箭头不要被挤掉
  .folder-icon {
    flex-shrink: 0;
  }
}
```

最后那条 `.folder-icon { flex-shrink: 0 }` 是配套的：文字块可以随便压，但图标不行，否则窄的时候图标先被压扁。

### 为什么写在 custom.scss，而不是改插件或框架文件

`quartz/styles/custom.scss` 是官方文档里明确指定的自定义样式入口。官方 Layout 页的原话是：

> You can see the base style sheet in `quartz/styles/base.scss` and write your own in `quartz/styles/custom.scss`.

出处：[Quartz 官方文档 · Layout](https://quartz.jzhao.xyz/layout)

它比别的位置好在两点：

1. **优先级天然更高**。构建时它被拼在框架样式**之后**，而且不在 `@layer quartz-base` 这一层里，所以同优先级的规则它是后写的，直接压过插件自带样式，不需要写一堆 `!important`。
2. **它不会被升级覆盖**。`quartz/` 目录下那些文件是框架自带的，以后更新 Quartz 可能被覆盖或者产生冲突；`custom.scss` 是留给使用者的文件，改动是安全的。

## 如果还想把栏调宽

截断只是让目录变整齐，**能看见的字数并没有变多**。要真想看全名字，得把栏加宽。

宽度有两种改法：

| 改哪里 | 怎么写 | 优点 | 代价 |
| --- | --- | --- | --- |
| `quartz/styles/variables.scss` 里的 `$sidePanelWidth` | 改一个数 | 最直观，一处生效 | 是框架自带的文件，以后升级可能被覆盖或产生冲突 |
| `custom.scss` 里覆盖 `grid-template-columns` | 加一段 CSS | 不会被覆盖 | 要自己写两个断点 |

推荐第二种。宽度最终是由页面容器的栅格决定的，直接覆盖栅格就行：

```scss
// 桌面端（窗口 ≥1200px）：三栏，左右两栏同宽
@media all and (min-width: 1200px) {
  .page > #quartz-body {
    grid-template-columns: 380px auto 380px;
  }
}

// 平板端（800~1200px）：两栏，只有左栏
@media all and (min-width: 800px) and (max-width: 1200px) {
  .page > #quartz-body {
    grid-template-columns: 380px auto;
  }
}
```

两个断点的数值（800 / 1200）来自 `variables.scss` 里的 `$breakpoints`，写死成同样的数字，行为才和框架一致。

380px 就是官方原生默认值。想更宽就把两个 `380px` 一起改掉，**两处要同时改**，不然平板上还是窄的。

另外还有一个不动栏宽的办法：**把侧边栏左右的内边距从 2rem 收到 1rem**，能白捡 32px 给文字，而且完全不挤压正文宽度。

## 改完怎么确认生效

顺序从上到下：

1. **构建一次**，然后刷新页面看目录。
2. **确认样式进了产物**：打开构建输出目录里任意一个 `.html`，搜 `text-overflow`，应该能搜到，并且位置在框架样式之后。
3. **省略号还是不出来，按这个顺序查**：
   - 选择器选中的是不是**真正装着文字的那个元素**？目录里文字常常套在 `<a>` 或 `<span>` 里，给外层 `li` 设 `overflow: hidden` 是没用的。
   - `min-width: 0` 写了吗？（这是最常见的漏项）
   - `white-space: nowrap` 和 `overflow: hidden` 都写了吗？
   - 那条规则是不是被别的、优先级更高的规则盖掉了？浏览器开发者工具里能直接看到哪条生效。

## 不想要了怎么还原

把 `custom.scss` 里对应那一段删掉，重新构建，就回到默认的折行行为。

因为改动全部集中在这一个文件里，插件、框架、配置都没碰，所以还原很干净，不会留后遗症。
