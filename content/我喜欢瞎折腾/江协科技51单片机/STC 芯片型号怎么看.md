# STC 芯片型号怎么看

## 一句话

芯片表面印的那串字就是它的型号（这行字叫**丝印**）。把它按段拆开读，就能知道这颗芯片的供电电压、程序空间、内存大小，以及烧录软件里该选哪一条。

## 逐段拆解 `STC89C52RC`

| 段 | 含义 |
| --- | --- |
| **STC** | 厂商名（宏晶科技，做 8051 兼容单片机的深圳厂商） |
| **89** | 内核系列：8051 内核、片内带 Flash（程序可以直接电擦写，不是要紫外线擦的老式 EPROM） |
| **C** | 供电电压：**5V 版**；写成 **LE** 则是 2.0~3.6V 的低压版 |
| **52** | 程序空间（Flash）大小：**52 对应 8KB**（51=4K、53=13K、54=16K、58=32K、516=64K） |
| **RC** | 内部 RAM 大小：**512 字节**（写 RD+ 的则是 1280 字节） |

连起来读就是：**宏晶 · 8051 内核 Flash 系列 · 5V 供电 · 8KB 程序空间 · 512 字节内存**。

> [!note] 数字是档位代号，不是容量本身
> `52` 不直接等于 8KB，它是厂家定的档位编号，要查表对应。这跟 USB 3.0、DDR4 那种命名一个道理——数字只表示第几档。

## 那一杠后面的 `/LE52RC` 是什么

烧录软件的型号列表里，这一条完整写作 `STC89C52RC/LE52RC`。斜杠后面是它的孪生型号 **STC89LE52RC**。

两者**除了供电电压之外完全相同**——Flash、RAM、定时器、串口、EEPROM 一项不差。因为烧录算法也一样，软件干脆把它们合并成一条。

- 用 USB 的 5V 供电 → 对应前半段 `STC89C52RC`
- 做 3V 电池供电的产品 → 才用后半段 `LE52RC`

> [!tip] 老版本软件里没有这一杠
> 旧版烧录软件里这条就叫 `STC89C52RC`，新版才把低压版合并进来。**指的是同一颗芯片**，照着选就行。教程视频往往用的是旧版软件，所以你看到的列表和自己的不一样——这不是选错了。

## 为什么不能选 `STC89C52`（没有 RC）

列表更下方还有一组老条目：`STC89C51`、`STC89C52`、`STC89C53`，**没有 RC 后缀**。这是更早一代的产品：

- 内部 RAM 更小
- 缺少后来加的增强功能（在线升级、看门狗、双倍速等）
- 烧录时的握手、擦除、校验参数都不一样

名字只差两个字母，但不是同一代东西。选错的表现通常是**一直握不上手**，或者勉强烧进去了但校验失败。

## 怎么确认自己选对了

**看芯片表面的丝印，和下拉框里的名字对得上就行。** 丝印是厂家打在芯片上的，比任何教程截图都可靠。

认准带 `STC` 开头、后面跟数字字母组合的那一行。芯片上通常还有另一行是生产批次（日期、产地代码），那个不是型号。

> [!warning] 型号选错会直接导致下载失败
> 烧录时软件要读芯片内部的 ID 来核对型号，对不上就不进烧录模式。所以如果一直卡在检测阶段，先回头核对这一项（见 [[怎么把程序烧进 51 单片机]]）。
