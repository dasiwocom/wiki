# 链接和图片，外链、页内跳转、本地图片和改尺寸

链接和图片的语法是同一套：**方括号里放文字，圆括号里放地址**。图片只是在前面多加一个感叹号。

## 外部链接

```md
[显示的文字](https://www.runoob.com)
```

↓ 渲染出来是这样：

[显示的文字](https://www.runoob.com)

方括号里是读者看到的文字，圆括号里是点进去的地址。

**别把链接文字写成"点击这里"**——读者扫一眼看到的是"点击这里"，不知道要去哪，复制链接也不方便。写清楚目的地，比如"菜鸟教程的 Markdown 教程"。

## 自动链接

网址直接写在正文里，本站会**自动识别成可点的链接**：

```md
https://www.runoob.com
```

↓ 渲染出来是这样：

https://www.runoob.com

想更明确一点，可以用尖括号包起来，效果一样：

```md
<https://www.runoob.com>
```

## 网址里有空格

空格会把链接截断——渲染器以为网址在空格处就结束了。

两种解决办法：

**换成 `%20`**（空格的 URL 编码）：

```md
[我的文件](https://example.com/my%20file.pdf)
```

**或者用尖括号把整个网址包起来**（更省事）：

```md
[我的文件](<https://example.com/my file.pdf>)
```

## 页内跳转

链接到同一篇笔记的某一节，用 `#` 加那一节的标题：

```md
[跳到自动链接那一节](#自动链接)
```

↓ 渲染出来是这样（点一下试试）：

[跳到自动链接那一节](#自动链接)

标题怎么变成锚点的，见 [[标题怎么用，分级、锚点和页内跳转]]。

**跳到别的笔记的某一节**，用的是 Obsidian 的双链加 `#`，见 [[Obsidian 的双链和嵌入，链接到整篇、章节或某一块]]。

## 站内笔记之间的链接

在这个库里，**优先用双链 `[[笔记名]]`，而不是写文件路径**。

原因：双链会在你改文件名、移动文件时自动跟着更新（Obsidian 帮你改），还能生成反向链接和关系图谱。手写 `.md` 路径的链接则什么都不管。

关于双链的完整用法见 [[Obsidian 的双链和嵌入，链接到整篇、章节或某一块]]。

## 图片：外链图片

外链图片的写法就是链接前面加 `!`：

```md
![图片说明](https://example.com/photo.jpg)
```

方括号里那句话叫**替代文字**（alt text）。它有两个用处：图片加载失败时显示它，屏幕阅读器会把它读给视障用户。**别空着**，写一句简短描述。

## 图片：Obsidian 本地图片

这是 Obsidian 的写法，用两对方括号：

```md
![[照片.png]]
```

前提是这张图已经在你这个库里。通常的做法是直接**拖拽**进笔记，或者**粘贴**——Obsidian 会自动把图片保存到附件目录并写好引用。

附件存哪可以在 Obsidian 设置里改（设置 → 文件与链接 → 附件存放位置）。

> [!tip] 图片路径不用手动管
> 发布时图片会被自动处理并一起输出，你不用在笔记里写相对路径。这也是用 `![[ ]]` 而不是手写 `![](相对路径)` 的好处之一。

## 改图片尺寸

**本地图片**（Obsidian 写法）用竖线加宽度：

```md
![[照片.png|200]]
```

只写宽度的话，高度会按原图比例自动算。

**外链图片**则是 `|宽x高`：

```md
![说明|640x480](https://example.com/photo.jpg)
```

只给宽度也行：`![说明|640](网址)`，高度自动。

> [!warning] 表格里写图片要转义竖线
> 如果在表格单元格里放带尺寸的图片，那个竖线要写成 `\|`，否则表格会被切断。详见 [[表格怎么写，对齐和单元格里的特殊内容]]。

## 图片排版的两件事

**Markdown 里没法控制图片位置**（居中、左浮动、右浮动）。

想居中的话，用 HTML：

```html
<div style="text-align:center">
<img src="图片地址" width="300">
</div>
```

**也没法直接给图片加 caption（图注）**。常见做法是图片下面另起一行写说明，用斜体或者小字：

```md
![[接线图.png]]

*图：这块的接线方式*
```

## 什么时候用链接，什么时候用嵌入

- **链接**：读者需要"跳过去看"，内容留在原地
- **嵌入 `![[ ]]`**：内容直接显示在当前位置，不用跳转

图片基本都是嵌入（你想让读者看到图，而不是看到一个链接）。笔记内容则看情况：想让当前这篇自包含就嵌入，想让读者按需跳转就链接。

## 常见坑

**感叹号写成了中文的**

`！[图片](地址)`（全角感叹号）不会变成图片，会原样显示。

**方括号和圆括号之间没挨着**

`[文字] (地址)`（中间有空格）在部分渲染器下会失效。**紧挨着写**：`[文字](地址)`。

**网址里有中文或特殊字符**

大部分时候能正常显示，但如果出问题，就把网址做 URL 编码，或者用尖括号包起来。

**本地图片改了名字**

Obsidian 里重命名图片会自动更新引用（如果开了"自动更新链接"）。但如果你是在 Obsidian 外面改的文件名，笔记里的 `![[旧名字.png]]` 就会失效，变成找不到图片。

**图片太大**

一张几 MB 的截图会让页面加载变慢。截图能裁剪就裁剪，能用 SVG 画的就用 SVG（见 [[Markdown 做不到的，直接写 HTML]]）。
