# 标题怎么用，分级、锚点和页内跳转

> 系列第 2 / 13 篇 · ← 上一步：[[01-换行到底怎么回事，回车、两空格、空行有什么区别|换行到底怎么回事]] · 下一步：[[03-文字强调：粗体、斜体、删除线、高亮和上下标|文字强调]] → · 路线图：[[Markdown 语法总览]]

标题是 Markdown 里最基础的语法，也是**唯一会自动生成"可跳转地址"的语法**。

换句话说，你写好标题，就等于顺手给这篇笔记做了目录、做好了导航。所以标题不只是"把字放大"，它还决定了别人（和几个月后的你自己）能不能快速找到内容。

## 基本写法

行首写 1 到 6 个 `#`，就是一到六级标题。**`#` 后面必须有空格**，不然它就是普通文字。

```md
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

↓ 渲染出来是这样，字号依次变小：

# 一级标题

## 二级标题

### 三级标题

#### 四级标题

##### 五级标题

###### 六级标题

## 怎么用才不乱

三条经验，都是从"读者能不能看懂结构"出发的：

**一级标题只用一次**，就是笔记名字本身。正文从 `##` 开始。

原因很简单：笔记的标题（文件名）在页面上已经显示成一个大标题了，如果正文里再来一个一级标题，页面上就有两个"最大的标题"，结构会乱。

**别跳级**。二级下面直接写四级，目录里会缺一层，读者会以为漏了内容。

**标题别太长**。它不只是标题，还是网址的一部分（见下面锚点那节），太长的标题会让链接变得又臭又长。

## 目录是自动生成的

这一点对新手很重要：**你不需要手写目录。**

- Obsidian 里有"大纲"面板，实时显示当前笔记的标题结构
- 这个站点的目录在页面右侧（窄屏时移到正文上方），点一下就能跳

两边都是**读取你写的标题**自动生成的，所以只要标题写得规范，目录就自动是好的。

## 锚点：每个标题都有一个地址

这是标题最有用的隐藏属性。

生成网页时，每个标题都会被自动分配一个 `id`，这个 id 就叫**锚点**。有了它，你就能直接链接到某一节，而不是"链接到这篇笔记然后让读者自己找"。

这个站点的锚点规则（实测）：

| 标题 | 生成的锚点 |
| --- | --- |
| `## 怎么用才不乱` | `#怎么用才不乱` |
| `## 基本写法` | `#基本写法` |

中文标题**直接用标题文字本身**，不用转拼音、不用加连字符。

英文标题则会做规范化：**大写转小写、空格换成连字符、标点去掉**。实测 `## How To Use English Title` 生成的锚点是 `#how-to-use-english-title`。

## 页内跳转

知道锚点之后，就能做页内跳转了：

```md
[跳到锚点那一节](#锚点：每个标题都有一个地址)
```

↓ 渲染出来是这样（点一下试试）：

[跳到锚点那一节](#锚点：每个标题都有一个地址)

写法就是 `[任意文字](#锚点)`。中间的空格和标点照抄标题原文就行。

**跳到别的笔记的某一节**，用 Obsidian 的双链加 `#`：

```md
[[换行到底怎么回事，回车、两空格、空行有什么区别#三种写法，三种结果]]
```

这样点进去会直接定位到那一节，而不是从笔记开头读起。双链的更多用法见 [[09-Obsidian 的双链和嵌入，链接到整篇、章节或某一块|双链和嵌入]]。

## 标题里能用什么

技术上，标题里可以加粗体、代码、链接：

```md
## 关于 `P2 = 0xFE` 这件事
```

但**不推荐**——标题里的格式在不同渲染器下表现不一致，而且它会出现在目录里，带格式的目录看起来很乱。

标题里也尽量避免这些符号：

- `#` 开头（会被当成更高级标题）
- 结尾跟着一串 `#`（有些渲染器会把它们当成"闭合标记"给吃掉）
- `?` `:` 这类字符——虽然标题里能用，但如果这个标题同时也是文件名，Windows 不允许

## 常见坑

**`#` 后面忘了空格**

`#标题` 不会变成标题，`# 标题` 才会。这是新手最常犯的错。

**`#` 前面多了空格**

Markdown 里，行首四个空格是"代码块"的意思。所以 `  ## 标题` 有可能被当成代码块，而不是标题。标题一定要顶格写。

**标题前后没空行**

紧贴着上一段写标题，有时候不会生效。养成习惯：**标题上下都空一行**。

**用标题来调整字号**

有人发现"三级标题的字号刚好合适"，就用标题当大字用。别这么干——它会污染目录，也会让读者以为这里开始了一个新话题。想强调一句话，用加粗就够了，见 [[03-文字强调：粗体、斜体、删除线、高亮和上下标|文字强调]]。
