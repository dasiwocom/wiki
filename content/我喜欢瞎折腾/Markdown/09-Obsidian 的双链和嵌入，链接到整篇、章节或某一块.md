# Obsidian 的双链和嵌入，链接到整篇、章节或某一块

> 系列第 9 / 13 篇 · ← 上一步：[[08-Callout 提示块，全部类型、折叠和嵌套|Callout 提示块]] · 下一步：[[10-Frontmatter 属性区和标签|Frontmatter 属性区]] → · 路线图：[[Markdown 语法总览]]

双链 `[[ ]]` 是 Obsidian 最核心的语法，也是它和普通 Markdown 编辑器最大的区别。

普通的链接是"给个网址让你跳过去"；双链是"我知道库里有这篇笔记，直接指过去"。你不用写路径、不用管文件在哪——**写笔记名就行**。

## 基本写法

两对方括号，里面写笔记的**文件名**，不用带 `.md`：

```md
[[01-换行到底怎么回事，回车、两空格、空行有什么区别|换行到底怎么回事]]
```

↓ 渲染出来是这样（点一下会跳到那篇）：

[[01-换行到底怎么回事，回车、两空格、空行有什么区别|换行到底怎么回事]]

几个好处：

- 不用写路径，文件挪到别的文件夹也不会断
- 改名时 Obsidian 会自动更新所有引用它的链接
- 这个站点会**自动生成反向链接**（哪几篇提到了这篇）和关系图谱

## 四种写法

| 想要什么 | 写法 |
| --- | --- |
| 链接整篇 | `[[笔记名]]` |
| 改显示文字 | `[[笔记名\|想显示的文字]]` |
| 链接到某一节 | `[[笔记名#小节标题]]` |
| 链接到某一段 | `[[笔记名#^块编号]]` |

### 改显示文字

有时候笔记名很长，直接显示在正文里很啰嗦。用竖线改掉：

```md
[[07-表格怎么写，对齐和单元格里的特殊内容|表格那篇]]
```

↓ 渲染出来是这样：

[[07-表格怎么写，对齐和单元格里的特殊内容|表格那篇]]

读者看到的是竖线后面的文字，点进去还是那篇笔记。

### 链接到某一节

加 `#` 和那一节的标题：

```md
[[换行到底怎么回事，回车、两空格、空行有什么区别#三种写法，三种结果]]
```

↓ 渲染出来是这样：

[[换行到底怎么回事，回车、两空格、空行有什么区别#三种写法，三种结果]]

点进去会**直接定位到那一节**，而不是从笔记开头读起。这个在引用长笔记的某个细节时特别有用。

### 链接到某一段（块 ID）

如果连"某一节"都太大，可以精确到**某一段**。

第一步，在你想被引用的那一段末尾，写一个 `^` 加自定义编号：

```md
这是我想被引用的一段话。 ^重要结论
```

那个 `^重要结论` 在页面上**看不见**，它只是个标记。

第二步，在别处引用它：

```md
[[某篇笔记#^重要结论]]
```

好处是：**就算以后标题改了、段落挪了位置，链接依然指向这段话**。因为它绑的是段落本身，不是标题文字。

## 嵌入：把内容搬过来

双链前面加一个 `!`，就不是"跳过去"，而是**把内容显示在当前位置**：

| 写法 | 效果 |
| --- | --- |
| `![[笔记名]]` | 整篇笔记的内容显示在这里 |
| `![[笔记名#小节]]` | 只显示那一节 |
| `![[笔记名#^块编号]]` | 只显示那一段 |
| `![[图片.png]]` | 显示图片 |

嵌入适合用在"这一段内容在别处写过，我不想复制一遍"的场合——改了原笔记，所有嵌入它的地方会跟着变。

不过要小心：**嵌入太多会让笔记变成一堆碎片的拼贴**，读起来没有连贯性。能用一两句话说明白的，就自己写。

> [!warning] 这个站点不支持的嵌入
> 嵌入 **HTML 文件**（`![[xxx.html]]`）在这个站点是关掉的，写了不会显示。视频也一样，别用 `![[xxx.mp4]]`，改用 `<iframe>` 嵌站外播放器，写法见 [[12-Markdown 做不到的，直接写 HTML|直接写 HTML]]。

## 双链和 Markdown 链接的区别

同一个笔记库里，其实两种写法都能用：

```md
[[笔记名]]
[笔记名](笔记名.md)
```

用双链的理由：

- 改名、移动文件时链接自动跟着变
- 参与反向链接和图谱统计
- 写起来短

用 Markdown 链接的理由：

- 兼容性好，换到别的 Markdown 编辑器也能用
- 可以链接到库外的文件

**在这个库里，默认用双链。**

## 常见坑

**笔记名写错一个字**

链接会变成"指向一篇不存在的笔记"。在这个站点上它显示为红色虚线（点进去是 404），Obsidian 里会提示你创建新笔记。

**竖线忘了转义**

在**表格**里写带别名的双链，那个竖线会被当成"分列"，表格会多出一列。要写成 `\|`：

```md
| 链接 | 说明 |
| --- | --- |
| [[笔记名\|别名]] | 这样才对 |
```

**标题里有特殊字符**

`#` 里写标题时，要和原标题**完全一致**，包括标点。中文标题里的全角逗号、`？` 这些都要照抄。

**块 ID 重复**

同一个编号在两处都用了，链接会指向其中一个（通常是第一个）。编号起得具体一点就不会撞。

**块 ID 写在了列表或表格里**

块 ID 必须跟在一个**段落**后面才生效。写在一行文字末尾，前面要有空格。
