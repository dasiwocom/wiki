# PHP 是什么，代码为什么要在服务器上跑

这一篇不写几行代码，先把最大的那个障碍解决掉：PHP 不能像 HTML 那样双击打开就看见效果。

## PHP 和前面三样东西，根本区别在哪

HTML、CSS、JavaScript 有个共同点：**它们最终都在你自己这台电脑的浏览器里跑。** 网页传过来，浏览器负责解释它、画出来、听你点鼠标。

PHP 不是。PHP 跑在**服务器**上——那台一天到晚不关机的电脑。

| | 在哪跑 | 谁看得见源码 |
| --- | --- | --- |
| HTML / CSS / JS | 你的浏览器 | 看得见（右键"查看源代码"就是） |
| PHP | 服务器 | 看不见，浏览器只拿到它算出来的结果 |

这个差别带来一个直接后果：**用户永远看不到 PHP 源码。** 这也是后台代码能放心写数据库密码的原因。

## 一个页面从地址栏到屏幕，中间发生了什么

```mermaid
flowchart LR
  A["你在地址栏<br/>敲下网址"] --> B["服务器收到请求"]
  B --> C["PHP 解释器<br/>执行 .php 文件"]
  C --> D["生成纯 HTML"]
  D --> E["发回浏览器"]
  E --> F["浏览器渲染<br/>你看到页面"]
```

关键在 C 到 D 这一步：**PHP 的任务是"生成 HTML"。** 它自己不是页面，它是一台造页面的机器。

所以你写一个 `index.php`，里面可能有查询数据库、算数字、判断登录状态——做完之后吐出来的只有一段干净的 HTML。浏览器从头到尾不知道你用了 PHP。

## 双击 `.php` 文件会发生什么

只会看到一堆代码文本。

因为你电脑上没有一个解释它的程序，系统只能当成普通文本文件打开。更麻烦的是：如果你把它放进网站目录、用浏览器直接访问，**浏览器会把它当纯文本原样显示出来**——包括里面的数据库密码。

所以 PHP 文件必须由服务器交给 PHP 解释器执行，不能直接打开。

## 怎么在自己电脑上跑起来

三条路，按"从简到全"排。学语法用第一条就够，做表单和数据库必须用第三条。

### ① 在线沙箱：不动自己电脑

把代码贴进网页里就能跑，最快。

- [菜鸟教程在线编辑器（PHP）](https://www.runoob.com/try/runcode.php?filename=demo_intro&type=php)
- [3v4l.org](https://3v4l.org/)：同一个片段在所有 PHP 版本上跑一遍，看兼容性很有用
- [onlinephp.io](https://onlinephp.io/)

**但它的限制很大**，而且这些限制恰好挡住了后面一半的内容：

- 不能读写文件（第 16 篇的文件和上传做不了）
- 不能设 Cookie、不能用 session（第 14 篇做不了）
- 连不上数据库（第 19 篇做不了）
- 页面一刷新，状态就没了
- 你在浏览器里访问不到那个脚本，只能看它打印出来的结果（第 12 篇的表单跳转做不了）

所以：**在线沙箱只适合练语法，到第三阶段就必须装本地环境。**

### ② 装 PHP 本体，用它自带的小服务器

PHP 官方从 5.4 起自带一个开发用服务器，够用来学。

1. 到 [windows.php.net/download](https://windows.php.net/download/) 下载 Windows 版 PHP 的 zip（选 **Thread Safe** 那个）。注意别下成源码包。
2. 解压到一个没空格、没中文的目录，比如 `C:\php`。
3. 把这个目录加进系统的 `PATH`（Windows 设置里搜"环境变量"）。
4. 打开终端，进到你的代码目录，运行：

```bash
cd C:\mycode
php -S localhost:8000
```

5. 浏览器打开 `http://localhost:8000/index.php`。

命令行里会打印每一个请求，出问题的时候很有用。

**只想试一小段纯计算代码**，还可以不用服务器：

```bash
php test.php
```

结果直接打在终端里。学第 3～10 篇的时候这样最省事。

### ③ 一体化环境：Apache + PHP + MySQL 打包

做表单一类、要连数据库的时候得用它。装完就有 `Apache`、`PHP`、`MySQL` 三样，还带图形化的管理界面。

- **XAMPP**：[apachefriends.org](https://www.apachefriends.org/zh_cn/index.html)，装完把文件放进 `htdocs` 目录，在控制面板点 Start
- **phpStudy（小皮）**：[xp.cn](https://www.xp.cn/)，中文界面，国内用得多，切换 PHP 版本很方便

用它的规矩就一条：**你的 `.php` 文件必须放在它指定的网站根目录下**（XAMPP 是 `htdocs`），然后通过 `http://localhost/文件名.php` 访问，而不是双击文件。

## PHP 现在是什么版本

**8.5**（当前稳定版）。8.4 和 8.5 都在积极维护中。

一个要注意的事：网上很多 PHP 教程是 PHP 5 时代写的，里面的写法和现在差得很多（老教程里能看到 `mysql_` 开头的函数，那些在 PHP 7 就被删了）。**看到带 `mysql_query` 的文章，直接换一篇。**

这一组笔记里的写法，PHP 8 及以上都能跑；用到 8.1、8.2 才有的特性时（比如枚举、`readonly`），会单独标出来。

## PHP 现在还在用吗

用得很凶。WordPress、维基百科的 MediaWiki、早期的 Facebook，都是 PHP 写的。它撑起了相当大一部分网站的服务器端。

对新手来说它的好处很直接：**不用装框架、不用学构建工具，写一个文件放进目录就是一个能访问的页面。** 这一点在所有后端语言里是最低的门槛。

## 一个最小的例子

新建 `hello.php`：

```php
<?php
$name = "小明";
$hour = (int) date("G");

if ($hour < 12) {
    $greeting = "早上好";
} else {
    $greeting = "下午好";
}

echo "<h1>{$greeting}，{$name}</h1>";
echo "<p>现在的时间是 " . date("H:i:s") . "</p>";
```

访问这个文件，页面上会显示：

```text
早上好，小明

现在的时间是 09:14:22
```

这里有四件后面每篇都会重复出现的事：

- **`<?php` 开头**，代码写在里面
- **`$` 开头的变量**，不用声明类型，直接赋值就能用
- **`echo` 把内容送到页面**，可以写 HTML 标签，浏览器会正常渲染
- **字符串里 `{$变量}` 会被替换成它的值**，这是双引号的特性，第 2 篇细讲

顺手改一下 `$name` 的值、改一下判断的小时数，刷新看看变化。这一步做完，后面就顺了。
