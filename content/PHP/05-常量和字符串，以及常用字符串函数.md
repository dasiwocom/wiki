# 常量和字符串，以及常用字符串函数

## 常量：定了就不能改

```php
<?php
const SITE_NAME = "我的小站";
define("MAX_SIZE", 2 * 1024 * 1024);

echo SITE_NAME;
echo MAX_SIZE;
```

```text
我的小站2097152
```

两种写法都能定义常量，区别在于：

| | `const` | `define()` |
| --- | --- | --- |
| 能不能写在 `if` 里 | 不能 | 能 |
| 能不能用表达式 | 可以（编译时就定） | 可以 |
| 能不能定义在类里 | 能 | 不能 |
| 常不常用 | 现在推荐 | 老代码里多见 |

**一般用 `const`。** 只有在"条件性地定义一个常量"时才需要 `define()`。

和变量的差别：

- 前面**没有 `$`**
- **定义后不能改**，也不 `unset`
- **在任何地方都能用**，函数里面不用 `global`（这是它比变量方便的地方）
- 按惯例名字全大写

常量最适合放这类东西：站点名称、每页条数、允许的图片类型、API 地址。放在文件开头，以后要改只改一个地方。

## 几个"自带"的常量

PHP 预定义了一批常量，其中这四个在写文件路径的时候天天用：

```php
<?php
echo __FILE__;      // 当前文件的完整路径
echo __DIR__;       // 当前文件所在的目录
echo __LINE__;      // 当前这一行的行号
echo PHP_VERSION;   // 比如 8.5.10
echo PHP_EOL;       // 当前系统的换行符（Windows 是 \r\n）
```

实际用法：

```php
<?php
// 无论在哪个目录下启动，路径都是对的
require __DIR__ . "/config.php";

$logFile = __DIR__ . "/logs/app.log";
```

**用 `__DIR__` 拼路径，不要用相对路径。**相对路径是相对"当前工作目录"算的，而当前工作目录取决于你从哪儿启动的命令、服务器怎么配的——换个环境就找不到文件了。这个坑在 include、读文件、写日志的时候最常见。

`__DIR__`、`__FILE__` 这类叫魔术常量，名字是双下划线开头结尾的。

## 字符串：长度和大小写

```php
<?php
$s = "Hello";
echo strlen($s);          // 5
echo strtoupper($s);      // HELLO
echo strtolower($s);      // hello
echo ucfirst($s);         // Hello
echo ucwords("hello world");   // Hello World
```

**中文要小心 `strlen`：**

```php
<?php
$name = "小明";

echo strlen($name);        // 6  —— 按字节算，一个汉字 3 字节
echo mb_strlen($name);     // 2  —— 按字符算，这才是你要的
```

凡是和中文打交道的函数，基本都有个 `mb_` 开头的版本（mb = multi-byte，多字节）：

| 按字节（中文会出错） | 按字符（中文正确） |
| --- | --- |
| `strlen($s)` | `mb_strlen($s)` |
| `substr($s, 0, 3)` | `mb_substr($s, 0, 3)` |
| `strtoupper($s)` | `mb_strtoupper($s)` |
| `str_split($s)` | `mb_str_split($s)` |

**项目里只要有中文，就用 `mb_` 版本。** 想省事可以在入口文件设一次默认编码：

```php
<?php
mb_internal_encoding("UTF-8");
```

## 截取

```php
<?php
$s = "abcdef";

echo substr($s, 0, 3);     // abc
echo substr($s, 2);        // cdef
echo substr($s, -2);       // ef   负数表示从末尾数
echo mb_substr("今天天气很好", 0, 2);   // 今天
```

`substr` 的第 2 个参数是起点，第 3 个是长度（不写就是到末尾）。

## 查找和替换

```php
<?php
$s = "我是一个 PHP 教程";

var_dump(strpos($s, "PHP"));        // int(11)
var_dump(strpos($s, "Java"));       // bool(false)

echo str_replace("PHP", "JavaScript", $s);   // 我是一个 JavaScript 教程
echo str_repeat("=", 20);                    // ====================
```

**`strpos` 最大的坑在这里：**

```php
<?php
$s = "abc";

// 错：如果匹配到开头，返回 0，0 在判断里是假
if (strpos($s, "a")) {
    echo "找到了";
} else {
    echo "没找到";     // 会走这里，但其实是找到了
}

// 对：用 !== false
if (strpos($s, "a") !== false) {
    echo "找到了";
}
```

**判断 `strpos` 的结果，只能用 `!== false` 或 `=== false`，不能直接当条件用。**

PHP 8 加了三个更好用的函数，语义清楚得多：

```php
<?php
if (str_contains($s, "a")) { }        // 包含
if (str_starts_with($s, "ab")) { }    // 以…开头
if (str_ends_with($s, "bc")) { }      // 以…结尾
```

新代码优先用这三个。

## 拆分和拼接

```php
<?php
$line = "张三,男,18";
$parts = explode(",", $line);
print_r($parts);

$arr = ["苹果", "香蕉", "橘子"];
echo implode("、", $arr);
```

```text
Array
(
    [0] => 张三
    [1] => 男
    [2] => 18
)
苹果、香蕉、橘子
```

`explode` 拆成数组，`implode` 合成字符串——这两个是一对，来回转换的时候用。读 CSV 文件、拼 SQL 的 `IN (...)` 都会用到。

## 清理多余空白

```php
<?php
$s = "  小明  ";

echo trim($s);          // "小明"   两头都去
echo ltrim($s);         // "小明  " 只去左
echo rtrim($s);         // "  小明" 只去右
```

用户复制粘贴进来的内容经常带空格和换行，**收到任何输入先 `trim()` 一下**，能省掉大量"两个值明明一样却不相等"的怪事。第二个参数可以指定要去的字符集合：

```php
<?php
echo trim("###标题###", "#");    // 标题
```

## 格式化输出

```php
<?php
$price = 1234.5;

echo number_format($price, 2);         // 1,234.50
echo number_format($price, 2, ".", ""); // 1234.50
printf("商品：%s，价格：%.2f 元", "键盘", $price);
$str = sprintf("%05d", 42);            // 00042
```

`number_format` 专门给金额用，自动加千位分隔符。`sprintf` 把格式化的结果**返回成字符串**，`printf` 是**直接输出**——需要拿到结果再处理的时候用 `sprintf`。

## 输出到 HTML 前的处理

```php
<?php
$userInput = "<b>加粗</b><script>alert(1)</script>";

echo htmlspecialchars($userInput);   // 原样显示标签文字，不执行
echo strip_tags($userInput);         // 把标签全删掉，只留文字
echo nl2br($userInput);              // 把换行符变成 <br>
```

三个各管一件事：

- **`htmlspecialchars`**：把 `<` `>` `&` `"` 转成实体，页面显示为文字。**只要往页面输出用户给的内容，就用它。**
- **`strip_tags`**：直接删掉所有标签。用在"只想要纯文本"的场合。
- **`nl2br`**：用户在多行文本框里敲的回车，在 HTML 里是不换行的，用它补上 `<br>`。

**`strip_tags` 不能当安全手段用**，它删得不够干净。要防注入，靠的是 `htmlspecialchars`（输出时）和预处理语句（写数据库时）。

## 密码：`md5` 是错的

```php
<?php
// 不要这样写
$hash = md5($password);
```

`md5` 和 `sha1` 是"算得特别快"的算法，正好帮了暴力破解的忙——一台普通电脑每秒能算上亿次。而且不加盐的话，同样的密码算出来永远一样，一张彩虹表就能反查。

正确做法：

```php
<?php
// 存的时候
$hash = password_hash($password, PASSWORD_DEFAULT);

// 登录校验的时候
if (password_verify($inputPassword, $hash)) {
    echo "登录成功";
}
```

`password_hash` 每次都会生成不同的盐，`password_verify` 负责比对。**存密码只有这一种正确写法**，`md5` 在任何场合都不该再出现在和密码有关的代码里。

## 一个例子

```php
<?php
const MAX_LEN = 10;

$input = "  我是一个很长的中文标题，超出限制了  ";

$text = trim($input);

if (mb_strlen($text) > MAX_LEN) {
    echo mb_substr($text, 0, MAX_LEN) . "…";
} else {
    echo $text;
}

echo PHP_EOL;
echo "原长度：" . mb_strlen($text) . " 字";
```

```text
我是一个很长的中文标题，…
原长度：16 字
```
