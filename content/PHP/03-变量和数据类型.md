# 变量和数据类型

## 变量就是一个带标签的盒子

```php
<?php
$name = "小明";
$age = 18;
$price = 199.5;
$isVip = true;

echo $name;
```

`$` 后面跟名字，等号把右边的东西放进这个盒子里。

三条规矩：

- 名字**只能**用字母、数字、下划线，且不能用数字开头
- **区分大小写**，`$name` 和 `$Name` 是两个变量
- 名字起得有信息量，`$userName` 比 `$a` 强，因为三个月后你还会回来看这段代码

## 不用声明类型，是方便也是陷阱

在 C、Java 里你要写 `int age = 18;`。PHP 不用：

```php
<?php
$x = 18;
var_dump($x);

$x = "十八";
var_dump($x);

$x = [1, 2, 3];
var_dump($x);
```

```text
int(18)
string(6) "十八"
array(3) { [0]=> int(1) [1]=> int(2) [2]=> int(3) }
```

同一个变量，先装数字、再装字符串、再装数组，都合法。

**代价是：类型错误不会在你写代码的时候被发现，只会在跑起来的时候暴露。** PHP 7.4 起可以在函数参数和返回值上写类型（第 10 篇讲），大型项目里基本都会写。

## 八种类型

| 类型名 | 写法 | 例子 |
| --- | --- | --- |
| int 整数 | 直接写 | `18`、`-3`、`0` |
| float 浮点 | 带小数点 | `199.5`、`1.2e3` |
| string 字符串 | 引号包起来 | `"你好"`、`'abc'` |
| bool 布尔 | `true` / `false` | `true` |
| array 数组 | 方括号 | `[1, 2]`、`["a" => 1]` |
| object 对象 | `new` 出来 | `new DateTime()` |
| null 空 | 就写 `null` | `null` |
| resource 资源 | 系统给的句柄 | 打开的文件、数据库连接 |

日常写业务代码，前六种就够用了。

## 看类型和转类型

```php
<?php
$x = "18";
var_dump($x);        // string(2) "18"
var_dump($x + 1);    // int(19) —— 字符串自动变成了数字
var_dump((int) $x);  // int(18) —— 手动转
```

括号里写类型名，叫强制转换：

```php
<?php
$price = "199.5 元";
var_dump((float) $price);    // float(199.5)
var_dump((int) $price);      // int(199)
var_dump((string) 18);       // string(2) "18"
var_dump((bool) "");         // bool(false)
var_dump((bool) "0");        // bool(false) —— "0" 是假
var_dump((bool) "abc");      // bool(true)
```

**哪些值会被当成假**，这张表要记住，写 `if` 的时候天天用：

| 这些是假（false） | 这些是真（true） |
| --- | --- |
| `false` | `true` |
| `0`、`0.0` | 任何非 0 的数 |
| `""`、`"0"` | 任何其他非空字符串 |
| `[]` 空数组 | 有内容的数组 |
| `null` | — |

注意 `"0"` 是假、`"0.0"` 是真，这种细节只有 PHP 有，写代码时不要依赖它们，明确用 `===` 判断更稳。

`(int)` 直接砍掉小数部分，不四舍五入：

```php
<?php
var_dump((int) 9.9);      // int(9)
var_dump(round(9.9));     // float(10)
var_dump(intdiv(10, 3));  // int(3) —— 整数除法
```

`round()` 四舍五入，`intdiv()` 整数相除，三个不一样，需要哪个用哪个。

## `isset`、`empty`、`is_null` 怎么选

三个都在问"这个东西有没有值"，但问题不一样。

```php
<?php
$arr = ["a" => 0, "b" => "", "c" => null];

var_dump(isset($arr["a"]));   // true  —— 键存在，值是 0
var_dump(isset($arr["c"]));   // false —— 值是 null，isset 说"没有"
var_dump(isset($arr["z"]));   // false —— 键都不存在

var_dump(empty($arr["a"]));   // true  —— 0 被当成空
var_dump(empty($arr["b"]));   // true  —— "" 被当成空
var_dump(empty($arr["c"]));   // true

var_dump(is_null($arr["c"])); // true
```

分工是这样：

- **`isset($x)`**：变量存在且不是 `null`。用来"这个变量有没有被给值"，比如接表单参数。它对不存在的变量**不报错**，这是它最常用的原因。
- **`empty($x)`**：变量不存在，或者是上面那张"假"表里的值。用在"这个字段填了没有"。
- **`is_null($x)`**：严格判断是不是 `null`。

一个常见的组合：表单里的"可选字段"和"填了 0"要区分开，就得用 `isset`；只想知道"有没有内容"，用 `empty`。

```php
<?php
// 接一个网址参数，没传就用默认值（第 4 篇的 ?? 是同一件事的更短写法）
if (isset($_GET["page"])) {
    $page = (int) $_GET["page"];
} else {
    $page = 1;
}
```

## 变量的引用：两个名字指同一个盒子

```php
<?php
$a = "苹果";
$b = $a;
$b = "香蕉";

echo $a;    // 苹果 —— $b 改了不影响 $a
```

加一个 `&` 就变成同一个盒子：

```php
<?php
$a = "苹果";
$b = &$a;
$b = "香蕉";

echo $a;    // 香蕉 —— 改 $b 就是改 $a
```

这叫引用。日常用得少，主要在函数参数里出现（第 10 篇），或者用 `sort()` 这类"直接改原数组"的函数时才会碰到。

想删掉一个变量：

```php
<?php
$tmp = "临时";
unset($tmp);
echo $tmp;    // 报错：Undefined variable
```

## 一个能用的例子

```php
<?php
// 模拟从表单收到的数据，全是字符串
$input = ["name" => "小明", "age" => "18", "vip" => "1", "email" => ""];

$name  = trim((string) $input["name"]);
$age   = (int) $input["age"];
$isVip = !empty($input["vip"]);
$email = empty($input["email"]) ? "未填写" : $input["email"];

echo "姓名：{$name}<br>";
echo "年龄：{$age} 岁，明年 " . ($age + 1) . " 岁<br>";
echo "会员：{$isVip}<br>";
echo "邮箱：{$email}";
```

```text
姓名：小明
年龄：18 岁，明年 19 岁
会员：1
邮箱：未填写
```

这段里有三件事值得注意：

- **表单传来的东西永远是字符串。** `"18"` 要参与计算就得先 `(int)` 转，不然和别的数字比较时行为可能不像你想的那样（第 4 篇专门讲这个）。
- `trim()` 去掉两头的空格。用户复制粘贴进来的内容经常带空格，这是最常见的一类"看起来一样但不相等"。
- `!empty($input["vip"])` 把 `"1"` 变成布尔真。表单里的复选框没勾选时**根本不会出现在数据里**，所以必须用 `empty` 而不是 `=== "1"`。
