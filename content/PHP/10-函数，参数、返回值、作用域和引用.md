# 函数，参数、返回值、作用域和引用

## 为什么要写函数

一段代码在三个地方重复出现，改的时候就容易漏掉一处。函数就是把这段代码打包起来，起个名字，以后用名字叫它。

```php
<?php
function sayHello() {
    echo "你好";
}

sayHello();
sayHello();
```

```text
你好你好
```

`function` 开头，函数名后面跟一对括号，花括号里是做什么。**函数名不区分大小写**（`sayHello()` 和 `sayhello()` 都行），但还是照原样写。

## 参数：把数据传进去

```php
<?php
function greet($name) {
    echo "你好，{$name}";
}

greet("小明");
```

```text
你好，小明
```

### 默认值

```php
<?php
function greet($name, $greeting = "你好") {
    return "{$greeting}，{$name}";
}

echo greet("小明");
echo greet("小明", "早上好");
```

```text
你好，小明早上好，小明
```

**带默认值的参数要放在后面。** `function f($a = 1, $b)` 是没意义的，PHP 现在会直接报错。

### 类型声明

可以在参数前面写上要求的类型，传错会直接报错：

```php
<?php
function add(int $a, int $b): int {
    return $a + $b;
}

echo add(3, 4);     // 7
```

冒号后面那个是**返回类型**。想让参数可以为 null，前面加问号：

```php
<?php
function show(?string $name): string {
    return $name ?? "匿名";
}
```

类型声明能帮你早点发现错误。不过要注意：**PHP 默认会做"宽松"转换**，传字符串 `"3"` 给 `int $a` 是允许的。想严格一点，在文件最上面加一行：

```php
<?php
declare(strict_types=1);
```

加了这个之后，`add("3", 4)` 会直接报错而不是偷偷转换。新项目建议加上。

### 可变参数

参数个数不确定的时候：

```php
<?php
function sum(...$nums) {
    return array_sum($nums);
}

echo sum(1, 2, 3);        // 6
echo sum(1, 2, 3, 4, 5);  // 15
```

`...` 把传进来的所有参数收成一个数组。反过来，把一个数组"摊开"传进去也是 `...`：

```php
<?php
$list = [1, 2, 3];
echo sum(...$list);       // 6
```

### 命名参数

PHP 8 起，可以按参数名传，不用管顺序：

```php
<?php
function createUser($name, $age = 18, $city = "杭州") {
    return "{$name}，{$age} 岁，{$city}";
}

echo createUser("小明", city: "北京");
```

```text
小明，18 岁，北京
```

参数多且都有默认值的时候很有用——不用为了传最后一个参数而把中间的都写一遍。

## 返回值

```php
<?php
function add($a, $b) {
    return $a + $b;
}

$result = add(3, 4);
echo $result;
```

```text
7
```

三件事：

- **`return` 之后函数立刻结束**，后面的代码不执行
- **不写 `return` 的函数返回 `null`**
- **函数里 `echo` 出来的东西会直接进页面**，和 `return` 完全是两回事

最后一条特别容易搞混：

```php
<?php
// 这个函数会立刻把内容打到页面上
function bad() {
    echo "你好";
}

// 这个是"算出结果交出去"，结果由调用方决定怎么用
function good() {
    return "你好";
}

$text = good();          // 页面上什么都没出现
$text = bad();           // 页面上出现了"你好"，$text 是 null
```

**函数应该 `return`，把"输出"这件事留给调用它的地方。** 这样函数才能被复用在别处（比如把结果写进文件、拼进 JSON）。

想一次返回多个值，返回数组：

```php
<?php
function stats(array $nums): array {
    return [
        "sum" => array_sum($nums),
        "avg" => array_sum($nums) / count($nums),
        "max" => max($nums),
    ];
}

["sum" => $sum, "avg" => $avg] = stats([1, 2, 3, 4]);
echo "合计 {$sum}，平均 {$avg}";
```

```text
合计 10，平均 2.5
```

配合第 9 篇的解构，用起来很顺。

## 作用域：函数里面看不见外面

```php
<?php
$siteName = "我的小站";

function showTitle() {
    echo $siteName;      // 报错：Undefined variable $siteName
}
```

**函数内部和外部是两个世界。** 外面的变量默认进不来。这叫作用域。

想用外面的变量，得用 `global` 声明：

```php
<?php
$count = 0;

function addCount() {
    global $count;
    $count++;
}

addCount();
addCount();
echo $count;    // 2
```

`global` 能不用就不用。它让"这个变量被谁改了"变得很难追——函数看起来只吃参数、只吐返回值，其实偷偷改了外面。**正确做法是把值当参数传进去、把结果 return 出来：**

```php
<?php
$count = 0;

function plusOne($n) {
    return $n + 1;
}

$count = plusOne($count);
$count = plusOne($count);
```

### static：只初始化一次的变量

```php
<?php
function counter() {
    static $n = 0;
    $n++;
    echo $n . " ";
}

counter();
counter();
counter();
```

```text
1 2 3
```

`static` 变量在函数第一次调用时初始化，之后每次调用都保留上次的值。用在"记住这个函数被调了几次""缓存一个算起来很贵的结果"这类场合。

不过它同样有"藏状态"的毛病，能不用也尽量不用。

## 引用传参

默认情况下，函数拿到的是参数的**副本**，改它不影响外面：

```php
<?php
function wrong($n) {
    $n = $n + 1;
}

$x = 1;
wrong($x);
echo $x;     // 1
```

参数前面加 `&` 就是同一个盒子：

```php
<?php
function right(&$n) {
    $n = $n + 1;
}

$x = 1;
right($x);
echo $x;     // 2
```

**引用传参要慎用。** 看 `right($x)` 这一行，你完全不知道 `$x` 会被改。PHP 内置的 `sort()`、`array_push()` 就是这种风格，所以要记住"哪些函数会改原变量"。

## 闭包和箭头函数

有时候要把一小段逻辑当"值"传出去，比如第 9 篇的 `usort`、`array_map`。

### 箭头函数

```php
<?php
$double = fn($n) => $n * 2;
echo $double(5);      // 10
```

只能写**一个表达式**，自动 `return` 这个表达式的值。它会**自动把外层的变量带进来**：

```php
<?php
$rate = 0.8;
$discount = fn($price) => $price * $rate;   // 直接用外面的 $rate，不用声明
echo $discount(100);   // 80
```

这一条让它特别适合放在 `array_map` 里面：

```php
<?php
$prices = [100, 200, 300];
$discounted = array_map(fn($p) => $p * $rate, $prices);
```

### 普通闭包

需要写多行、或者要引用改变外部变量的时候，用 `function`：

```php
<?php
$rate = 0.8;

$fn = function ($price) use ($rate) {
    $label = $price > 200 ? "高价" : "普通";
    return $price * $rate . "（{$label}）";
};

echo $fn(300);
```

```text
240（高价）
```

区别就一条：**普通闭包要用 `use ($变量)` 把外面的变量带进来，箭头函数不用。**

想在闭包里改外面的变量，`use (&$变量)`：

```php
<?php
$total = 0;
$add = function ($n) use (&$total) {
    $total += $n;
};

$add(10);
$add(5);
echo $total;    // 15
```

## 提前返回，别往右缩

```php
<?php
// 不好读
function check($user) {
    if ($user) {
        if ($user["active"]) {
            return "通过";
        } else {
            return "未激活";
        }
    } else {
        return "不存在";
    }
}
```

```php
<?php
// 好读
function check($user) {
    if (!$user) {
        return "不存在";
    }
    if (!$user["active"]) {
        return "未激活";
    }
    return "通过";
}
```

条件反着写，"不满足"的情况先赶走。第 6 篇讲过这个，函数里用得最多。

## 一个完整的例子

```php
<?php
const TAX_RATE = 0.06;

/**
 * 算一个商品列表的总价
 */
function totalPrice(array $items, float $rate = TAX_RATE): array {
    $subtotal = 0;

    foreach ($items as $item) {
        // 价格缺失或为负数的直接跳过
        if (!isset($item["price"]) || $item["price"] < 0) {
            continue;
        }
        $subtotal += $item["price"] * ($item["num"] ?? 1);
    }

    $tax = $subtotal * $rate;

    return [
        "subtotal" => round($subtotal, 2),
        "tax" => round($tax, 2),
        "total" => round($subtotal + $tax, 2),
    ];
}

$items = [
    ["price" => 199.5, "num" => 1],
    ["price" => 89.0, "num" => 2],
    ["price" => -5.0, "num" => 1],     // 脏数据，会被跳过
];

$bill = totalPrice($items);

foreach ($bill as $label => $amount) {
    echo "{$label}：{$amount}<br>";
}
```

```text
subtotal：377.5
tax：22.65
total：400.15
```

这个函数有类型声明、有默认值、有返回数组、有脏数据防御，是一个"可以放进真实项目"的函数的样子。
