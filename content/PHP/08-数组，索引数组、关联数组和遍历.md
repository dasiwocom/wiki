# 数组，索引数组、关联数组和遍历

PHP 里数组是用得最多的结构。后台拿到的数据——一行用户、一批订单、一份配置——全是数组。

它和别的语言有个很大的不同：**PHP 的数组用得好的话，一个结构同时当列表、当字典、当映射用。**

## 两种写法

```php
<?php
// 短语法（推荐）
$fruits = ["苹果", "香蕉", "橘子"];

// 老语法，效果一样
$fruits = array("苹果", "香蕉", "橘子");
```

都行，新代码一律用方括号。

## 索引数组：靠位置取

```php
<?php
$fruits = ["苹果", "香蕉", "橘子"];

echo $fruits[0];      // 苹果
echo $fruits[2];      // 橘子
echo count($fruits);  // 3
```

**下标从 0 开始**，这是最常出错的地方——三个元素的最大下标是 2，`$fruits[3]` 会报"未定义的键"。

## 关联数组：靠名字取

```php
<?php
$user = [
    "name" => "小明",
    "age" => 18,
    "city" => "杭州",
];

echo $user["name"];    // 小明
echo $user["age"];     // 18
```

`=>` 左边是键，右边是值。**有了键名，代码可读性完全不一样**：`$user["age"]` 一眼知道是什么，`$user[1]` 得回去数。

实际项目里，从数据库查出来的一行数据、一份配置、一个表单的结果，都是关联数组。

## 两种可以混着用

```php
<?php
$mixed = [
    "title" => "商品列表",
    0 => "第一项",
    "第二项",        // 没写键，自动接上一个数字键，这里是 1
];

echo $mixed["title"];   // 商品列表
echo $mixed[1];         // 第二项
```

能这么写，但**不要这么写**。一个数组要么是列表、要么是字典，混着来自己三个月后都看不懂。

## 更常见的是"数组里装数组"

```php
<?php
$goods = [
    ["name" => "键盘", "price" => 199.5, "stock" => 12],
    ["name" => "鼠标", "price" => 89.0,  "stock" => 30],
    ["name" => "显示器", "price" => 1099.0, "stock" => 5],
];

echo $goods[0]["name"];    // 键盘
echo $goods[2]["stock"];   // 5
echo count($goods);        // 3 —— 只数最外层
```

这就是"二维数组"，实质是一个列表，每一项又是一个字典。**从数据库查一批数据出来，拿到的就是这个形状。** 记住它，后面读别人的代码会轻松很多。

## 增删改查

### 加

```php
<?php
$arr = ["a", "b"];

$arr[] = "c";              // 追加到末尾，键自动是 2
$arr["x"] = "d";           // 指定键
array_push($arr, "e", "f"); // 一次加多个

print_r($arr);
```

```text
Array
(
    [0] => a
    [1] => b
    [2] => c
    [x] => d
    [3] => e
    [4] => f
)
```

**`$arr[] = 值;` 是追加的标准写法**，比 `array_push` 快一点也短一点，一次加一个值时用它。

### 删

```php
<?php
$arr = ["a", "b", "c"];

unset($arr[1]);
print_r($arr);
```

```text
Array
(
    [0] => a
    [2] => c
)
```

**注意：`unset` 之后下标不会自动补上，`1` 就空着了。** 想让它变成紧凑的列表，得重建索引：

```php
<?php
$arr = array_values($arr);
print_r($arr);
```

```text
Array
(
    [0] => a
    [1] => c
)
```

这件事在**把数组输出成 JSON 给前端**的时候特别重要——键是 `0, 2` 的数组会被转成对象 `{"0":"a","2":"c"}`，而不是数组 `["a","c"]`，前端一 `for` 就出错（第 18 篇）。

删除最后一个用 `array_pop`：

```php
<?php
$arr = ["a", "b", "c"];
$last = array_pop($arr);     // $last 是 "c"，$arr 剩 ["a", "b"]

$first = array_shift($arr);  // $first 是 "a"，$arr 剩 ["b"]
```

`array_pop` 从尾部拿掉，`array_shift` 从头部拿掉。`array_shift` 会重建索引，元素多的时候慢，别放在循环里用。

### 改

```php
<?php
$user = ["name" => "小明", "age" => 18];
$user["age"] = 19;
```

直接用键赋值就行，键不存在就是新增。

### 查

```php
<?php
$user = ["name" => "小明", "age" => 18];

var_dump(isset($user["name"]));            // true
var_dump(array_key_exists("name", $user));  // true
var_dump(isset($user["height"]));           // false
```

`isset` 和 `array_key_exists` 的区别只在一处：**值是 `null` 的时候**。

```php
<?php
$arr = ["a" => null];

var_dump(isset($arr["a"]));              // false —— isset 把 null 当成"没有"
var_dump(array_key_exists("a", $arr));   // true  —— 键确实在
```

需要区分"键不存在"和"键在但值是 null"（这在处理数据库字段时很常见）就得用 `array_key_exists`。

找值在不在：

```php
<?php
$ids = [3, 7, 11];

var_dump(in_array(7, $ids, true));     // true
var_dump(array_search(7, $ids, true)); // 1 —— 返回键

if (in_array($id, $ids, true)) {
    echo "有这个 id";
}
```

**第三个参数 `true` 一定要传**（第 4 篇讲过原因）。

## 遍历

```php
<?php
$user = ["name" => "小明", "age" => 18];

// 只要值
foreach ($user as $v) {
    echo $v . "<br>";
}

// 键和值都要
foreach ($user as $k => $v) {
    echo "{$k} = {$v}<br>";
}
```

**别用 `for ($i = 0; $i < count($arr); $i++)` 遍历关联数组**——`$arr[0]` 可能根本不存在。`foreach` 只管挨个跑一遍，不问键是什么，永远是对的。

另外 `count()` 写在循环条件里会在每一轮都重新调用一次，效率差。非要用 `for` 的话先存起来：

```php
<?php
$n = count($arr);
for ($i = 0; $i < $n; $i++) { }
```

## 一个例子：把数组渲染成表格，再算个合计

```php
<?php
$goods = [
    ["name" => "键盘",   "price" => 199.5, "stock" => 12],
    ["name" => "鼠标",   "price" => 89.0,  "stock" => 30],
    ["name" => "显示器", "price" => 1099.0, "stock" => 5],
];

$total = 0;
foreach ($goods as $g) {
    $total += $g["price"] * $g["stock"];
}
?>
<table border="1" cellpadding="6">
  <tr><th>#</th><th>商品</th><th>单价</th><th>库存</th><th>小计</th></tr>
  <?php foreach ($goods as $i => $g): ?>
    <tr>
      <td><?php echo $i + 1; ?></td>
      <td><?php echo htmlspecialchars($g["name"]); ?></td>
      <td><?php echo number_format($g["price"], 2); ?></td>
      <td><?php echo $g["stock"]; ?></td>
      <td><?php echo number_format($g["price"] * $g["stock"], 2); ?></td>
    </tr>
  <?php endforeach; ?>
  <tr>
    <td colspan="4">合计</td>
    <td><?php echo number_format($total, 2); ?></td>
  </tr>
</table>
```

页面上是一张四列表格，最后一行是总计。

这段代码把前面几篇的东西全用上了：二维数组、`foreach`、替代语法、`htmlspecialchars` 输出转义、`number_format` 格式化金额。**"查数据 → 循环 → 输出成表格"就是 PHP 最典型的工作流**，后面几篇都是在这上面加东西。
