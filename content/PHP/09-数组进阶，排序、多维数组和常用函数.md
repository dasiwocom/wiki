# 数组进阶，排序、多维数组和常用函数

## 排序：先说最常用的那种

PHP 的排序函数有十来个，很容易记混。先记住一个结论：

**排序"一个普通列表"用 `sort()`，排序"一批带字段的数组"用 `usort()`。** 其他几个看了就知道怎么回事。

### 简单数组

```php
<?php
$nums = [3, 1, 4, 1, 5];

sort($nums);        // 从小到大，键会被重建
print_r($nums);
```

```text
Array
(
    [0] => 1
    [1] => 1
    [2] => 3
    [3] => 4
    [4] => 5
)
```

```php
<?php
$nums = [3, 1, 4];
rsort($nums);       // 从大到小
```

注意：`sort()` **直接改原数组**（叫"原地排序"，所以传进去的变量会被改掉），并且**会重建键**。上面 `$nums` 原来是 `0,1,2`，排完还是 `0,1,2`。

排序关联数组的时候这一点很危险：

```php
<?php
$user = ["name" => "小明", "age" => 18, "city" => "杭州"];

sort($user);      // 错：键被冲掉，变成 0,1,2
print_r($user);
```

```text
Array
(
    [0] => 18
    [1] => 杭州
    [2] => 小明
)
```

键没了，`$user["name"]` 也就取不到东西了。

### 按键排还是按值排

| 函数 | 按什么排 | 方向 | 会重建键吗 |
| --- | --- | --- | --- |
| `sort()` | 值 | 升 | 会 |
| `rsort()` | 值 | 降 | 会 |
| `asort()` | 值 | 升 | **不会，保留键** |
| `arsort()` | 值 | 降 | 不会 |
| `ksort()` | 键 | 升 | 不会 |
| `krsort()` | 键 | 降 | 不会 |

字母 a 在前表示"值"（association），k 表示"键"。**关联数组想排序又不丢键，用带 a 或 k 的那几个。**

```php
<?php
$scores = ["小明" => 85, "小红" => 92, "小刚" => 78];

asort($scores);
print_r($scores);
```

```text
Array
(
    [小刚] => 78
    [小明] => 85
    [小红] => 92
)
```

## 按字段排序：`usort`

从数据库查出来的列表长这样：

```php
<?php
$users = [
    ["name" => "小明", "age" => 18],
    ["name" => "小红", "age" => 22],
    ["name" => "小刚", "age" => 15],
];
```

想按 `age` 排，`sort()` 帮不上忙（它没法比较两个数组）。要用 `usort`，**自己写一个"怎么比大小"的函数**：

```php
<?php
usort($users, function ($a, $b) {
    return $a["age"] <=> $b["age"];
});
```

这个比较函数要返回三档：负数表示 `$a` 排前面，0 表示一样大，正数表示 `$b` 排前面。

`<=>` 这个运算符干的正好就是这件事（第 4 篇讲过），所以排一个字段只要一行。

用箭头函数写更短：

```php
<?php
usort($users, fn($a, $b) => $a["age"] <=> $b["age"]);       // 按年龄升序
usort($users, fn($a, $b) => $b["age"] <=> $a["age"]);       // 降序：把两边调过来
```

**降序就是把 `$a` 和 `$b` 的位置对调一下**，这个技巧记住就好。

按多个字段排（先按年龄、年龄相同按名字）：

```php
<?php
usort($users, fn($a, $b) => [$a["age"], $a["name"]] <=> [$b["age"], $b["name"]]);
```

把要比较的字段组成数组再比，PHP 会逐个元素比较，很省事。

`usort` 和 `sort` 一样，**直接改原数组**。想保留原数组先复制一份：

```php
<?php
$sorted = $users;
usort($sorted, fn($a, $b) => $a["age"] <=> $b["age"]);
```

## 抽出一列：`array_column`

```php
<?php
$names = array_column($users, "name");
print_r($names);
```

```text
Array
(
    [0] => 小明
    [1] => 小红
    [2] => 小刚
)
```

**这是把"一批记录"变成"一列值"最快的办法。** 想拿一批 id、一批名字、一批邮箱，都用它。

它还能重建索引：

```php
<?php
$byId = array_column($users, null, "name");   // 用 name 当键
// 得到 ["小明" => [...], "小红" => [...], ...]
```

从数据库查出来的列表转成"按 id 快速查找"的字典，用这一句就够。

## 映射、筛选、归约

这三个是日常处理数据的主力。

### `array_map`：每一项都过一遍

```php
<?php
$nums = [1, 2, 3, 4];

$doubled = array_map(fn($n) => $n * 2, $nums);
print_r($doubled);
```

```text
Array
(
    [0] => 2
    [1] => 4
    [2] => 6
    [3] => 8
)
```

`array_map` **返回新数组，不改原来的**。

### `array_filter`：只留符合条件的

```php
<?php
$nums = [1, 0, 3, null, 5, ""];

$valid = array_filter($nums);
print_r($valid);
```

```text
Array
(
    [0] => 1
    [2] => 3
    [4] => 5
)
```

不传回调时，**它会自动去掉所有"假"值**（第 3 篇那张表里的）。过滤表单里的空值特别方便。

传回调就是自定义条件：

```php
<?php
$adults = array_filter($users, fn($u) => $u["age"] >= 18);
```

注意结果的下标是 `0, 2` 这种**有洞的**，因为 `array_filter` 保留原来的键。要变成紧凑列表：

```php
<?php
$adults = array_values(array_filter($users, fn($u) => $u["age"] >= 18));
```

`array_values(...)` 包在外面是标准写法，尤其是结果要输出成 JSON 的时候。

### `array_reduce`：把整个数组压成一个值

```php
<?php
$nums = [1, 2, 3, 4];

$sum = array_reduce($nums, fn($carry, $n) => $carry + $n, 0);
echo $sum;
```

```text
10
```

`$carry` 是"到目前为止累积的结果"，最后的 `0` 是初始值。求和、求最大值、拼字符串都能用它。

不过**只是求和的场合直接用 `array_sum`**：

```php
<?php
echo array_sum($nums);     // 10
echo max($nums);           // 4
echo min($nums);           // 1
```

## 合并、去重、切片

```php
<?php
$a = ["a", "b"];
$b = ["c", "d"];

// 合并（都是数字键）
print_r(array_merge($a, $b));     // [a, b, c, d]

// 去重
print_r(array_unique([1, 2, 2, 3]));

// 取一段（不改原数组）
print_r(array_slice([1, 2, 3, 4, 5], 1, 3));   // [2, 3, 4]

// 键和值
print_r(array_keys(["a" => 1, "b" => 2]));     // [a, b]
print_r(array_values(["a" => 1]));             // [1]
```

**`array_merge` 和 `+` 不一样，这个要记住：**

```php
<?php
$x = ["name" => "小明", "age" => 18];
$y = ["age" => 20, "city" => "杭州"];

print_r(array_merge($x, $y));   // ["name"=>"小明", "age"=>20, "city"=>"杭州"]  后面的覆盖前面
print_r($x + $y);               // ["name"=>"小明", "age"=>18, "city"=>"杭州"]  前面的不动
```

`array_merge` 遇到相同的字符串键，**后者覆盖前者**；`+` 运算符是**前者优先**。合并配置的时候想清楚要哪种。

数组里元素的顺序、键的类型，也都有讲究：`array_merge` 会把数字键重建，`+` 会把数字键保留成 `0,1,2` 覆盖的关系——所以**合并列表用 `array_merge`，合并配置字典要看清楚想要谁赢。**

## 解构

PHP 7.1 起可以这样一次取出多个值：

```php
<?php
$user = ["小明", 18, "杭州"];
[$name, $age, $city] = $user;

echo $name;    // 小明
```

关联数组也能解构：

```php
<?php
$u = ["name" => "小明", "age" => 18];
["name" => $name, "age" => $age] = $u;
```

好用的地方在于**跳过不想要的**：

```php
<?php
[ , , $city] = ["小明", 18, "杭州"];    // 只要第三个
echo $city;
```

```text
杭州
```

## `array_is_list`：判断是不是一个"整齐的列表"

```php
<?php
var_dump(array_is_list([1, 2, 3]));       // true
var_dump(array_is_list([0 => "a", 2 => "b"]));  // false
var_dump(array_is_list(["a" => 1]));      // false
```

PHP 8.1 新增。在**把数组转成 JSON 之前**检查一下很有用——不是 list 的数组会被转成对象而不是数组，前端会收到意料之外的结构（第 18 篇细讲）。

## 一个例子：把列表按条件筛出来再排序

```php
<?php
$users = [
    ["name" => "小明", "age" => 18, "active" => true],
    ["name" => "小红", "age" => 22, "active" => false],
    ["name" => "小刚", "age" => 15, "active" => true],
    ["name" => "小美", "age" => 25, "active" => true],
];

// 先筛出启用的成年人，再按年龄从大到小排
$list = array_values(
    array_filter($users, fn($u) => $u["active"] && $u["age"] >= 18)
);
usort($list, fn($a, $b) => $b["age"] <=> $a["age"]);

print_r(array_column($list, "name"));
echo "平均年龄：" . array_sum(array_column($list, "age")) / count($list);
```

```text
Array
(
    [0] => 小美
    [1] => 小明
)
平均年龄：21.5
```

三步：**筛 → 排 → 取列**。这个套路在写后台的时候几乎天天用。
