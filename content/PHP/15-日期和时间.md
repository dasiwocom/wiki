# 日期和时间

## 先配时区，不然后面全是错的

PHP 默认用 UTC，直接 `date()` 会比北京时间**少 8 小时**。这是新手第一个撞上的坑。

在入口文件最上面设一次：

```php
<?php
date_default_timezone_set("Asia/Shanghai");
```

或者在 `php.ini` 里：

```ini
date.timezone = Asia/Shanghai
```

**忘了配的话，晚上八点之后的页面会显示成"明天"**，日期相关的逻辑全乱。

## `date()`：把时间格式化成文字

```php
<?php
date_default_timezone_set("Asia/Shanghai");

echo date("Y-m-d");            // 2026-10-03
echo date("Y-m-d H:i:s");      // 2026-10-03 14:22:07
echo date("Y年m月d日 H时i分");  // 2026年10月03日 14时22分
echo date("N");                // 6（星期几，1=周一 … 7=周日）
echo date("t");                // 31（这个月有多少天）
```

常用的格式字符：

| 字符 | 意思 | 例子 |
| --- | --- | --- |
| `Y` | 四位年份 | 2026 |
| `y` | 两位年份 | 26 |
| `m` | 月份，补零 | 10 |
| `n` | 月份，不补零 | 10 |
| `d` | 日，补零 | 03 |
| `j` | 日，不补零 | 3 |
| `H` | 小时（24 小时制） | 14 |
| `h` | 小时（12 小时制） | 02 |
| `i` | 分钟 | 22 |
| `s` | 秒 | 07 |
| `N` | 星期几，1~7 | 6 |
| `w` | 星期几，0~6（0 是周日） | 6 |
| `t` | 当月天数 | 31 |
| `U` | Unix 时间戳 | 1791000000 |
| `A` | 上午/下午 | PM |

**`m` 和 `n` 的区别只在补不补零。** 拼 SQL、做接口参数的时候，一律用补零的 `m`、`d`、`H`、`i`、`s`，这样字符串长度固定，比较和排序都不会出错。

## 时间戳：从 1970 年数起的秒数

```php
<?php
echo time();                       // 1791000000 这样的整数
echo date("Y-m-d H:i:s", time());  // 转成看得懂的
```

时间戳是一个整数，好处是**能直接做加减**：

```php
<?php
$now = time();
$tomorrow = $now + 24 * 3600;         // 加一天
$lastWeek = $now - 7 * 24 * 3600;     // 减一周

echo date("Y-m-d", $tomorrow);
```

一天 86400 秒，这是最常用的换算。

## `strtotime()`：把文字变成时间戳

```php
<?php
echo strtotime("2026-10-03");            // 那一天的零点
echo strtotime("+1 day");                // 明天这个时候
echo strtotime("next Monday");           // 下周一
echo strtotime("2026-10-03 +2 weeks");   // 10 月 17 日
echo strtotime("last day of this month");// 本月最后一天

echo date("Y-m-d", strtotime("+1 month"));
```

**`strtotime` 能听懂英文短语**，写"下周一""三个月后""本月最后一天"特别省事。

注意一个陷阱：

```php
<?php
echo date("Y-m-d", strtotime("2026-01-31 +1 month"));   // 2026-03-03
```

1 月 31 日加一个月，2 月没有 31 号，PHP 会往后溢出到 3 月 3 日。**涉及月份加减要留个心眼**，用下面说的 `DateTime` 更稳。

转换回来也是一对：

```php
<?php
$ts = strtotime("2026-10-03 14:30:00");
echo date("Y-m-d", $ts);
```

## 算两个日期差多少天

最直接的办法是把两个时间戳相减：

```php
<?php
$d1 = strtotime("2026-10-03");
$d2 = strtotime("2026-12-25");

$days = ($d2 - $d1) / 86400;
echo (int) $days . " 天";
```

```text
83 天
```

因为两个时间戳都指向当天的零点，差值正好是整数天。

## `DateTime` 类：推荐的做法

`strtotime` + `date` 够用，但日期算得复杂的时候，`DateTime` 更清楚：

```php
<?php
$now = new DateTime();
echo $now->format("Y-m-d H:i:s");

$next = new DateTime("+1 month");
```

### 加减时间

```php
<?php
$d = new DateTime("2026-01-31");
$d->modify("+1 month");
echo $d->format("Y-m-d");      // 2026-03-03 —— 和 strtotime 一样会溢出
```

### 求两个日期的差

```php
<?php
$birth = new DateTime("2000-05-20");
$today = new DateTime();

$diff = $today->diff($birth);

echo $diff->y . " 岁 " . $diff->m . " 个月";
echo $diff->days . " 天";
```

```text
26 岁 4 个月9467 天
```

`diff()` 返回的对象里有 `y`（年）、`m`（月）、`d`（天）、`days`（总天数）这些属性——**算年龄用它最准**，不用自己去算闰年。

想算得规整一点：

```php
<?php
$start = new DateTime("2026-10-03");
$end   = new DateTime("2027-03-15");

$diff = $start->diff($end);
echo $diff->format("%Y 年 %M 个月 %D 天");
echo $diff->days . " 天";
echo $end > $start ? "（在后面）" : "（在前面）";
```

`format()` 里的 `%Y` `%M` `%D` 是"差值的年月日"，和 `date()` 那套不一样，别混。

### 时间戳互转

```php
<?php
$d = new DateTime("2026-10-03 14:30");
echo $d->getTimestamp();              // 转成时间戳

$d2 = (new DateTime())->setTimestamp(1791000000);
echo $d2->format("Y-m-d H:i:s");
```

## 几个常见需求

### 显示"3 分钟前"

```php
<?php
function timeAgo(string $datetime): string {
    $seconds = time() - strtotime($datetime);

    if ($seconds < 60)  return "刚刚";
    if ($seconds < 3600) return floor($seconds / 60) . " 分钟前";
    if ($seconds < 86400) return floor($seconds / 3600) . " 小时前";
    if ($seconds < 2592000) return floor($seconds / 86400) . " 天前";

    return date("Y-m-d", strtotime($datetime));
}

echo timeAgo(date("Y-m-d H:i:s", time() - 7200));
```

```text
2 小时前
```

### 判断是不是今天

```php
<?php
$orderDate = "2026-10-03 09:12:00";

if (date("Y-m-d", strtotime($orderDate)) === date("Y-m-d")) {
    echo "今天的订单";
}
```

**只比较"年月日"这三个部分，不比较具体时间。** 直接比 `strtotime()` 的结果是错的，那样要求秒钟都一样。

### 求某个月有多少天

```php
<?php
echo date("t", strtotime("2026-02-01"));     // 28

$d = new DateTime("2026-02-01");
echo $d->format("t");                        // 28
```

`t` 这个格式字符会自动处理闰年，比自己写 `if` 判断省事。

### 输出的日期可以在数据库里排序

```php
<?php
date_default_timezone_set("Asia/Shanghai");

$createdAt = date("Y-m-d H:i:s");
```

`2026-10-03 14:22:07` 这个格式的好处是**字符串排序和按时间排序结果一致**——从早到晚就是从小到大。所以存进数据库、做排序和范围查询都用它。

想排序更严格，可以用带微秒的：

```php
<?php
echo (new DateTime())->format("Y-m-d H:i:s.u");
```

## 一个例子：把一批时间显示成人看得懂的样子

```php
<?php
date_default_timezone_set("Asia/Shanghai");

$orders = [
    ["no" => "A001", "created" => date("Y-m-d H:i:s", time() - 300)],
    ["no" => "A002", "created" => date("Y-m-d H:i:s", time() - 7200)],
    ["no" => "A003", "created" => date("Y-m-d H:i:s", time() - 86400 * 3)],
];

function timeAgo(string $datetime): string {
    $s = time() - strtotime($datetime);
    if ($s < 60)    return "刚刚";
    if ($s < 3600)  return floor($s / 60) . " 分钟前";
    if ($s < 86400) return floor($s / 3600) . " 小时前";
    if ($s < 2592000) return floor($s / 86400) . " 天前";
    return date("Y-m-d", strtotime($datetime));
}

foreach ($orders as $o) {
    echo $o["no"] . "　" . timeAgo($o["created"]) . "<br>";
}
```

```text
A001　刚刚
A002　2 小时前
A003　3 天前
```
