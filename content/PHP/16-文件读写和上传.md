# 文件读写和上传

## 读整个文件

```php
<?php
$text = file_get_contents(__DIR__ . "/data.txt");
echo $text;
```

一行搞定。文件小的时候（几 KB 到几 MB）就用它，最省事。

文件不存在会警告并返回 `false`：

```php
<?php
$path = __DIR__ . "/data.txt";

if (file_exists($path)) {
    $text = file_get_contents($path);
} else {
    echo "文件不存在";
}
```

另外两个常用的判断：

```php
<?php
var_dump(filesize($path));      // 字节数
var_dump(is_file($path));       // 是文件还是目录
```

## 写文件

```php
<?php
$data = "第一行\n第二行";

file_put_contents(__DIR__ . "/out.txt", $data);
```

默认会**清空原文件再写**。想追加：

```php
<?php
file_put_contents(__DIR__ . "/out.txt", "新的一行\n", FILE_APPEND | LOCK_EX);
```

`FILE_APPEND` 表示追加到末尾，`LOCK_EX` 表示写入时锁住文件——**多人同时访问的网站上，写日志一定要带上它**，否则两个请求同时写会互相覆盖、丢内容。

组合多个常量的时候中间要用 `|`（位或）。

## 一行一行读大文件

文件几十 MB 的时候，`file_get_contents` 会把整份内容读进内存，可能撑爆。用 `fopen` 逐行读：

```php
<?php
$fp = fopen(__DIR__ . "/big.csv", "r");

if ($fp) {
    while (($line = fgets($fp)) !== false) {
        echo htmlspecialchars(trim($line)) . "<br>";
    }
    fclose($fp);
}
```

`fopen` 的第二个参数是模式：

| 模式 | 意思 |
| --- | --- |
| `"r"` | 只读，从头开始 |
| `"w"` | 只写，清空原文件 |
| `"a"` | 只写，追加到末尾 |
| `"r+"` | 读写 |

**`fclose` 别忘了。** 用完不关，文件句柄会一直占着。

## 删文件

```php
<?php
$path = __DIR__ . "/tmp.txt";

if (file_exists($path)) {
    unlink($path);
}
```

`unlink` 是删除文件，`rmdir` 删空目录。**这两个操作没有回收站**，删了就没了，所以调用前一定先 `file_exists` 判断。

## 写日志的实用函数

```php
<?php
function logLine(string $msg): void {
    $line = "[" . date("Y-m-d H:i:s") . "] " . $msg . PHP_EOL;
    file_put_contents(__DIR__ . "/logs/app.log", $line, FILE_APPEND | LOCK_EX);
}

logLine("用户 7 登录成功");
```

日志文件大概长这样：

```text
[2026-10-03 14:22:07] 用户 7 登录成功
[2026-10-03 14:23:11] 用户 7 上传了 1 个文件
```

**日志默认要放在网站根目录之外，或者保证外界访问不到。** 放在能通过网址直接下载的位置，等于把系统信息摊开给所有人看。

## 文件上传

上传的表单和普通表单有一处不同：

```html
<form method="post" enctype="multipart/form-data">
  <input type="file" name="avatar">
  <button type="submit">上传</button>
</form>
```

**`enctype="multipart/form-data"` 不能少。** 少了的话，服务器只会收到文件名，收不到文件内容。这是上传失败最常见的原因。

处理端在 `$_FILES` 里拿数据：

```php
<?php
print_r($_FILES);
```

```text
Array
(
    [avatar] => Array
    (
        [name] => photo.jpg         用户电脑上的原文件名
        [type] => image/jpeg        浏览器猜的类型，不可信
        [tmp_name] => /tmp/phpA3F.jpg  服务器上的临时文件
        [error] => 0                0 表示成功
        [size] => 245311            字节数
    )
)
```

`$_FILES` 的键是表单里的 `name`。

### 先看 `error`

```php
<?php
$err = $_FILES["avatar"]["error"] ?? UPLOAD_ERR_NO_FILE;

if ($err !== UPLOAD_ERR_OK) {
    echo "上传失败，错误码：" . $err;
}
```

| 错误码 | 意思 |
| --- | --- |
| `0` | 成功 |
| `1` | 超过 `php.ini` 里的 `upload_max_filesize` |
| `2` | 超过表单里的 `MAX_FILE_SIZE` |
| `3` | 只上传了一半 |
| `4` | **没有选文件** |
| `6` | 服务器没有临时目录 |
| `7` | 写不进磁盘 |

**`4` 是最常见的**——用户没选文件直接点了提交。这不是错误，只是"没传"，代码里要能区分开。

### 检查：大小、类型、扩展名

```php
<?php
const MAX_SIZE = 2 * 1024 * 1024;             // 2 MB
const ALLOW_EXT = ["jpg", "jpeg", "png", "gif"];
const ALLOW_MIME = ["image/jpeg", "image/png", "image/gif"];

$f = $_FILES["avatar"];
$errors = [];

// ① 大小
if ($f["size"] > MAX_SIZE) {
    $errors[] = "文件超过 2MB";
}

// ② 扩展名
$ext = strtolower(pathinfo($f["name"], PATHINFO_EXTENSION));
if (!in_array($ext, ALLOW_EXT, true)) {
    $errors[] = "只允许上传 " . implode("、", ALLOW_EXT);
}

// ③ 真实类型（不看浏览器报的，看文件本身）
$mime = mime_content_type($f["tmp_name"]);
if (!in_array($mime, ALLOW_MIME, true)) {
    $errors[] = "文件内容不是图片";
}
```

**三条都要查，缺一不可。**

- 只看扩展名：把 `a.php` 改名成 `a.jpg` 就混进来了
- 只看浏览器报的 `type`：那是浏览器猜的，可以随便伪造
- 用 `mime_content_type()` 读文件头判断真实类型，才是可靠的那一层

### 保存：换个名字，别用原文件名

```php
<?php
if (empty($errors)) {
    $newName = bin2hex(random_bytes(16)) . "." . $ext;
    $dest = __DIR__ . "/uploads/" . $newName;

    if (move_uploaded_file($f["tmp_name"], $dest)) {
        echo "上传成功：" . htmlspecialchars($newName);
    } else {
        echo "保存失败，检查 uploads 目录有没有写权限";
    }
}
```

三个要点：

**① `move_uploaded_file` 是唯一正确的搬运方式。** 用 `copy()` 或 `rename()` 会有安全漏洞——PHP 特意用这个函数确认"这确实是一个刚上传上来的临时文件"。

**② 文件名必须自己生成。** 用户的原文件名可能是 `../../config.php`（路径穿越）、可能是 `a.php`（想让你执行它）、也可能是中文或特殊字符（在服务器上打不开）。用随机串最省心。

**③ 按日期分目录**，上传多了不会全堆在一起：

```php
<?php
$sub = date("Ymd");
$dir = __DIR__ . "/uploads/" . $sub;

if (!is_dir($dir)) {
    mkdir($dir, 0755, true);
}

$dest = $dir . "/" . $newName;
```

### 上传目录不能执行 PHP

这是最容易被忽略、也最危险的一条。

如果上传目录能执行脚本，攻击者传一个 `shell.php`，然后用浏览器访问它——你的服务器就被拿走了。

防护办法（任选，建议都做）：

- 上传目录**放在网站根目录之外**，用 PHP 读文件再输出；
- 或者在 `uploads` 目录里放一个 `.htaccess`（Apache）：

```apache
php_flag engine off
```

- 或者保存时**强制改掉扩展名**（图片就叫 `.jpg`，不管原来叫什么）。

另外，`php.ini` 里有两个上限管着上传，文件太大时要改：

```ini
upload_max_filesize = 2M
post_max_size = 8M
```

**`post_max_size` 要比 `upload_max_filesize` 大**，因为 POST 里除了文件还有别的字段。改完要重启 Apache 或 PHP-FPM。

## 一个完整的上传例子

```php
<?php
const MAX_SIZE = 2 * 1024 * 1024;
const ALLOW_EXT = ["jpg", "jpeg", "png", "gif"];

$msg = "";
$saved = "";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $f = $_FILES["photo"] ?? null;
    $err = $f["error"] ?? UPLOAD_ERR_NO_FILE;

    if ($err === UPLOAD_ERR_NO_FILE) {
        $msg = "请选择要上传的图片";
    } elseif ($err !== UPLOAD_ERR_OK) {
        $msg = "上传出错，错误码 " . $err;
    } elseif ($f["size"] > MAX_SIZE) {
        $msg = "图片不能超过 2MB";
    } else {
        $ext = strtolower(pathinfo($f["name"], PATHINFO_EXTENSION));
        $mime = mime_content_type($f["tmp_name"]);

        if (!in_array($ext, ALLOW_EXT, true) || !str_starts_with($mime, "image/")) {
            $msg = "只允许上传 jpg、png、gif 图片";
        } else {
            $dir = __DIR__ . "/uploads/" . date("Ymd");
            if (!is_dir($dir)) {
                mkdir($dir, 0755, true);
            }

            $name = bin2hex(random_bytes(8)) . "." . $ext;
            if (move_uploaded_file($f["tmp_name"], $dir . "/" . $name)) {
                $saved = "uploads/" . date("Ymd") . "/" . $name;
                $msg = "上传成功";
            } else {
                $msg = "保存失败，检查目录权限";
            }
        }
    }
}
?>
<!DOCTYPE html>
<html lang="zh-CN">
<head><meta charset="UTF-8"><title>上传图片</title></head>
<body>
<h1>上传图片</h1>

<?php if ($msg !== ""): ?>
  <p><?php echo htmlspecialchars($msg); ?></p>
<?php endif; ?>

<?php if ($saved !== ""): ?>
  <p><img src="<?php echo htmlspecialchars($saved); ?>" alt="刚上传的图片" width="300"></p>
<?php endif; ?>

<form method="post" enctype="multipart/form-data">
  <input type="file" name="photo" accept="image/*">
  <button type="submit">上传</button>
</form>
</body>
</html>
```

选一张图片提交，页面上会出现"上传成功"，下面直接把刚上传的图显示出来。
