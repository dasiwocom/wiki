# PHP 总览

这一组共 19 篇，按顺序排好了：从"PHP 到底是什么、怎么在自己电脑上跑起来"开始，到"连上数据库把数据存起来"。

前两篇只干一件事：让你手上有一个能跑 PHP 的地方。这件事在 PHP 上比在 HTML、CSS、JavaScript 上麻烦得多，必须先解决。

每一篇的末尾都有一行导航，打开第 1 篇一路点"下一步"就能顺着读完，随时点"路线图"回到这里。

## 一个前提：这组示例没法在页面上直接跑

CSS 那组可以在页面上真的动起来，因为它本来就是浏览器执行的。**PHP 不行**——这一组里的代码块后面跟着的"运行结果"，是运行过之后贴出来的样子，不是页面上算出来的。

想验证，有两个办法：

- 简单语法：把代码贴进[菜鸟教程的在线编辑器](https://www.runoob.com/try/runcode.php?filename=demo_intro&type=php)或 [3v4l.org](https://3v4l.org/)，立刻出结果；
- 表单一类、文件上传、Cookie、数据库：**必须在自己电脑上装环境**，在线沙箱全都做不了（它们不允许读写文件，也不保存状态）。装法见第 1 篇。

## 写 PHP 的几条习惯

**纯 PHP 文件末尾不写 `?>`。** 写下去之后，文件末尾多出来的一个空格或换行会被当成页面输出，接在图片、跳转、下载后面就是"文件已损坏"。

**一律用 `===`。** PHP 的 `==` 会先把两边转成同一个类型再比，`0 == "abc"` 在老版本里是真的。这类比较在判断条件里非常危险。

**往数据库写的时候，绝不用字符串拼 SQL。** 一律用预处理语句（`prepare` + `execute`），第 19 篇有完整写法。

**往页面输出用户给的内容，一律过一遍 `htmlspecialchars`。** 否则别人能往你页面里塞脚本。

**打开报错显示再写代码。** 开发的时候看得到报错，比对着空白页面猜快一百倍。改法在第 17 篇，**上线前记得关掉**。

**文件路径用 `__DIR__` 拼。** `__DIR__` 是当前文件所在目录的绝对路径，用它拼出来的路径不会因为"从哪个目录启动的"而变化。

**字符串统一用单引号，除非里面有变量。** 双引号会去解析里面的 `$变量`，有时候是你要的，有时候是意外。
