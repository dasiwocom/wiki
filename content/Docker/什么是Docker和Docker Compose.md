## 什么是 Docker？

想象有一个密封小盒子。 盒子里面装着： 你要用的程序（比如 Dashy） 还有这个程序运行需要的所有东西。

这个盒子可以在任何电脑上跑。不管你的服务器是什么系统，它都不在乎。也不会弄坏服务器上别的程序。

- 盒子文件 = Docker 镜像（image）
- 把盒子打开、让它跑起来 = Docker 容器（container）

在 Docker 出现之前： 你得一步步手动安装程序。有时候装完会弄坏别的软件。有时候在这台服务器能跑，换到另一台就不行。

有了 Docker： 直接启动这个盒子就行。所有需要的东西都已经在盒子里面。敲一条命令，搞定。 你的 Dashy 就是跑在这样一个盒子里。

## 什么是 Docker Compose？

Docker 只跑一个盒子的时候很好用。 但有些场景，你需要好几个盒子一起配合工作。 举例子：盒子1=网站，盒子2=数据库，盒子3=缓存工具。

如果不用 Compose，每个盒子都要敲很长一串命令，很麻烦。

Docker Compose 允许你写一个简单的文本文件。 把所有盒子和它们的配置都写进这个文件。 之后你只需要敲短短的一条命令，就能一次性启动全部盒子。

### 简单对比

- `docker run`：启动**单个盒子**，所有配置写在命令里
- `docker compose`：启动**多个盒子**，所有配置保存在文件里

### 放到你的 Dashy 场景

Dashy 只需要一个盒子。所以两种方式都行：`docker run` 或者 Docker Compose。 如果你以后还要加别的服务，Docker Compose 会更方便。

真实例子： 如果你之后想同时跑：Dashy + FileBrowser + 其他工具。一共三个独立盒子。Docker Compose 只用一个文件就能统一管理这三个。
