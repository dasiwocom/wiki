# 几何公差标注（GB/T 1182）

## 代号组成

几何公差代号 = **公差框格**（细实线，2 格或多格）+ **带箭头的指引线** + **基准符号**。

## 公差框格

- 用**细实线**绘制，高度 = 图中尺寸数字字高的 **2 倍**（h=3.5 → 框格高 7）
- 只能**水平或垂直**放置，不能斜放
- 框格宽度：第一格 = 框格高度；第二格与标注内容长度相适应；第三格起与基准字母宽度相适应
- 从左到右填写：
  1. 公差特征项目符号（线宽约为字高的 1/10）
  2. 公差值（mm，圆形/圆柱形公差带加 Ø，球形加 SØ）
  3. 起为基准字母，顺序固定（与字母表顺序无关）
- 形状公差无基准 → 只需两格；位置/方向/跳动公差 → 三格以上
- 同一要素多项公差：框格并列；多箭头可指向多处被测要素

## 基准代号

- 组成：**方框（细实线，内填大写字母）+ 涂黑或空白的等腰三角形 + 细实线连线**
- 涂黑与空白含义相同；三角形底边与基准要素重合
- 无论基准代号方向如何，**方框内字母一律水平书写**
- 基准字母用大写拉丁字母，**禁用 E、F、I、J、L、M、O、P、R**（另有含义易混淆）
- 方框字母高度与图中数字等高

## 被测要素的标注

- **轮廓要素**（表面/轮廓线）：箭头指在被测要素的轮廓线或延长线上，
  且必须与尺寸线**明显错开**（不得重合）
- **中心要素**（轴线/中心平面）：箭头应与该要素的**尺寸线延长线对齐**；
  位置不够时基准三角形可代替尺寸线的一个箭头
- 基准要素同理：轮廓基准 → 三角形错开尺寸线；中心基准 → 连线与尺寸线对齐

## 常用特征符号

| 类别 | 符号 | 名称 |
|---|---|---|
| 形状 | ─ | 直线度 |
| 形状 | ○ | 圆度 |
| 形状 | ◢ | 圆柱度 |
| 方向 | ∠ | 倾斜度 |
| 方向 | ⊥ | 垂直度 |
| 方向 | ∥ | 平行度 |
| 位置 | ◎ | 同轴度 |
| 位置 | ⌖ | 位置度 |
| 跳动 | ↗ | 圆跳动 |
| 跳动 | ↗↗ | 全跳动 |
