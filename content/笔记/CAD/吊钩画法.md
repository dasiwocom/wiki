# 吊钩画法（圆弧连接经典题）

吊钩是圆弧连接（已知弧/中间弧/连接弧）的代表作。网上教程对 R14/R24 圆心位置说法互相矛盾，**不要照抄图，要从相切条件反推圆心**，再用参考图逐弧像素验证。

## 坐标系与已知条件

碗孔圆心 O=(0,0)，y 向上，柄在上：

| 要素 | 尺寸 | 性质 |
|---|---|---|
| 碗孔 | Ø24（R12） | 已知弧 |
| 外底 | R29，圆心 (5,0) | 已知弧（"5" 直接标注） |
| 下颚 | R24，圆心 y=−9 | 中间弧（"9" 是定位尺寸） |
| 钩内 | R14 | 中间弧 |
| 钩尖 | R2 | 连接弧（**内切**钩腔圆、外切 R14） |
| 左喉 | R36 | 连接弧（切颈线 + **切钩腔 R24 圆**，不是切 R29！） |
| 右背 | R24 | 连接弧（切颈线 + 切 R29） |
| 柄部 | Ø14×23，颈宽 18，肩到碗心 54，倒角 2×45° | — |

## 圆心推导链（全公式，零目测）

```
C_OUT  = (5, 0)                                  # R29
C_CLAW = (5−(29+14), 0) = (−38, 0)               # R14：圆心在水平中心线上，与 R29 外切
C_JAW  = (−√((12+24)²−9²), −9) ≈ (−34.86, −9)    # R24：与碗孔外切，圆心 y=−9
```

- **R2 钩尖**：同时满足「与 R14 外切 d=16」和「与钩腔 R24 内切 d=22」→ 圆-圆交点标准解（余弦定理 + 垂直方向），两个解取**靠碗孔一侧**（x 大）的那个
- **R36 左喉**：圆心 x=−9−36=−45（切左颈线），与**钩腔 R24 圆**外切 d=60 → y=−9+√(60²−(45−34.86)²)≈50.14。易错点：R36 切的是钩腔圆不是 R29，照抄「切 R29」会差出 6.6mm、轮廓断开
- **R24 右背**：圆心 x=+9+24=33（切右颈线），与 R29 外切 d=53 → y=√(53²−28²)=45
- **钩腔圆画两段弧**：R2 尖把腔圆分成上段（R2 切点→R36 切点，约 68.7°→99.7°）和下段（碗孔切点→R2 切点，约 14.5°→68.7°），两段都是金属边界
- **R29 底弧**：从 R14 切点 (−24,0)【180°】逆时针经底部到右背切点【58.1°+360°】，不是从 R36 切点起
- **R2 弧方向**：从腔切点【68.7°】逆时针绕过尖端【180°】到 R14 切点【226°】，跨度 157°；反着画会多出 45° 与邻弧重叠
- 切点一律用**径向插值**：外切点 = C₁ + r₁/(r₁+r₂)·(C₂−C₁)；内切点同理调整

## 像素验证法（防止照错教程）

对参考图：按已知尺寸（54、77）标定像素比例 → 对每个假设圆心，统计轮廓落在 ±0.7mm 圆环带内的像素数（support）→ support 高的假设成立。实测各弧 support：R29=2656、碗孔=1096、R24=660、R14=369，假设全部成立。再用**角度分布**确认每段弧实际使用的扇区。

## 数值闭合自检（比看截图可靠）

截图人眼不可靠（模型读不了图时更是自欺）。做法：
1. 逐段读回 COM 实体，算每段弧/线的**起止端点**
2. 每个端点必须有另一段的端点在 0.05mm 内（整圆、中心线、标题栏除外）
3. 相切约束回验：圆心距必须等于 r₁±r₂（外切加、内切减）
4. 标注压盖用 check_annotations 数值自检

吊钩第一版就是靠这个发现的错：R36 误当切 R29，圆心距 71.6≠65，切点悬空 6.6mm。

## 教程矛盾与裁决

网上教程对钩腔圆心有两说：偏移法（碗孔圆外扩 24，与 y=−9 交点）给 (−34.86,−9)，辅助圆法（过 (−12,0) 作 R24 交 y=−9）给 (−34.25,−9)。差 0.6mm。裁决依据：钩腔与碗孔**必须相切**（图形特征），只有 (−34.86,−9) 满足 d=36=12+24，取它。

## 标注要点

- 半径标注放弧的**外侧空白区**，引线避开尺寸线；开口空腔内不要放文字
- 钩左侧标注密集（54、9、R36、R24、R14、R2 堆在一起），文字位置先用自检数值定位，别目测
- 竖直尺寸文字必须 TextRotation=90（GB 方法一），见 [[机械制图国标速查]]
