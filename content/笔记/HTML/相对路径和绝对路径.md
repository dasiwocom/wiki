## 一、路径是什么

做网页时，图片、样式、文件、页面跳转，都需要告诉浏览器资源在哪里。

这个「资源的地址」，就叫 **路径**。

网页里的路径分两种：1. 绝对路径 2. 相对路径
## 二、绝对路径

从电脑最根部开始写的完整地址，从头到尾写死，完整唯一。

本地绝对路径：

```
C:/Users/xxx/Desktop/html/images/1.png
```

网络绝对路径：

```
https://markdown.com.cn/basic-syntax/index.htm
```
## 三、相对路径（网页最常用）

不写完整地址，一切位置，相对于当前网页文件来找资源。
我们以下图为例子

![[Pasted image 20261004181808.png]]

```
仓库根目录
├─ 文件夹1
│  ├─ 笔记1（我们当前打开的文件，参考起点！）
│  ├─ 图片1
│  └─ 文件夹3
│     └─ 图片2
└─ 文件夹2
   └─ 图片3
```

笔记1访问三个图片的语法分别是、

`./`代表当前目录，也就是笔记1所在的文件夹1，他可以访问笔记1，图片1，文件夹3

```
./图片1.png
```

`/`代表当前目录的子目录，也就是笔记1所在的文件夹1的子文件夹2，它可以访问图片3

```
./文件夹3/图片2.png
```

`../`代表向上跳出当前目录，也就是跳出所在的文件夹1，来到仓库根目录，这个时候当前目录代表根目录，然后`/`可以访问文件夹1和文件夹2，在通过两个/访问到图片3

```
../文件夹2/图片3.png
```
