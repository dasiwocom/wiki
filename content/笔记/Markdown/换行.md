## 空格换行

不同Markdown编辑器渲染略有差异
段落直接回车换行可能并不会生效：

```
这是没有空格结尾的第一行
这是没有空格结尾的第二行
```

结果如下：

这是没有空格结尾的第一行这是没有空格结尾的第二行

最标准的做法是在第一行的结尾按两下空格然后会车换行

```
这是没有空格结尾的第一行  
这是没有空格结尾的第二行
```

显示结果：

这是没有空格结尾的第一行  
这是没有空格结尾的第二行

不过弊端也很明显，大大违背了Markdown轻量简单的宗旨

## 标签换行

我们看一下第二种做法，使用html标签换行

```
这是没有空格结尾的第一行<br>  
这是没有空格结尾的第二行
```

详细请看[[段落和换行]]，html和markdown很多地方都是通用的
markdown本身就支持嵌入html，但是这个方法其实和第一种一样麻烦

## 空行换行

在第一行结束后按两下空格使中间空出来一行来实现强制换行

```
这是没有空格结尾的第一行
 
这是没有空格结尾的第二行
```
