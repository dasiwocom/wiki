## 粗体


使用两个星号包裹使字体变成**粗体**

```
使用两个星号包裹使字体变成**粗体**
```

## 斜体

使用一个星号包裹字体变成*斜体*

```
使用一个星号包裹字体变成*斜体*
```

使用下划线包裹字体变成_斜体_

```
使用下划线包裹字体变成_斜体_
```

## 分隔线

连续按三次以上的星号或者短横线然后回车插入一个分割线

---

```

***
*****
---
------
```
