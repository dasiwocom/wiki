## 表格基础格式

```
|  表头   | 表头  |
|  ----  | ----  |
| 单元格  | 单元格 |
| 单元格  | 单元格 |
```

|  表头   | 表头  |
|  ----  | ----  |
| 单元格  | 单元格 |
| 单元格  | 单元格 |
## 对齐方式

哪边需要对其就在那边加上冒号，如果需要居中对齐就在两头都加上

```
| 这一列左对齐 | 这一列右对齐 | 这一列居中对齐 |
| :----------| ----------: | :---------: |
| 单元格      | 单元格      |    单元格    |
| 单元格      | 单元格      |  单元格       |
```

| 这一列左对齐 | 这一列右对齐 | 这一列居中对齐 |
| :----- | -----: | :-----: |
| 单元格    |    单元格 |   单元格   |
| 单元格    |    单元格 |   单元格   |
