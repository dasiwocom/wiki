## 标准语法

大多数 Markdown 处理器会自动为标题创建锚点（anchor）
假如有一个标题的名字叫做`## 二级标题`，他的身份证号码就是`#二级标题`
点击页面内嵌入的标题锚点可以快速跳转指定文件的特定标题的位置

文章内锚点

```
[Markdown标题](#Markdown标题)
```

效果：[粗体](#粗体)

外部文章锚点

```
[HTML段落](段落和换行.md#HTML段落)
```

效果：[HTML段落](段落和换行.md#HTML段落)

## 扩展语法

内部文件

```
[[文本格式（Markdown）#粗体]]
```

效果：[[文本格式（Markdown）#粗体]]

可以看到如果我们在Obsidian中打出了`[[`他会自动显示所有文件

![[Pasted image 20261004130239.png]]

选中文件之后在后面插入`#`会自动显示该文件的所有锚点

![[Pasted image 20261004130422.png]]

外部文章锚点

```
[[段落和换行#HTML段落]]
```

效果：[[段落和换行#HTML段落]]

维基双链的作用和好处还有很多，在Obisidian中使用双链会更得心应手，见 [[链接]]

> [!tip] 锚点跟着标题走
> 改了标题文字，指向它的锚点链接会全部失效。
> 所以被广泛引用的小节标题不要随便改。
