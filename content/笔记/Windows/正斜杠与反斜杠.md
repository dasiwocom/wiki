## 正斜杠 `/`

Unix、Linux、网页、URL、HTML 都使用**正斜杠 `/`**。

```
https://www.baidu.com/img/xxx.png
```

## 反斜杠 `\`

Windows 文件资源管理器（此电脑）使用**反斜杠 `\`** 分隔文件夹。例如：

```
C:\Users\windows\Pictures
```

这是微软设定的老传统，**只在 Windows 操作系统的本地文件路径中使用**。

## 历史原因

早期的 Windows 3.x 只是运行在 DOS（微软早期系统）之上的图形外壳，类似于 Linux 中的桌面环境。DOS 原本没有目录功能，而 `/` 已经被用于命令行[[单词#Argument 参数|参数]]（原文拼写 Auguments，应为 Arguments）。为避免符号冲突，微软在添加目录功能时选择了 `\` 作为目录分隔符。后来，微软开发了不再依赖 DOS 的独立 NT [[单词#Kernel 内核|内核]]（XP、Win7、Win10/11），但为了与旧软件向后兼容，一直保留了使用 `\` 的习惯。现代 Windows 实际上也支持用正斜杠 `/` 书写路径，只是系统默认显示为反斜杠。
