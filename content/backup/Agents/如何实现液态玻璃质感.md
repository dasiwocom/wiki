# 如何实现液态玻璃质感

## 你看到的现象

页面顶部有一条磨砂玻璃风格的横条，本意是把它下面滚动的内容模糊掉。有些站上效果惊艳；你的站上白天几乎看不出模糊，到了夜里颜色又开始偏移、看着不对。不管怎么调数值，总觉得哪里别扭。

## 真正发生了什么

玻璃效果来自一个 CSS 属性：

```css
backdrop-filter: blur(20px);
```

它把元素**背后**绘制的一切模糊掉。配合半透明背景，就有了磨砂玻璃的观感：

```css
.glass {
    background: rgba(255,255,255,0.6);   /* 半透明的色调 */
    backdrop-filter: blur(20px);          /* 把背后的内容磨砂化 */
}
```

三个数值决定整个效果：

| 参数 | 含义 | 调高的效果 |
| --- | --- | --- |
| `rgba(...,a)` 里的 alpha | 玻璃有多不透明 | 更不透，玻璃感更弱 |
| `blur(px)` | 背后被磨砂的程度 | 更朦胧，可读性下降 |
| `saturate(n)` | 提升背后内容的色彩浓度 | 更鲜艳，但深色主题下会变色 |

## 为什么明暗模式下表现不同

这是关键的洞察，也是整场折腾的根源。

**模糊在灰白内容上是看不见的。** 模糊滤镜的本质是把颜色抹到一起。如果背后是白纸黑字，模糊之后看起来还是白的 —— 几乎没有东西可抹。黑白配色是玻璃效果的天敌。这就是你那条白天的横条「什么都没做」的原因：它背后的内容是白底黑字，磨砂不磨砂几乎一模一样。

**饱和度在夜间是危险的。** `saturate(5)`（很多热门主题在用这个值）把色彩浓度乘五倍。在浅色背景上这显得鲜亮、高级；在深色背景上，同样的值会让每种颜色都溢出发色偏移 —— 灰色变蓝，暗红变霓虹。夜间模式把「鲜艳」变成了「崩坏」。

这也是为什么 Zibll 这类热门主题明暗模式共用一个值（`saturate(5) blur(20px)` 配 `rgba(255,255,255,0.8)`）：它们的页面在玻璃后面有彩色卡片、图片和渐变，模糊有东西可抹。而在一个极简的黑白站点上，没有东西可抹，同一套公式就显得很平。

## 怎么调

按模式用不同的值 —— 不存在万能数字：

| 模式 | alpha | blur | saturate | 为什么 |
| --- | --- | --- | --- | --- |
| 浅色（白底） | 0.5–0.65 | 24–30px | ~2 | 需要够透、磨砂够重才看得出来 |
| 深色（深底） | 0.8+ | 10–15px | 1–1.2 | 保持克制；饱和度超过 ~2 就会偏色 |

如果想要最强的效果，把背景降到 `transparent`，让模糊独自承担全部工作 —— 滚动的内容会明显地从横条里穿过去。

## 浏览器支持的坑

- `backdrop-filter` 需要 Firefox 103+（2022 年）和较新的 Chrome/Safari。老版 Firefox 会静默忽略它 —— 横条就只是透明而已。
- `-webkit-backdrop-filter` 对 Safari 和老 WebKit 仍然是必需的。
- 某些浏览器里，元素如果写了 `background: transparent`，滤镜压根不会被绘制 —— 测试时至少要给一层极淡的色调。
- 父元素带 `overflow: hidden` 或非 static 的 transform，在某些引擎里会破坏滤镜；贴在视口上的横条用 `position: fixed`。

## 真正的结论

磨砂玻璃这套风潮在彩色站点上很惊艳，因为**模糊需要颜色才抹得动**。在极简的黑白界面上，诚实的做法是让横条保持透明、让内容从后面穿过，并接受「磨砂会很微妙」这个事实。在单色站点上照搬彩色主题的玻璃配方，永远都会觉得别扭 —— 要按你自己的背景调，不是按别人的调。
