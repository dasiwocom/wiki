# 运营 dasiwo.com（WordPress 资源分享站）

## 定位

dasiwo.com 是一个**资源分享站**（达思沃）： curated「宝藏发现」—— 值得收藏的高质量网站、工具、平台。内容策略：SEO 长尾（标题驱动的推荐帖）+ 偶尔的原创技术文章。

和 docs.dasiwo.com 的内容分工：**商业/SEO → WordPress**（推荐帖），**知识/笔记 → MD2HTML**（文档知识库）。

## 选站标准（精品宝藏）

只选**高质量、功能强、值得收藏**的网站 —— 任何品类都行（工具、资源、平台、学习、娱乐…）。判断标准就一句：用户会把它加书签并回来吗？风格参考已有帖子（Steam、DBeaver、Flaticon、DeepSeek、宝塔面板…）。

## 文章要求（定稿 2026-08-16 —— 用户已确认）

```
标题:  名字｜精准概括 (15-35 字 — 最全面最精准，覆盖核心价值)
        - 每篇差异化（同类型也各不相同 —— 不要「XX 平台，提供…」模板腔）
        - 自然表达：该用逗号就用逗号 —— 不要刻意删逗号，更不要用空格堆叠
        - 目标 20-30 字最佳（平均 22 字）
        例：招商银行｜国内零售银行标杆，信用卡与财富管理行业领先

正文:   一段或两段普通文字（无 h2 小标题），~300 字左右
        - 真实细节（像 Steam/Typecho 原文：具体数据、功能、特点、背景）
        例：招商银行…「零售之王」…掌上生活 App 月活过亿…金葵花理财…
        - 概括广而全面（定位/功能/优势/适用自然融合）
        - 拒绝模板腔：「XX 是知名的 XX 平台，提供……」（每类一个模板=被否）
        - SEO：第一句含核心关键词（「XX 是全球领先的…」），关键词自然融入不堆砌

官网链接: 根域名首页（https://域名/）—— 不要子页/推广页/版权声明页
        例：豆包 → https://www.doubao.com/（不是 /chat/?channel=... 推广链接）

分类: 7 (宝藏发现)
标签:     SEO 关键词标签（中文 —— 相关 3-5 个）
别名slug: 品牌名或拼音
状态:   draft（发草稿 —— 用户确认后发布）
```

## 官网链接（自动跳转）

内容里写**纯根域名 URL** 就行 —— zibll 在保存时会自动把外链转成它的 golink 跳转格式（点击统计，无需手工处理）：

```html
官方网站：<a href="https://example.com/" target="_blank">https://example.com/</a>
```

存进库里会变成 `?golink=<base64(url)>&nonce=<auto>` —— 已验证：写纯链接就够了，zibll 自己处理跳转。

⚠️ **golink nonce 过期坑（已修 2026-08-16）**：zibll 保存时生成的 nonce 会在 12-24h 后过期，过期后点击链接报「非法请求，正在返回首页」。已在 `go.php` 里注释掉 nonce 验证（所有链接永久有效）。**主题更新会覆盖 go.php —— 升级后如果链接又报「非法请求」，需要重新注释**（备份：`/tmp/go.php.bak-20260816-111214`）。

## 生产流程（Hermes 批量）

1. 挑一个宝藏站（任意品类、高质量、尚未发布 —— 查已发布链接笔记 + 站内搜索）
2. 取信息（curl —— og:title/description/title；兜底：凭领域知识写描述）
3. 生成：标题（名字｜15-35 字，差异化）+ 正文（~300 字，真实细节，1-2 段，无 h2）+ 官网根域名那一行
4. POST 草稿到 wp/v2/posts（分类 7，状态 draft）
5. 记进已发布链接笔记（日期/标题/域名）
6. 用户审草稿并发布

## 批量生产的坑（踩坑记录 2026-08-16）

| 坑 | 根因 | 修法 |
| --- | --- | --- |
| 模板文被否（「标题内容完全一样」） | 按类型模板生成（每类一个模板） | 每篇手写真实细节，差异化标题 |
| 标题 <15 字 | 概括太短（「XX｜搜索引擎」） | 扩写至 15-35 字（平均 22） |
| 标题空格堆叠被否（「词 词 词」） | 误以为删逗号=自然 | 自然表达：该逗号就逗号 |
| 标题品牌重复（「网易 126 邮箱｜网易 126 邮箱…」） | 概括以品牌开头 | 概括开头去掉品牌名 |
| 正文仅 75 字 | 补长脚本段 2 提取失败 | 完整重写（不依赖提取） |
| 正文 ~150 字 | 补写内容本身偏短 | 两段式补到 ~300 字 |
| 官网链接指向子页/推广页（版权声明/博彩页/推广参数） | 导航站抓取的 URL 非首页 | 统一改为根域名首页 |
| 导航站抓取的链接含垃圾站（传奇私服/广告链/CDN 资源） | 导航站自带广告链接 | 发布前筛选：2345/hao123 系、游戏私服、广告子域、陌生站 → 删 |
| golink「非法请求」 | nonce 12-24h 过期 | go.php 注释 nonce 验证（主题更新会覆盖） |
| REST 批量删除失效 | urllib 的 DELETE 请求 WP 不执行 | 用 `curl -X DELETE ?force=true` |
| REST 标题匹配失败 | 标题扩写后与匹配键不一致 | 品牌关键词模糊匹配/按 id 处理 |
| 大批量文章质量下降 | 追求数量（1000 篇）导致模板化 | 质量优先：手写分批（每批 30） |

## 去重

- 维护 `dasiwo-published-links.md`（每一条已发布链接，本会话的清单）
- 生产之前：通过 wp-json 搜索 grep 一下站内 + 检查笔记
- 站点自带的链接管理器也会标记重复（wp_links 表）

## 访问方式

- REST API：https://www.dasiwo.com/wp-json/wp/v2/ （用户 dasiwobot，应用密码，管理员）
- 站点主题：zibll —— 官网链接跳转（golink），导航页通过 WP Link Manager 插件（wp_links 表）
