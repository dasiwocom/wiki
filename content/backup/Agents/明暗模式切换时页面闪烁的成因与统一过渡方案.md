## 现象

切换明暗模式时，页面元素变色速度不一致：大面积区域（背景、正文）是平滑渐变，而分割线、代码块、表格这些细节元素却「啪」地一下瞬间跳到新颜色。两种速度同时出现，视觉上就是闪烁。VitePress 官网切换主题时没有这个问题。

## 原理

### 为什么会不同步

主题切换的本质是切换 `html.dark` 这个 class。CSS 变量（如 `--line`、`--vp-c-code`）会立刻取到新值，但**元素能否平滑过渡取决于它自己有没有 `transition` 属性**，而 CSS 的 `transition` **不会被继承**。

典型的错误写法（常见坑）：

```css
/* 只给容器加过渡 */
html, body, .md, #content {
    transition: background-color .25s ease, color .25s ease, border-color .25s ease;
}
```

结果：

| 元素 | 有无 transition | 切换主题时的表现 |
|---|---|---|
| body、.md（容器） | 有 | 0.25s 渐变 |
| `.md h2` 的上边框、`hr` 分割线 | 无 | 瞬间跳变 |
| `.md code`、`.md pre`（代码块） | 无 | 瞬间跳变 |
| `.md table`、`th`、`td` 边框 | 无 | 瞬间跳变 |

主体在慢慢渐变，装饰性细节却在瞬变，两套时间线撞在一起，就成了闪烁。

### 为什么 VitePress 没这个问题

VitePress 给**所有元素、包括伪元素**统一加了颜色过渡：

```css
*, *::before, *::after {
    transition: background-color .25s ease, color .25s ease, border-color .25s ease;
}
```

每个会变色的元素都用相同的时长和缓动函数，动画完全同步，自然不闪。

## 解决方案

### 方案 1：全局统一过渡（推荐，VitePress 式）

```css
*, *::before, *::after {
    transition: background-color .25s ease, color .25s ease, border-color .25s ease;
}
```

一次改到位，以后新增的元素自动参与同步过渡。

**三个重要注意点**：

1. **会覆盖已有动画**：通用选择器 `*` 的优先级极低。如果某个元素本来有基于 `transform` / `opacity` 的动画（抽屉滑出、toast 淡入），要用**更高优先级的选择器去覆盖它的 transition**。注意：`transition` 赋值是整体替换，不是逐项合并。

2. **hover / active 变色变慢**：全局规则会给 hover 触发的颜色变化也套上 0.25s 渐变。如果需要 hover 立刻反馈，得考虑这个副作用。（本项目已经移除了 hover 变色规则，预计不会冲突。）

3. **`transition: none !important` 会关掉主题过渡（反复踩的坑）**：为了修视图切换的闪烁而加 `transition: none !important`，同时也会把这个区域的主题切换动画一起干掉，瞬间跳变型闪烁又回来了。`!important` 能压过全局 `*` 规则，全局规则反过来压不过它。
> 正确做法：视图切换的闪烁在 JS 侧解决（内容渲染完成后再插入、操纵 `display`），不要用 `transition: none !important`。如果某些组件（比如做 transform 动画的图标）确实需要自定义过渡，就在它的 `transition` 值里**显式带上 `color`、`background-color`、`border-color`**，而不是把过渡整个抹掉。

> **真实案例（语法高亮的代码块）**：接入 highlight.js 给 token 上色（`.hljs-keyword`、`.hljs-string` …）之后，切换主题时代码块区域会闪。当时的修法是给 token 和复制按钮加 `transition: none !important`。结果更糟：token 瞬间跳变，而 `pre` 的背景和页面其余部分还在 0.25s 渐变，整块区域相对页面明显「跳了一下」。正确的修法是**把代码块里所有 `transition: none !important` 全部删掉，让所有元素（包括 `.hljs-*` token 和复制按钮）跟随全局 `*` 过渡**。另外，代码块背景要用和页面背景同一族的变量（比如 `--vp-c-bg-soft`，而不是另起一个 `--code-bg`），这样背景和页面走的是同一条颜色插值路径。识别这个症状的诀窍：不是块内部的动画抽风，而是**整块（背景、边框、token、按钮）和页面变色的速度不一样**。凡是「别人都在渐变、就它瞬变」的区域，几乎一定是某个元素写了 `transition: none !important`（或者压根没写 transition），不是重绘问题。

### 方案 2：按需逐个补过渡

只给缺失的细节元素加 transition：

```css
.md h2, .md hr, .md code, .md pre, .md table, .md th, .md td,
.md blockquote, .archive-item {
    transition: background-color .25s ease, color .25s ease, border-color .25s ease;
}
```

优点：不动无关的动画。
缺点：以后新增组件容易忘记补，同样的 bug 会再犯。

## 小结

- 主题切换闪烁的根因：**`transition` 不继承**。容器有过渡、子级的细节元素没有，一次主题切换里跑着两套动画时间线。
- 首选修法：给所有元素和伪元素套上一致的颜色过渡规则，做到完全同步。
- 通用原则：整页换色的动画，过渡规则必须覆盖**每一个会变色的元素**，不能只覆盖顶层容器。
