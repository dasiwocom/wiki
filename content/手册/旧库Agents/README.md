# 这是什么

`content/Agents/` 是 AI 在这个 wiki 里的独立工作区，由所有者划给 AI 的自由空间。

## 接手指南（新 Agent 按顺序做）

1. 读本文件，了解边界和保护名单。
2. 读 [[用户档案]]，了解所有者是谁、什么水平、在意什么。
3. 读 [[协作规则]]，了解写作格式和绝对不能做的事。
4. 读 [[日志]]，看最近做过什么，避免重复劳动。
5. 开工。做完在 [[日志]] 追加一行，新产出放 `产出/`。

## 保护名单（完全不能动）

所有者划定的禁区，**不许改名、移动、删除、改写内容**：

- `index.md` — 首页
- `Templates/` — 模板。可以往里**添加**文件，但目录本身必须在顶层，不能挪走或改名
- `Attachments/` — 图片。可以**添加**图片，不能删不能挪
- `不在五行之中/` — 小说，所有者自己写
- `Excalidraw/` — Excalidraw 插件会自动往这里写文件，不要删这个目录

## 可自由操作

- `Agents/` — 本目录，AI 完全自主
- `Knowledge/` — 知识笔记
- `Profile/` — 个人档案
- `Journal/` — 日记 / 时间线
- `Prompts/` — 提示词与笔记规范

## 写笔记前必读

`Prompts/Wiki个人知识库Agents生成笔记规范/` 下有 8 份规范文件（00-总纲 到 07-外部资源与多媒体）。

**写任何笔记前先读 `00-总纲.md`**，它规定了：写多细、什么视角、排版怎么排、frontmatter 怎么填、怎么引外部资料。

日常写单篇带 `00 + 01 + 02 + 04`；写系列再加 `05`；讲实操/技术再加 `07`。

这套规范在 2026-10-07 被误删过，已从 git 提交 `34c66c5^` 恢复。别再弄丢。

## 红线

- 不碰保护名单里的任何一项（添加图片和模板除外）。
- 不删文件。要归档就加 `draft: true`。
- 不把密钥、密码、API Key 写进任何笔记。
- 技术内容必须引外部资料，先查再写，不靠记忆。
- 速记里没说清的线索，标"待查证"，不要替他补全。
- 拿不准就问，不要猜。

## 关键约定

- **双链按文件名解析**。写 `[[用户档案]]` 就能链到 `上下文/用户档案.md`，不需要路径。移动文件不会断链，所以整理目录很安全。
- **frontmatter `title` 留空**，页面标题自动取文件名。这是所有者的既定习惯。
- **只填 `description`**，其余字段留空，除非所有者要求（比如批量填 tags）。
- 每篇产出都要有 `description`，否则列表页是空的。

## 给人类看的说明

这个目录在站点上就是普通页面，侧边栏能直接点开。

想看 AI 最近干了什么 → `日志.md`。

想看交付物 → `产出/`。

> [!warning] 隐私
> `上下文/用户档案.md` 汇总了所有者的个人信息。这个站是公开的，正式发布前请自己决定要不要给它加 `draft: true`（加了就不发布，但 AI 仍能读到）。
