## 写入范围

默认只写 `content/Agents/`。

要动其他地方，必须当次明确授权，且只动指定的文件。

## frontmatter 规范

模板四字段：`title` / `aliases` / `tags` / `description`，加 `draft: false`。

惯例：

- `title` **留空**。留空时页面标题自动取文件名，`contentIndex.json`、`<title>`、页内 `<h1>` 三处一致。
- `aliases` 留空。
- `tags` 留空，除非所有者明确要求批量填（例如英语笔记填 `英语`）。
- **`description` 必须填**，否则列表页显示空白。
- `draft: false` 才发布；不想发布的改 `true`（不删文件）。

## 正文排版

- **硬换行已开启**（`quartz.config.yaml` 里 `hard-line-breaks: enabled: true`）。
- 源码里按一次回车就换行，空行才分段。
- 写法是**一行一句话**，不要写成长段落。

## 已实测的语法支持情况

支持：

- callout 全类型 + 别名（会自动归一化）
- 脚注、KaTeX、mermaid
- `![[图.png|200]]` 指定宽度
- 块 ID、注释 `%%`、内联 HTML

不支持：

- emoji 短代码 `:smile:`
- 定义列表
- 行内 `#标签`（不生成标签链接）
- `^2^` / `~2~`
- `![[x.html]]`、`![[x.mp4]]`
- Dataview

## 链接

- 双链 **按文件名解析**：`[[用户档案]]` 能链到任意目录下的 `用户档案.md`。
- 移动文件不会断链，所以整理目录很安全。
- 外部链接直接写 URL，会被渲染成可点击链接。

## 排序机制

`@quartz-community/explorer` 按 `displayName` 做 `localeCompare(numeric: true, sensitivity: "base")`。

推论：**路线图 / 入口页要用 `00-` 前缀**。

不加序号的话，中文开头的名字会排到 `01-`~`13-` 后面，读者要滚到底才看到入口。

系列笔记用 `NN-` 前缀，词典式条目（角色、设定）不加前缀。

## 日期机制

frontmatter 里 `date` 无人读取。

真正生效的是 `created` / `modified` / `published`，未填则回退 git 提交时间 → 文件 mtime。

`quartz.config.yaml` 里 `defaultDateType: modified`，所以默认显示"最后修改时间"，每次编辑都会变。

想显示固定创建日期，要写 `created:` 并把 `defaultDateType` 改成 `created`。

## 样式

改外观只动 `quartz/styles/custom.scss`。

它在构建时拼在框架样式之后，且不在 `@layer quartz-base` 里，优先级天然更高。

**不要改 `quartz/` 下的框架文件。**

## 构建

- 命令：`npx quartz build -o <临时目录>`
- 默认输出到 `public/` 会被安全策略拦截，必须指定 `-o`
- 一次约 1.5–3 分钟
- **构建和 push 由所有者自己做，不要提醒他，也不要替他执行**

## 红线清单

- 不删文件。归档用 `draft: true`。
- 不擅自改他的源码和工程文件（Keil `main.c` 这类）。
- 不写密钥、密码、API Key。
- 技术内容必须引外部资料，先查再写，不靠记忆。
- 速记里没说清的线索，标"待查证"，不要替他补全。
