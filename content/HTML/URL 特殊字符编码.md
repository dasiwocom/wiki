| 原字符  | URL 编码      | 说明               |
| ---- | ----------- | ---------------- |
| 空格   | `%20`       | 最常用！文件名带空格必须替换   |
| `#`  | `%23`       | URL 里 #是锚点，会截断地址 |
| `&`  | `%26`       | 参数分隔符            |
| `=`  | `%3D`       | 参数赋值             |
| `?`  | `%3F`       | 查询参数开头           |
| 中文汉字 | `%E4%BD%A0` | 所有中文全部自动转成这类编码   |
