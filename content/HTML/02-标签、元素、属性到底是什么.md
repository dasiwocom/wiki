# 标签、元素、属性到底是什么

这三个词天天混着用，但它们指的不是一件事。

## 标签

标签就是尖括号包起来的那一小段：

```text
<p>
</p>
```

带斜杠的 `</p>` 是结束标签，不带的是开始标签。

标签本身不显示，它只是给浏览器下的指令。

## 元素

开始标签 + 里面的内容 + 结束标签，三样合起来叫一个元素：

```text
<p>这是一个段落。</p>
```

所以 `<p>` 是标签，`<p>这是一个段落。</p>` 是元素。

日常说话时两者混用没什么问题，但看到文档里说"块级元素"时，指的是整个这个结构。

## 空元素

有些标签天生没有内容，不需要结束标签：

```html
<br>
<hr>
<img src="a.png" alt="示例">
<input type="text">
<meta charset="UTF-8">
```

这类叫空元素（也叫自闭合元素）。在 HTML5 里，写成 `<br>` 和 `<br />` 都对，加不加那个斜杠随意。

XHTML 时代必须加，现在不用管。

## 属性

属性写在开始标签里，用来补充说明这个元素的细节：

```html
<a href="https://www.runoob.com">菜鸟教程</a>
<img src="photo.jpg" alt="一张照片" width="300">
```

属性永远是"名字 = 值"的形式，值外面那对引号不能省。

单引号和双引号都行，习惯上用双引号。属性之间的先后顺序随意，不影响结果。

属性的值里如果要出现同种引号，就换成另一种引号包起来：

```html
<p title='他说"你好"'>段落</p>
```

## 布尔属性

有些属性只有"有"和"没有"两种状态，写法上不用给值：

```html
<input type="text" disabled>
<input type="checkbox" checked>
```

写了就是生效，不写就是不生效。写成 `disabled="disabled"` 或 `disabled="true"` 也都是"生效"，但没必要。

## 标签必须正确嵌套

像括号一样，先开的后关：

```html
<p><strong>加粗的文字</strong></p>
```

下面这种交叉了，是错的：

```html
<p><strong>加粗的文字</p></strong>
```

浏览器遇到错的嵌套会自己猜着修，但修出来的结果不一定是你想要的，所以别指望它。

## 大小写

HTML 的标签名不区分大小写，`<P>`、`<p>`、`<Title>`、`<TITLE>` 是一样的。

但习惯上一律写小写，一是读起来清爽，二是 XHTML 和很多工具都要求小写。

属性的值大多也不区分大小写，但有些值有意义——比如 `type="text"` 的 `text`，最好按规范写。

## 常用标签一张表

| 用途 | 标签 |
| --- | --- |
| 文档结构 | `html` `head` `body` |
| 标题 | `h1` ~ `h6` |
| 段落、换行、分隔线 | `p` `br` `hr` |
| 文字强调 | `strong` `em` `mark` `del` `ins` `sub` `sup` |
| 链接和图片 | `a` `img` |
| 列表 | `ul` `ol` `li` `dl` `dt` `dd` |
| 表格 | `table` `tr` `th` `td` |
| 表单 | `form` `input` `label` `select` `textarea` `button` |
| 分区 | `div` `span` `header` `nav` `main` `footer` |
| 嵌入外部内容 | `iframe` `video` `audio` |

后面每一篇讲的都是这张表里的内容。

## 注释

注释写给自己看，浏览器不会显示：

```html
<!-- 这里是注释，随便写 -->
```

跨行的也行，但注意不能嵌套——注释里再写 `<!--` 会让浏览器找错结束位置。
