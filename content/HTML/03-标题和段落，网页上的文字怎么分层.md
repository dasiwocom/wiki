# 标题和段落，网页上的文字怎么分层

一个页面上大部分内容是文字，而文字要靠标题分组、靠段落断句。

## 六级标题

HTML 提供六个级别的标题，从 `<h1>` 到 `<h6>`，一级最大。

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题</h6>
```

↓ 渲染出来是这样：

<h3>三级标题</h3>
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题</h6>

字越往下越小，字号是浏览器默认给的效果，用 CSS 可以改成任何样子。

## 别为了字号去挑级别

这是最常见的一个误用。

看到三级标题太小、想换成一级让它大一点——这样写出来的页面，标题层级就乱了。

标题表达的是"这块内容属于谁"，字号是 CSS 的事。层级对了，字号想怎么调都行。

## 不要跳级

从 `<h1>` 直接跳到 `<h3>`，等于目录里只有"第一章"和"1.1.1"，中间的 1.1 不见了。

正确的用法是逐级往下：

```text
h1  这个页面讲什么
├── h2  第一节
│   ├── h3  1.1
│   └── h3  1.2
└── h2  第二节
```

跳级不只是看着别扭，屏幕阅读器和搜索引擎靠标题来理解页面结构，跳级会让它们读不懂。

## 一个页面通常只有一个 h1

`<h1>` 是页面的主标题，一般和 `<title>` 对应，全页只出现一次。

如果页面上有多个并列的板块，每个板块用 `<h2>` 开头。

## 段落

段落用 `<p>`：

```html
<p>这是第一个段落。</p>
<p>这是第二个段落。</p>
```

↓ 渲染出来是这样：

<p>这是第一个段落。</p>
<p>这是第二个段落。</p>

浏览器会自动在段落之间留出空隙，你不用手动空行。

## 源码里的换行不算换行

这一点和 Markdown 不一样，注意区分：

```html
<p>
  这几行在源码里
  是分开写的
  但页面上会连成一行
</p>
```

↓ 渲染出来是这样：

<p>
  这几行在源码里
  是分开写的
  但页面上会连成一行
</p>

源码里的换行只是为了方便你自己读，浏览器会把它当成一个空格。

真要在页面上换行，得写 `<br>`：

```html
<p>第一行<br>第二行</p>
```

`<br>` 只用于"这一行和下一行本来就是一件事"的场合，比如地址、诗句。

想分成两段，用两个 `<p>`，别用一堆 `<br>` 去凑间距。

## 分隔线

`<hr>` 画一条横线，用来分隔内容：

```html
<hr>
```

它是空元素，没有结束标签。

不过要注意：`<hr>` 表达的是"这里和上面是两回事"，不是"我想要一条线"。纯装饰性的线交给 CSS。

## 一段示例

把标题、段落、换行、分隔线放一起：

```html
<h1>怎么给自行车换内胎</h1>

<h2>准备工作</h2>
<p>需要撬胎棒、新内胎和打气筒。</p>

<h2>步骤</h2>
<p>第一步：把轮胎从车架上拆下来。<br>
第二步：用撬胎棒把外胎撬开一角。</p>

<hr>

<p>如果外胎上有破口，新内胎装进去还会被扎破，先查外胎。</p>
```

## 顺便说一句

写 HTML 时不要用 `<p>` 去凑空行、不要用 `<h3>` 去调字号，这类"为了好看"的写法后面都要用 CSS 重做一遍。

结构和样式分开，是这套东西里最基本的一条规矩。
