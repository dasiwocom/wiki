# 列表，无序、有序、嵌套和描述列表

列表在网页上到处都是：导航栏是列表，菜单是列表，一篇文章的要点也是列表。

## 无序列表

不在乎先后的条目，用 `<ul>` 包起来，每项用 `<li>`：

```html
<ul>
  <li>撬胎棒</li>
  <li>新内胎</li>
  <li>打气筒</li>
</ul>
```

↓ 渲染出来是这样：

<ul>
  <li>撬胎棒</li>
  <li>新内胎</li>
  <li>打气筒</li>
</ul>

前面的小圆点是浏览器默认给的，样式交给 CSS 就能改。

## 有序列表

有先后顺序的用 `<ol>`：

```html
<ol>
  <li>把轮胎从车架上拆下来</li>
  <li>用撬胎棒把外胎撬开一角</li>
  <li>抽出旧内胎，塞进新内胎</li>
</ol>
```

↓ 渲染出来是这样：

<ol>
  <li>把轮胎从车架上拆下来</li>
  <li>用撬胎棒把外胎撬开一角</li>
  <li>抽出旧内胎，塞进新内胎</li>
</ol>

编号是自动生成的，你插一条、删一条，后面的编号自己会重排。

## 别手写编号

新手常这么干：

```html
<ul>
  <li>1. 第一步</li>
  <li>2. 第二步</li>
</ul>
```

这样写，中间插入一步就得手动改后面所有的编号。

该有编号就用 `<ol>`，编号让浏览器去管。

## 编号可以调

`<ol>` 有几个属性控制编号：

```html
<ol start="5">        <!-- 从 5 开始编号 -->
<ol reversed>         <!-- 倒着数 -->
<ol type="A">         <!-- 用 A B C 编号（type 可为 1 A a I i） -->
```

单项还能单独指定：`<li value="10">`。

这些都不常用，但排查别人写的页面时可能遇到。

## 嵌套列表

`<li>` 里面再放一个 `<ul>` 或 `<ol>`，就是子列表：

```html
<ul>
  <li>准备工作
    <ul>
      <li>撬胎棒</li>
      <li>补胎片</li>
    </ul>
  </li>
  <li>动手
    <ol>
      <li>拆轮子</li>
      <li>撬外胎</li>
    </ol>
  </li>
</ul>
```

↓ 渲染出来是这样：

<ul>
  <li>准备工作
    <ul>
      <li>撬胎棒</li>
      <li>补胎片</li>
    </ul>
  </li>
  <li>动手
    <ol>
      <li>拆轮子</li>
      <li>撬外胎</li>
    </ol>
  </li>
</ul>

注意子列表是写在 `<li>` 里面的，不是写在两个 `<li>` 中间。写错位置，列表就会从里面断掉。

注意看上面的源码——`<li>` 里的文字写完，接着写 `<ul>`，最后才关掉 `</li>`。

## 列表里放别的东西

`<li>` 里除了文字，还能放任何东西：段落、图片、链接、另一个列表。

```html
<li>
  <p>第一段说明。</p>
  <img src="step.png" alt="步骤示意图">
</li>
```

## 描述列表

不是"几项"，而是"几个词各自对应一段解释"的时候，用描述列表：

```html
<dl>
  <dt>内胎</dt>
  <dd>轮胎里那圈橡胶管，破了就漏气。</dd>

  <dt>撬胎棒</dt>
  <dd>用来把外胎从轮圈上撬开的塑料工具。</dd>
</dl>
```

↓ 渲染出来是这样：

<dl>
  <dt>内胎</dt>
  <dd>轮胎里那圈橡胶管，破了就漏气。</dd>
  <dt>撬胎棒</dt>
  <dd>用来把外胎从轮圈上撬开的塑料工具。</dd>
</dl>

`<dt>` 是要解释的词，`<dd>` 是解释内容。

一个 `<dt>` 可以配多个 `<dd>`，比如一个词有多种解释。

术语表、参数表、名词对照，用这个比用 `<ul>` 加破折号规范。

## 导航栏也是列表

以后你会看到大量这种写法：

```html
<nav>
  <ul>
    <li><a href="/">首页</a></li>
    <li><a href="/about.html">关于</a></li>
  </ul>
</nav>
```

导航栏在结构上就是一串链接，所以写成列表最合适。小圆点是靠 CSS 去掉的。
