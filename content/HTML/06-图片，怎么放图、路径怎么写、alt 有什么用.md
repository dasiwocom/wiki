# 图片，怎么放图、路径怎么写、alt 有什么用

放一张图只要一个标签，难的是那几行属性该写什么。

## 最小的写法

```html
<img src="photo.jpg" alt="一张照片">
```

`<img>` 是空元素，没有结束标签。

两个属性：

- `src` 是图片的地址
- `alt` 是图片的替代文字

## alt 不是可选项

很多人以为 `alt` 是"图片加载失败时显示的"，所以随便填个字。

它其实有三个作用，按重要性排：

1. 图片加载不出来时，页面上显示的就是它
2. 屏幕阅读器会把它读出来，让看不见的人知道这里有什么
3. 搜索引擎靠它理解图片内容

所以 `alt` 应该描述"这张图在讲什么"，而不是"这是一张图片"。

| 图片 | 差的 alt | 好的 alt |
| --- | --- | --- |
| 产品照 | `图片` | `黑色的机械键盘，右侧带数字小键盘` |
| 流程图 | `图1` | `登录流程图：输入手机号 → 收验证码 → 填验证码 → 进入首页` |
| 纯装饰的线条 | 留空 | 留空 |

纯装饰性的图，把 `alt` 写成空字符串 `alt=""`，屏幕阅读器会直接跳过它，这是正确做法。

## 图片不显示的时候

故意写一个不存在的路径，看看效果：

<img src="这张图不存在.png" alt="图片没加载出来时，就显示这段 alt 文字">

页面上出现的是 alt 里的文字，而不是空白。这就是为什么 alt 要好好写。

## 路径怎么算

和链接的路径规则完全一样：

| 图片和当前页面的关系 | 写法 |
| --- | --- |
| 同一个目录 | `photo.jpg` |
| 下一级目录 | `images/photo.jpg` |
| 上一级目录 | `../photo.jpg` |
| 别的网站 | `https://example.com/photo.jpg` |

目录和文件名里尽量只用小写字母、数字、连字符。

中文名和空格在浏览器里会被转义成 `%20` 之类，虽然能用，但复制来复制去很容易出错。

大小写也要注意：Windows 上文件名不区分大小写，传到你不知道是什么系统的服务器上就认死理了，`Photo.jpg` 和 `photo.jpg` 是两个文件。

## 尺寸

```html
<img src="photo.jpg" alt="示例" width="300" height="200">
```

`width` 和 `height` 只写数字，单位是像素，不要写 `px`。

但要注意：在 HTML 里写死尺寸，图片会被硬拉伸变形，而且在手机上不会自适应。

更好的做法是**只写宽高用来占位**（防止图片加载出来时页面跳动），实际显示大小交给 CSS：

```css
img {
  max-width: 100%;
  height: auto;
}
```

这几行让图片永远不会超出容器宽度，是响应式页面必备的一条。

## 图片说明

图片下面要配说明文字时，用 `<figure>` 和 `<figcaption>`：

```html
<figure>
  <img src="shiyan.jpg" alt="实验装置接线图">
  <figcaption>图 1：实验装置的接线方式</figcaption>
</figure>
```

这样图和说明在结构上绑定在一起，屏幕阅读器会把它们当一个整体。

## 加载优化

```html
<img src="photo.jpg" alt="示例" loading="lazy">
```

`loading="lazy"` 让这张图滚到可见位置才开始加载。

页面上图片多的时候加上它，能明显减少首屏加载量，尤其是长文章里几十张图的情况。

首屏一定会看到的图别加，那会拖慢第一眼的速度。
