## 一、路径是什么

做网页时，图片、样式、文件、页面跳转，**都需要告诉浏览器资源在哪里**。

这个「资源的地址」，就叫 **路径**。

网页里的路径分两种：1. 绝对路径 2. 相对路径
## 二、绝对路径

从**电脑最根部**开始写的完整地址，从头到尾写死，完整唯一。

本地绝对路径：

```
C:/Users/xxx/Desktop/html/images/1.png
```

网络绝对路径：

```
https://markdown.com.cn/basic-syntax/index.htm
```
## 三、相对路径（网页最常用）

**不写完整地址**，一切位置，**相对于当前网页文件**来找资源。
## 四、相对路径三大核心符号

### 1. `./` 当前目录

代表：**当前网页所在的文件夹** 可以省略不写

示例：当前文件夹里的图片

```
./images/1.png
等价于
images/1.png
```

### 2. `../` 上一级目录

代表：**退出当前文件夹，回到外面一层** 层级不够、文件不在同级时必须写

场景：

- 网页在 html 文件夹
- 图片在和 html 同级的 images 文件夹

写法：

```
../images/1.png
```

### 3. 文件夹名/ 进入子文件夹

往下进入下一级目录，一直拼接即可

## 五、目录层级实战（最常用结构）

结构示例：

```
项目文件夹
 ├─ html（网页文件放这里）
 └─ images（图片放这里）
```

网页在 html 文件夹，图片在同级 images

正确路径：

```
../images/图片名.png
```

解析：

1. `../` 跳出 html 文件夹
2. `images/` 进入图片文件夹
