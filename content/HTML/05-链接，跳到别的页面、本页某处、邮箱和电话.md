# 链接，跳到别的页面、本页某处、邮箱和电话

网页之所以叫"网页"，就是因为页面之间能互相连起来。干这件事的标签是 `<a>`。

## 最基本的写法

```html
<a href="https://www.runoob.com/html/html-links.html">菜鸟教程的链接章节</a>
```

↓ 点一下试试：

<a href="https://www.runoob.com/html/html-links.html">菜鸟教程的链接章节</a>

`href` 是目标地址，标签中间的文字是页面上显示的、可点击的部分。

## 当前窗口还是新窗口

默认在当前标签页打开，会把原来的页面顶掉。

想开新窗口，加 `target="_blank"`：

```html
<a href="https://developer.mozilla.org/zh-CN/" target="_blank" rel="noopener">MDN</a>
```

↓ 点一下试试（会在新标签页打开）：

<a href="https://developer.mozilla.org/zh-CN/" target="_blank" rel="noopener">MDN</a>

`rel="noopener"` 建议一起写上。新开的页面如果拿到 `window.opener`，可以偷偷把你原来的页面改成钓鱼页，加上这个属性就切断了这层联系。现代浏览器已经默认这么做，但写上去不亏。

## 内部链接：相对路径和绝对路径

指向自己站内的页面，地址有两种写法：

| 写法 | 例子 | 含义 |
| --- | --- | --- |
| 绝对路径 | `https://example.com/about.html` | 写全，从协议开始 |
| 根相对路径 | `/about.html` | 从网站根目录算起 |
| 文档相对路径 | `about.html` | 和当前页面同一个目录 |
| 文档相对路径 | `../about.html` | 上一级目录 |
| 文档相对路径 | `img/logo.png` | 下一级目录 |

站内链接优先用相对路径，将来换域名、换目录都不用改。

`..` 表示上一级，可以叠着用：`../../about.html`。

## 跳到本页的某一节

给目标元素起个 `id`，链接里写 `#id`：

```html
<h2 id="part-2">第二节</h2>

<a href="#part-2">跳到第二节</a>
```

`id` 在同一份文档里必须唯一，不能有两个元素用同一个 id。

只用 `#`（`href="#"`）表示回到页面最顶部，是很多"返回顶部"按钮的写法。

此外还有一种老写法，用一个 `<a name="xxx">` 当锚点。它在 HTML5 里已经被 `id` 取代，新代码不要再用。

## 邮件和电话

```html
<a href="mailto:someone@example.com">给我发邮件</a>
<a href="tel:+8613800138000">打电话给我</a>
```

在手机上点电话链接会直接跳到拨号界面，这在移动端很好用。

`mailto:` 还可以预填主题和正文：

```html
<a href="mailto:a@b.com?subject=咨询&body=你好">带主题的邮件</a>
```

## 链接文字要能看懂

这是无障碍里最容易忽略的一条。

不要写：

```html
<a href="/report.pdf">点这里</a>
```

要写：

```html
<a href="/report.pdf">下载 2026 年第一季度报告（PDF，1.2 MB）</a>
```

屏幕阅读器可以把页面里所有链接单独列出来朗读，如果全是"点这里""更多"，用户根本不知道点进去是什么。

顺便把"这是个下载文件"和格式、大小也写进去，读者能自己决定要不要点。

## 图片当链接

`<a>` 里可以放图片：

```html
<a href="/"><img src="logo.png" alt="回到首页"></a>
```

这时候 `alt` 就承担了链接文字的作用，更要写清楚。

## 下载链接

在 `<a>` 上加 `download`，点击会变成下载而不是打开：

```html
<a href="/files/manual.pdf" download>下载使用手册</a>
```

可以顺便指定下载后的文件名：`download="使用手册.pdf"`。
