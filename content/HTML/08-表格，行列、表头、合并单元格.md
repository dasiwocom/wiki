# 表格，行列、表头、合并单元格

表格用来放"行列都有的数据"，比如参数对比、课程表、成绩单。

## 最小结构

```html
<table>
  <tr>
    <th>型号</th>
    <th>电压</th>
    <th>价格</th>
  </tr>
  <tr>
    <td>STC89C52RC</td>
    <td>5V</td>
    <td>5 元</td>
  </tr>
  <tr>
    <td>AT89C51</td>
    <td>5V</td>
    <td>8 元</td>
  </tr>
</table>
```

↓ 渲染出来是这样：

<table>
  <tr>
    <th>型号</th>
    <th>电压</th>
    <th>价格</th>
  </tr>
  <tr>
    <td>STC89C52RC</td>
    <td>5V</td>
    <td>5 元</td>
  </tr>
  <tr>
    <td>AT89C51</td>
    <td>5V</td>
    <td>8 元</td>
  </tr>
</table>

四个标签分工：

| 标签 | 含义 |
| --- | --- |
| `<table>` | 整张表 |
| `<tr>` | 一行（table row） |
| `<td>` | 一个普通单元格（table data） |
| `<th>` | 表头单元格（table header），默认加粗居中 |

## 表头一定要用 th

表头用 `<td>` 加上加粗，看着一样，但屏幕阅读器读不出"这一列是什么"。

用 `<th>` 之后，读屏软件在念到某个单元格时会先报它的列名："电压，5V"。

数据表一律用 `<th>`。

## 表格标题

想给整张表加个说明，用 `<caption>`，写在 `<table>` 里的第一行：

```html
<table>
  <caption>表 1：常见 51 单片机型号对比</caption>
  <tr>...</tr>
</table>
```

`<caption>` 是给表格用的，别用 `<h3>` 硬凑在表格上面。

## 分成表头、表身、表尾

长表格可以分三段：

```html
<table>
  <thead>
    <tr><th>月份</th><th>支出</th></tr>
  </thead>
  <tbody>
    <tr><td>一月</td><td>1200</td></tr>
  </tbody>
  <tfoot>
    <tr><td>合计</td><td>1200</td></tr>
  </tfoot>
</table>
```

这样浏览器打印长表格时，每页都会重复表头。

`<thead>` 和 `<tfoot>` 都只能有一个，`<tbody>` 可以有多个。

## 合并单元格

横向合并用 `colspan`，纵向合并用 `rowspan`，值是"占几格"：

```html
<table>
  <tr>
    <th>季度</th>
    <th>一月</th>
    <th>二月</th>
  </tr>
  <tr>
    <td rowspan="2">上半年</td>
    <td>1200</td>
    <td>1500</td>
  </tr>
  <tr>
    <td>1800</td>
    <td>900</td>
  </tr>
</table>
```

↓ 渲染出来是这样：

<table>
  <tr>
    <th>季度</th>
    <th>一月</th>
    <th>二月</th>
  </tr>
  <tr>
    <td rowspan="2">上半年</td>
    <td>1200</td>
    <td>1500</td>
  </tr>
  <tr>
    <td>1800</td>
    <td>900</td>
  </tr>
</table>

"上半年"这一格纵向占了 2 行，所以下面那行少写一个 `<td>`——**被占掉的位置不用再补格子**。

这是合并最容易错的地方：多写一个 `<td>`，整张表就歪了。

## 表格里没有的地方

表格只管结构，不管样子：

- 单元格宽度、边框、底色、文字居中 → 全是 CSS
- 表格里想换行 → 用 `<br>`，不能直接按回车

在 HTML 里写 `border="1"` 之类，是 HTML4 时代的老写法，现在虽然还能显示，但应该用 CSS。

## 别用表格排版

早期的网页用表格来摆版面：左边的表格当侧栏，右边的表格当正文。

现在没人这么干了，因为：

- 手机上表格不会自适应，横向直接溢出
- 屏幕阅读器会把整个页面当成一张数据表来念，完全没法听
- 改一处布局要动一大片表格

排列版面的事，交给 CSS 的 flex 和 grid（[[10-把页面分区，div、span 和那些语义标签|下一篇]]里会说到分区标签）。

判断标准很简单：**这些内容是不是"行列对应的数据"**。是，用表格；不是，用别的。
