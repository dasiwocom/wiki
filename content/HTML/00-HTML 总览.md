# HTML 总览

这一组共 13 篇，按顺序排好了：从"一个网页文件到底长什么样"开始，到"页面出了毛病怎么查"。

每一篇的末尾都有一行导航，打开第 1 篇一路点"下一步"就能顺着读完，随时点"路线图"回到这里。

已经知道 HTML 大概是怎么回事，只想查某个标签怎么用，直接在下面的篇目表里找。

## 写 HTML 的几条习惯

这几条能让你少返工。

**先想结构，再想样子**。用标签描述"这块内容是什么"，长什么样留给 CSS。在 HTML 里写 `border`、`align`、`font` 都是上一代的做法。

**该用语义标签就别用 div**。`<nav>`、`<main>`、`<article>` 写出来不比你多花时间，但对读屏软件和搜索引擎都友好。

**标签一律小写，属性值一律加引号**。不影响显示，但能少踩坑、方便别人看。

**每层缩进两个空格**。HTML 嵌套很深，不缩进三天后自己都读不懂。

**写完拿校验器过一遍**。把代码贴进 [W3C 校验器](https://validator.w3.org/)，它会指出没闭合的标签、写错的属性。比肉眼找快得多。
