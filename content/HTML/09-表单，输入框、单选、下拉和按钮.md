# 表单，输入框、单选、下拉和按钮

表单是页面上唯一"双向"的东西：别的标签都是往外显示，表单是往里收。

## 最外层是 form

```html
<form action="/submit" method="post">
  ...里面放各种输入控件...
</form>
```

- `action` 是数据提交到哪个地址
- `method` 是提交方式，`get` 把数据拼在网址后面，`post` 放在请求体里

登录、注册、搜索这类都要用 `post`，因为 `get` 会把密码、手机号明晃晃地显示在地址栏和浏览器历史里。

## 最常见的输入控件：input

`<input>` 是空元素，靠 `type` 属性变换形态：

```html
<input type="text" name="username" placeholder="请输入用户名">
<input type="password" name="pwd">
<input type="email" name="mail">
<input type="number" name="age" min="1" max="100">
<input type="date" name="birthday">
<input type="checkbox" name="hobby" value="reading">
<input type="radio" name="gender" value="male">
<input type="file" name="avatar">
<input type="color" name="theme">
<input type="range" name="volume" min="0" max="100">
```

↓ 渲染出来是这样：

<p>
  <input type="text" name="demo-text" placeholder="请输入用户名">
  <input type="password" name="demo-pwd" placeholder="密码">
  <input type="email" name="demo-mail" placeholder="邮箱">
  <input type="number" name="demo-age" min="1" max="100" placeholder="年龄">
  <input type="date" name="demo-date">
</p>
<p>
  <input type="checkbox" name="demo-hobby" value="reading"> 阅读
  <input type="radio" name="demo-gender" value="male"> 男
  <input type="radio" name="demo-gender" value="female"> 女
  <input type="file" name="demo-file">
  <input type="color" name="demo-color">
  <input type="range" name="demo-volume" min="0" max="100">
</p>

| type | 长什么样 | 用在哪 |
| --- | --- | --- |
| `text` | 单行文本框 | 姓名、地址 |
| `password` | 输入内容显示成圆点 | 密码 |
| `email` | 文本框，提交时校验格式 | 邮箱 |
| `number` | 带上下箭头的数字框 | 数量、年龄 |
| `date` | 日期选择器 | 出生日期 |
| `checkbox` | 方框，可多选 | 兴趣爱好、同意条款 |
| `radio` | 圆点，同组只能选一个 | 性别、性别 |
| `file` | 文件选择按钮 | 上传头像 |
| `color` | 取色器 | 主题色 |
| `range` | 滑块 | 音量、亮度 |
| `submit` | 提交按钮 | 表单结尾 |
| `hidden` | 看不见 | 偷偷带个 id 一起提交 |

`email`、`number`、`date` 这类浏览器自带格式校验，填错了会提示。这是最省事的校验方式。

## 单选要同名

一组单选按钮，`name` 必须写成同一个值，它们才互斥：

```html
<input type="radio" name="gender" value="male"> 男
<input type="radio" name="gender" value="female"> 女
```

`name` 不同，就变成两组独立的单选，两个都能选中。

`value` 是真正提交出去的值，页面上显示的"男""女"只是旁边的文字，不会提交。

## 文字和控件绑在一起

点"阅读"两个字也能选中方框，这件事靠 `<label>`：

```html
<label>
  <input type="checkbox" name="hobby" value="reading"> 阅读
</label>
```

把控件包在 `<label>` 里，或者用 `for` 指向控件的 `id`：

```html
<input type="checkbox" id="reading">
<label for="reading">阅读</label>
```

对手机用户来说这点很重要，文字比小方框好点得多。

## 下拉框

```html
<select name="city">
  <option value="">请选择城市</option>
  <option value="bj">北京</option>
  <option value="sh" selected>上海</option>
</select>
```

↓ 渲染出来是这样：

<select name="demo-city">
  <option value="">请选择城市</option>
  <option value="bj">北京</option>
  <option value="sh" selected>上海</option>
</select>

`selected` 让它默认选中。

想给选项分组，外面套一层 `<optgroup label="分组名">`。

要多选就把 `multiple` 加上，但下拉多选很难用，一般会换成一组 checkbox。

## 多行文本

输入框只能写一行，想写多行用 `<textarea>`：

```html
<textarea name="message" rows="4" cols="40">默认内容</textarea>
```

`rows` 是显示几行，`cols` 是一行几个字符宽。

`<textarea>` 不是空元素，它有结束标签。想给默认内容，就写在两个标签中间——**不能写在 value 属性里**，写了不生效。

## 按钮

```html
<button type="submit">提交</button>
<button type="reset">重置</button>
<button type="button">就是个按钮</button>
```

`<button>` 在表单里默认就是 `submit`，点一下会提交整个表单。

如果只是想要一个"点了执行某件事"的按钮，一定要写 `type="button"`，否则会莫名其妙刷新页面。

下面这个就是不会提交的类型，点它没反应是正常的：

<p><button type="button">点我没反应</button></p>

## 分成几块

表单长了可以分组，每组配个标题：

```html
<fieldset>
  <legend>联系方式</legend>
  <input type="tel" name="phone">
</fieldset>
```

`<legend>` 会画在边框上，一眼能看出分组。

## disabled 和 readonly

```html
<input type="text" value="不可改，也不提交" disabled>
<input type="text" value="不可改，但会提交" readonly>
```

`disabled` 的控件用户改不了、点不了，提交时也不会带上它。

`readonly` 改不了，但照常提交。

两者都要靠 CSS 才能看出区别，默认样式都很淡。

## required 和 placeholder

```html
<input type="text" name="phone" required placeholder="11 位手机号">
```

`required` 让浏览器在提交前检查这项有没有填。

`placeholder` 是输入框里的灰色提示文字，一旦开始输入就消失——所以它不能代替 `<label>`，因为用户打完字就看不见了。
