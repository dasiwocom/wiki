# 一个网页文件的骨架长什么样

新建一个记事本，把下面这几行粘进去，另存为 `hello.html`（编码选 UTF-8），然后双击它。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个网页</title>
</head>
<body>
  <h1>我的第一个标题</h1>
  <p>我的第一个段落。</p>
</body>
</html>
```

浏览器会打开一个页面，里面是一行大字和一行普通文字。

这个文件本身没有任何"程序"在跑，它只是一份说明书，告诉浏览器"这几行字要当标题显示""那几行当正文显示"。

## 每行在干什么

| 写法 | 作用 |
| --- | --- |
| `<!DOCTYPE html>` | 声明这是 HTML5 文档，让浏览器按标准模式渲染 |
| `<html>` | 整个文档的根，其他所有内容都装在它里面 |
| `<head>` | 放给浏览器和搜索引擎看的信息，不会显示在页面上 |
| `<meta charset="UTF-8">` | 声明文件用 UTF-8 编码，防止中文乱码 |
| `<title>` | 浏览器标签页上显示的名字，也是加入收藏时的名字 |
| `<body>` | 页面上真正能看到的内容，全部写在这里 |
| `<h1>` | 一级标题 |
| `<p>` | 段落 |

只有 `<body>` 里的东西会显示出来，`<head>` 里的全是给机器看的。

## 三层结构别搞混

```text
<html>          ← 整个文档
├── <head>      ← 给浏览器看的信息（不显示）
└── <body>      ← 给用户看的内容（显示）
```

写得再多，也是往 `<body>` 里面塞。

## 中文乱码就是这一行没写

`<meta charset="UTF-8">` 是中文网页的必需品，漏了它，页面上的中文就会变成一堆问号或方块。

乱码的根源是两处编码不一致：**文件保存时用的编码**，和 **meta 里声明的编码**。两边都是 UTF-8 就不会乱。

用记事本另存为时，右下角有一个"编码"下拉框，确认它选的是 UTF-8。

用 VS Code 的话，右下角状态栏会显示当前编码，点一下就能改。

## lang 属性和文件名

`<html lang="zh-CN">` 告诉浏览器这份文档是简体中文。

它影响的是：浏览器要不要弹出翻译提示、屏幕阅读器用哪种语言朗读、字体怎么选。

文件后缀 `.html` 和 `.htm` 完全没区别，随便用哪个。推荐 `.html`。

首页文件通常命名为 `index.html`，这是服务器的默认约定，访问一个目录时会自动打开它。

## 想看看真实的网页是不是也这样

随便打开一个网站，按 `F12` 打开开发者工具，切到 Elements（元素）标签，就能看到它的 HTML。

你会发现结构跟上面几乎一样，只是 `<body>` 里塞了成百上千行。

## 配套的两个东西

HTML 只管内容，长什么样是 CSS 管的，能动起来是 JavaScript 管的。三门课的分工：

| 语言 | 负责 |
| --- | --- |
| HTML | 页面上有什么（标题、段落、图片、链接） |
| CSS | 这些东西长什么样（颜色、大小、位置） |
| JavaScript | 页面能做什么（点击、计算、改内容） |

这一组笔记只讲第一门。
