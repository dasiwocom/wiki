# 文字变了样，加粗、斜体、上下标和实体字符

同样的几个字，能做出十来种样子。问题不是"怎么变"，而是"该用哪一个"。

## 先分清两件事

`<strong>` 和 `<b>` 在页面上看着一模一样，都是加粗。

区别在含义：`<strong>` 表示"这句话很重要"，`<b>` 只表示"这里要加粗"。

对屏幕阅读器来说，`<strong>` 会被加重语气读出来，`<b>` 不会。搜索引擎也会更重视 `<strong>`。

所以有含义的场合用 `<strong>`，纯视觉的场合用 `<b>`。同理：

| 语义写法 | 视觉写法 | 含义 |
| --- | --- | --- |
| `<strong>` | `<b>` | 重要 |
| `<em>` | `<i>` | 强调 |
| `<del>` | `<s>` | 删除 |
| `<ins>` | `<u>` | 插入 |

左边这列是应该优先用的，右边那列留给"纯装饰"。

## 常用的一批

```html
<p><strong>重要</strong>、<em>强调</em>、<mark>高亮</mark>、<del>删掉</del>、<ins>新增</ins></p>
<p>水的化学式是 H<sub>2</sub>O，面积单位是 m<sup>2</sup>。</p>
<p>快捷键是 <kbd>Ctrl</kbd> + <kbd>S</kbd>，代码写法是 <code>print()</code>。</p>
<p><small>小一号的字，常用于版权声明</small></p>
```

↓ 渲染出来是这样：

<p><strong>重要</strong>、<em>强调</em>、<mark>高亮</mark>、<del>删掉</del>、<ins>新增</ins></p>
<p>水的化学式是 H<sub>2</sub>O，面积单位是 m<sup>2</sup>。</p>
<p>快捷键是 <kbd>Ctrl</kbd> + <kbd>S</kbd>，代码写法是 <code>print()</code>。</p>
<p><small>小一号的字，常用于版权声明</small></p>

| 标签 | 效果 | 常用在哪 |
| --- | --- | --- |
| `<strong>` | 加粗 | 关键结论、警告 |
| `<em>` | 斜体 | 需要强调的词语 |
| `<mark>` | 黄底高亮 | 搜索结果命中、重点标记 |
| `<del>` | 删除线 | 改稿时保留的删改痕迹 |
| `<ins>` | 下划线 | 改稿时新加的内容 |
| `<sub>` | 下标 | 化学式、变量 |
| `<sup>` | 上标 | 平方、脚注编号 |
| `<small>` | 小一号 | 补充说明、版权 |
| `<code>` | 等宽字体 | 代码、文件名、命令 |
| `<kbd>` | 等宽+边框 | 键盘按键 |
| `<abbr>` | 悬停显示全称 | 缩写 |
| `<blockquote>` | 缩进的引用块 | 引述别人的话 |

## 加粗别用过头

一段话里到处是加粗，等于没有重点。

一屏文字里加粗三五处就够了，多出来的部分读者会自动跳过。

## 引用

短引用用 `<q>`，浏览器会自动加引号：

```html
<p>他说的原话是 <q>先跑起来再说</q>。</p>
```

↓ 渲染出来是这样：

<p>他说的原话是 <q>先跑起来再说</q>。</p>

成段的引用用 `<blockquote>`：

```html
<blockquote>
  <p>任何足够先进的技术，初看都与魔法无异。</p>
</blockquote>
```

## 实体字符：那些打不出来的符号

HTML 里有两个符号是"保留字"，写出来会被当成代码：

- `<` 会被当成标签的开始
- `&` 会被当成实体的开始

想在页面上显示它们，得写成实体：

```html
<p>标签用小尖括号包起来，比如 &lt;p&gt;。</p>
<p>实体以 &amp; 开头，以分号结尾。</p>
```

↓ 渲染出来是这样：

<p>标签用小尖括号包起来，比如 &lt;p&gt;。</p>
<p>实体以 &amp; 开头，以分号结尾。</p>

常用的几个：

| 实体 | 显示为 | 什么时候用 |
| --- | --- | --- |
| `&lt;` | `<` | 显示小于号 |
| `&gt;` | `>` | 显示大于号 |
| `&amp;` | `&` | 显示 & 符号 |
| `&quot;` | `"` | 显示双引号 |
| `&copy;` | © | 版权符号 |
| `&nbsp;` | 一个不断行的空格 | 防止两段文字被拆到两行 |
| `&times;` | × | 乘号、关闭按钮 |

`&nbsp;` 是不断行空格，用它连接的两个词永远会待在同一行，比如 `100&nbsp;km`。

但别拿它来排版——需要间距就用 CSS，一堆 `&nbsp;` 排出来的版式，换个字号就散架。

## 一个提醒

所有"变了样"的标签，都不该用来凑版式。

想让一段字变大、变红、居中，这些是 CSS 的活。这一篇里的标签只管"这几个字有什么含义"。
