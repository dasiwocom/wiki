# 工程图与 GD&T

> [!note] 判断标准
> 视图定义**是什么**，尺寸定义**有多大**，粗糙度与形位公差定义**有多好**。
> 三者齐了，图纸才是技术契约，不是示意草图。

## 一、视图布局：先想清楚用什么视图表达

| 零件类型 | 布局套路 |
|---|---|
| 轴类 | 主视图轴线**水平**放；键槽用**局部剖**；退刀槽用 **2:1 局部放大**；遵循开放尺寸链 |
| 箱体类 | **阶梯剖 / 旋转剖**表达多轴系与油路交叉；重要轴承孔标**圆柱度** |
| 异形支架 | **45° 辅助视图**消除复杂虚线；长杆件用**断裂视图** |

硬规则：

- 剖切线用**粗实线**，两端箭头标字母（A-A）
- 局部放大图边界用**细实线圆圈**，标注放大比例
- 视图之间必须**长对正、高平齐、宽相等**

## 二、尺寸：不要全自动标注

**「模型项目导入驱动尺寸 + 智能尺寸补工艺尺寸」**——全自动标注一定乱，必须手动整理。

- 关键配合尺寸、定位尺寸**直接标出**，别让加工的人去算
- 尺寸尽量**集中在一个视图**
- 同方向尺寸链**对齐并排布**（共线/同轴约束）
- 重要尺寸用**方框框出**（右键尺寸 → 显示选项 → 套合）
- **尺寸链不许封闭**——留一个开口给公差累积

> [!tip] 批量改格式
> 选中所有尺寸，`Ctrl+Shift+C` 调出尺寸调色板，一键统一字体、箭头、公差格式。

公差怎么标：

| 形式 | 例子 | 选哪个 |
|---|---|---|
| 双面 | 50±0.1 | 对称 |
| 单面 | 50 +0.2/−0.1 | 双边 |
| 公差带代号 | 50H7 | 配合公差（系统自动查表） |

## 三、形位公差（GD&T）：顺序和箭头位置都有讲究

1. **先定基准**：用「基准特征」符号标在作为基准的面/轴线上，字母 A、B、C
2. **再插特征控制框**：注解 → 形位公差，填公差项目符号、公差值、基准字母
3. 基准字母按**主 → 次 → 第三**顺序填

> [!warning] 引线箭头指哪，含义不一样
> - 指**尺寸线** → 控制的是该尺寸特征的轴线或中心面（符合 GD&T 规则 #1）
> - 指**模型边线** → 控制的是那条边
>
> 轴孔的同轴度、圆跳动，箭头要**与尺寸线对齐**，不要点在轮廓上。
> 基准三角形放在基准要素的轮廓线或其延长线上。

尺寸公差**不能替代**形位公差——50H7 管的是大小，同轴度管的是位置，两回事。

## 四、粗糙度：区分加工面与非加工面

- 符号尖端必须**从材料外指向表面**（详见 [[表面粗糙度符号]]）
- 轴上不同轴段要求不同时，用**「面」选择过滤器**把符号直接贴到圆柱面上——视图移动时符号跟着走
- 多数表面统一要求的，图纸右上角标「**其余**」
- **把常用值（Ra 0.8 / 1.6 / 3.2 / 6.3）存进设计库的注解文件夹**，下次拖拽到边线即可，比每次手输快 5 倍

## 五、技术要求要"参数化"

"调质处理 HB 220-250""未注倒角 C2"这类文字**不要写成死文本**。
用**注释 → 链接到属性**，引用模型的自定义属性（热处理、表面处理）。
改模型属性，图纸文字自动更新。

## 六、BOM 表

装配图必须有材料明细表：插入 → 表格 → 材料明细表 → 选装配体视图 → 设列（序号/零件号/名称/数量/材料/备注）。

国标要求：序号从 1 开始自上而下；标题栏与 BOM 之间空一行；零件多可右键**分割**成多页。

> [!tip] 模型驱动
> 在零件里提前填好自定义属性（材料、表面处理、重量），BOM 自动提取，不用手输。

## 七、模板与自动化

- 定制企业级 `.drwdot` 模板：统一字体、箭头样式、图层颜色
- 设计表驱动系列化零件
- 宏批量导出 PDF、自动填 BOM——出图效率能提 80%

## 八、出图前自检

- [ ] 关键配合尺寸是否直接标出（没让人去算）？
- [ ] 尺寸链是否封闭？
- [ ] 基准符号是否已定义，且形位公差框引用顺序正确？
- [ ] 形位公差箭头指的是尺寸线还是边线——是不是想要的意思？
- [ ] 粗糙度符号朝向对不对？
- [ ] 非加工面标了吗？「其余」写了吗？
- [ ] BOM 属性是否从模型自动提取？
- [ ] 有没有漏标（可用「检查绘图」工具扫未标注草图实体）？
