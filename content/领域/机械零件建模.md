# 机械零件建模

> [!note] 这篇和 [[SolidWorks建模]] 的分工
> 那篇讲**通用建模方法论**（特征顺序、草图规范、设计意图）——适用于任何零件。
> 这篇讲**机械特有的东西**：齿轮怎么算出真渐开线、筋和拔模为什么是铸造件的标配、
> 孔和螺纹有哪些坑、轴该收哪些细节。

## 一、齿轮：先算，别手描

### 基本参数（标准直齿圆柱齿轮，ha\*=1、c\*=0.25）

| 参数 | 公式 | m=2 z=20 时 |
|---|---|---|
| 模数 m、齿数 z、压力角 α | 给定（α 标准 20°） | — |
| 分度圆 d | m·z | 40 |
| 齿顶圆 da | d + 2m | 44 |
| 齿根圆 df | d − 2.5m | 35 |
| 基圆 db | d·cos α | 37.588 |

### 渐开线怎么来

极坐标下：

- 半径 r(t) = rb·√(1+t²)
- 极角 φ(t) = t − arctan(t)　（这就是渐开线函数 inv(α) = tanα − α）

其中 t = √((r/rb)² − 1) = tan(该半径处的压力角)。

**半齿角随半径变化**：ψ(r) = ψ_p − (φ(r) − φ(rp))，分度圆处 ψ_p = π/(2z)（即 90/z 度）。

> [!warning] 这个负号最容易写反
> 写反了齿顶会比齿根还宽，一眼就该看出来。
> 校验办法：m=2、z=20 时，分度圆处半齿角必须正好是 **4.5° = 90/z**。

### 建模流程（参数化的）

1. 分度圆/齿顶圆/齿根圆/基圆画成**构造线**
2. 用「方程式驱动的曲线」画渐开线，或（我们的做法）用 Python 算点列画折线
3. 镜像出另一侧齿面，齿顶圆弧 + 齿根圆弧封成闭合齿廓
4. 拉伸出**一个齿**，圆周阵列 z 份
5. 齿根圆角 R ≈ 0.38m
6. 挖轴孔、键槽、减重孔

齿轮必须参数化：把 m、z、α 做成全局变量，改模数齿数整个齿轮自动重建——
这也是把「硬编码是埋雷」体会得最深的地方。

**齿数分界**：z ≤ 41 时基圆大于齿根圆，齿廓根部要补一段径向线（或过渡曲线），
z > 41 时基圆在齿根圆以内，渐开线能一路画到底。

## 二、筋（加强筋）：最划算的刚度方案

加厚壁厚 vs 加筋——加筋省材料、减重量、还能改善铸造流动性。

### 硬约束

- 草图是**一条开放直线**（不是闭合轮廓）
- **两端必须落在实体表面上**，悬空直接报错
- 筋体从这条线延伸、填充到已有实体为止，所以线画在空腔那一侧，筋就长成那块三角板

### 我们的实测

L 形支架内角：斜边 (35,−20) → (5,10)，厚 8mm
→ 直角三角形 ½·30·30 = 450 mm²，体积增量 **450 × 8 = 3600 mm³**，实测精确吻合。
包围盒没变（筋在原有包络内），说明几何位置正确。

> [!tip] 对称件画一侧再镜像
> 两侧都要筋时，画一侧 → 镜像特征。别画两遍。

## 三、铸件工艺：拔模、铸造圆角、壁厚

铸造件（支架、箱体、轴承座）不是"形状对"就够了，还得**造得出来**：

| 工艺要求 | 数值 | 为什么 |
|---|---|---|
| 拔模斜度 | 通常 1°~3° | 脱模，没有它铸件拔不出来 |
| 铸造圆角 | R2~R5 | 尖角处应力集中、还容易浇不足 |
| 壁厚均匀 | 尽量避免突变 | 厚薄不均 → 缩孔、变形 |

**拔模放在最后**。它依赖被修改的那些面，顺序提前了，后续凸台/切除一改就崩。
**抽壳要在筋、凸台都就位之后**，壁厚才包得住它们。

## 四、孔系与螺纹

### 孔的类型别选错

| 类型 | 用途 | 含螺纹 |
|---|---|---|
| 简单直孔 | 通孔、定位孔 | 否 |
| 柱形沉头孔 | 螺栓过孔、六角头螺栓 | 否 |
| 锥形沉头孔 | 沉头螺钉 | 否 |
| 直螺纹孔 / 锥螺纹孔 | 螺纹连接 | 是 |

> [!warning] 沉头孔 ≠ 带沉头的螺纹孔
> 选"沉头孔"做出来是光孔，没有螺纹。要"带沉头的螺纹孔"得在**螺纹孔类型里勾沉头**，
> 或者先柱孔后螺纹孔（但会变成两个特征，定位容易错位）。

### 定位要用「面 + 点」

先在图形区选**平面**，再到"位置"页点位置。直接点在 3D 模型上，系统会猜投影面，
孔很容易跑偏到模型外面。

### 装饰螺纹 vs 真实螺纹

- **装饰螺纹线**：只是符号，不参与几何，文件小、性能好，工程图里按国标画细实线
- **真实螺纹**：螺旋切除，几何准确但文件大、重建慢

渲染要看到牙型才做真实螺纹，一般工程图用装饰螺纹就够了。

### 螺纹规格

Toolbox 里可以添加国标 GB 规格。注意：标准里没有的规格，硬写进 Toolbox 也不生成。

## 五、轴类零件的细节

课本上画轴觉得就是几段圆柱，实际工程图里这些细节一个都不能少：

- **键槽**：尺寸按 GB 查（如 d=30 的轴配 8×7 键）
- **退刀槽 / 越程槽**：磨削和车螺纹的加工让刀位
- **中心孔**：轴两端，是加工和检测的定位基准
- **倒角**：装配导向，一般 C0.5~C2
- **阶梯处的圆角**：阶梯变化处应力集中最严重，圆角不能省

## 六、实测案例：轴承座

用我们的 MCP 跑通的完整机械件（体积逐步核算，全部与理论值吻合）：

| 步骤 | 体积变化 |
|---|---|
| 倒 T 形主体（底板 100×14 + 立墙 36×34），两侧对称拉伸 | 2624 mm² × 80 = 209920 |
| 轴承孔 Ø28 贯穿 | −π·14²·80 = 160659.8 |
| 两侧三角筋各一片，厚 8 | +1936 ×2 = 164531.8 |
| 两个 Ø11 螺栓过孔 | −π·5.5²·80 ×2 = 149326.5 |

> [!tip] 两个都叫 both，语义却相反
> `extrude(depth, both=True)`：**每侧**各 depth，总长 = 2×depth（第一版齿轮没除 2，齿宽翻倍）。
> `rib(thickness, both_sides=True)`：thickness 是**总厚**，两侧各一半。
> 算理论体积时别混——上面轴承座那条筋 ½·22·22×8 = 1936/条就是拿它核过的。

## 七、实测案例：带凸台与筋的底座（按图纸）

第一个真正"照图施工"的件：**底板 100×45×12 四角 R10 / 凸台 Ø30 高 20 / Ø15 通孔 /
顶面槽 8×5 / 筋厚 8 / 4×Ø8 过孔**。最终 **60124.28 mm³ vs 解析理论 60104.0，差 0.03%**。

### 特征顺序就是能不能做出来

```
底板(矩形) → 凸台 → 筋 → 顶面槽 → Ø15 通孔 → 4×Ø8 过孔 → 四角 R10
```

三条顺序上的教训：

1. **筋必须排在切槽之前**。槽把凸台顶部 27~32 那一段挖掉了，
   筋的上端点是"落在凸台上"的，材料没了就只能失败（而且`InsertRib` 失败是不报错的）。
   一般规律：**先加料、后去料**。
2. **圆角最后加**。这不只是美观问题，见下面那条。
3. 孔是最后去的，但它改的是重量和装配，不影响别的特征的定位基准。

### 四角圆角千万别画进草图

第一反应是画一条带圆角的矩形轮廓（44 个点）。实测外形只有 99.75×44.88，
而且 44 段输入的折线，生成出来的实体只有 **38 个侧面——丢了 6 段**。
圆角在 90° 位置的极值点被丢掉，轮廓被拉成了弦。这毛病不是折线专有的：

| 画法 | 结果 |
|---|---|
| `sketch_polygon` 正 8 边形 R20 | 精确 40×40 ✓ |
| `sketch_polygon` 正 16 / 24 / 48 边形 R20 | 39.24×38.48 / 39.86×40.15 / 38.48×39.30 ✗ |
| 真圆弧 `CreateArc` 三种方向闭合 | 全部报"草图可能未闭合" ✗ |

结论：**API 下多段轮廓会掉段**。所以圆角一律**作为特征加**，不进草图——
正好也就是[[机械零件建模#三、铸件工艺：拔模、铸造圆角、壁厚|规范里说的]]"圆角最后"。

### 怎么验收：理论值要两套互校

```
底板（含四角圆角）  (100×45 − (4−π)·10²) × 12   = 52969.91
凸台                π·15² × 20                  = 14137.17
筋                  ½·30·14 × 8                 =  1680.00
顶面槽              圆盘∩|y|≤4 的条带 × 5        = −1185.62
中心通孔            整圆段 + 槽没挖到的部分       = −5084.63
4×Ø8 过孔           4 × π·4² × 12               = −2412.74
                                           合计 = 60104.09
```

手推公式容易在重叠处翻车（槽和通孔交叠、筋和凸台相交），所以再跑一遍数值积分交叉验证，两边差 0.02% 才敢当基准。
数值积分务必**中点采样**——`while x <= xmax` 那种写法三个方向各多算一格，0.5mm 步长能偏 3% 以上。

## 八、加强筋最容易踩的坑：端点相切 = 空特征

SolidWorks 的 `InsertRib` 要求**斜边两个端点都落在实体面内部**。
做"筋顶到筒顶"的件时，端点若取在筒顶圆的边缘，只在极少数点相切，
特征照样生成、名字照样出现在特征树里，**但一根料都没加**（体积增量 = 0，不报错）。

> [!warning] 别用特征树判断成败
> 判据只有一个：**体积有没有涨**。这次差值 2428.9 mm³ 正好等于筋的理论体积 2424.8，
> 就是靠这个对出来的。

| 筋顶落在哪 | 做法 |
|---|---|
| 筒**侧面**、平墙面上 | `InsertRib` 直接用，最干净 |
| 正好到**顶面边缘**（相切） | 改用**闭合三角形拉伸**，垂直边伸进筒内 1~2mm 保证并集无缝 |

后者外形只差 1mm（肉眼不可见），但体积可精确算出，建模也确定得多——
工程上"能确定"比"更贴合图纸 1mm"重要。
