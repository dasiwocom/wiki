# 个人数据

> [!note] 这份清单从哪来的
> 旧库 `个人信息/数据/` 下建了 8 个**空目录**，一直没有内容。
> 空目录本身就是信息——说明这些是被规划过、准备长期记的东西。
> 原始目录已不再使用（旧库结构不作数），但这份构想值得保留下来。

## 八个维度

| 维度 | 大概要记什么 | 状态 |
|---|---|---|
| 习惯 | 想养成 / 想戒掉的，打卡记录 | 空 |
| 健康 | 体重、作息、身体数据、就诊记录 | 空 |
| 观影 | 看过的片子、评分、感想 | 空 |
| 设备 | 电脑、手机、开发板等硬件清单与参数 | 空 |
| 读书 | 在读 / 读完的书，笔记 | 空 |
| 账号 | 各站点账号（**不放密码**） | 空 |
| 账目 | 收支、订阅续费 | 空 |
| 项目 | 在做的事 | 已并入 `项目/` 分区 |

## 怎么落地

不预先建 8 个空目录——空目录没有意义，还会在导航里添乱。

**有内容再建文件**，一个维度一个文件，标题写具体点：

- `习惯-早起打卡.md`
- `设备-开发板清单.md`
- `读书-机械制造技术基础.md`

攒够几篇了，再考虑要不要给这个维度单独开目录。

- 长期维护而非有终点的事，都归 `领域/`
