# 大型装配体性能

> [!note] 先说结论
> 卡顿的根因通常是**个别"重量级"零件**，不是电脑不行。
> 先治模型，再调设置；换硬件是最后一步。

## 第一层：建模源头减重

| 特征 | 做法 | 原因 |
|---|---|---|
| 螺纹 | 用**装饰螺纹线**，绝不用真实螺纹切除 | 螺旋扫描切除会让计算量暴涨（除非要 3D 打印） |
| 阵列 | 几十个散热孔/加强筋用**阵列**，不用镜像或切除-复制 | 特征树节点少，重建快 |
| 微小圆角 | R<0.5 的圆角留到出图阶段再加 | 显存和重建都被它们吃掉 |

## 第二层：装配体轻量化

- **轻量化模式**：右键零件或整个装配体 → 设定为轻量化。只加载显示数据，不加载特征数据，**内存降约 70%**。标准件库（螺钉、轴承）直接默认轻量化
- **SpeedPak**：给复杂子装配体（如整台减速机）建 SpeedPak 配置，只保留指定面、边线、基准面，丢弃内部特征，但**保留外观和边界框**，仍可配合和测量
- **封套（Envelope）**：厂房、输送线这类非产品零件设成封套——能参与干涉检查，**但不计入 BOM**
- **压缩/冻结**：不用的零件直接压缩；改一批尺寸前用冻结栏冻结早期特征，最后统一重建

> [!warning] SpeedPak 不会自动跟上修改
> 底层装配改了（移动零件、改尺寸），SpeedPak **必须手动更新**：
> 右键 SpeedPak 配置 → Update SpeedPak。
> 或在系统选项 → 装配体里勾「保存时更新过期的 SpeedPak 配置」。
> 忘了更新，配合会悄悄失效。

## 第三层：配置与显示状态组合拳

- 建一个「简化」配置，压掉盖板、标签、装饰条和内部不可见零件；设计用简化，出渲染/剖切再切回完整
- 按工作阶段存不同**显示状态**（装配调试 / 干涉检查 / 运动仿真）

## 第四层：系统设置

| 设置 | 位置 |
|---|---|
| 大型装配体模式（可设零件数阈值自动触发） | 工具 → 选项 → 系统选项 → 装配体 |
| 自动轻量化加载 | 同上 |
| 增强的图形性能（需 OpenGL 4.5 显卡） | 工具 → 选项 → 系统选项 → 性能 |
| 降低图像质量滑块 | 工具 → 选项 → 文档属性 → 图像质量 |
| 大型设计审阅（Large Design Review） | 文件 → 打开 → 模式 |

> [!failure] 别把项目放机械硬盘 + 云同步目录下
> OneDrive / Dropbox 监控会导致频繁文件锁定和重建，卡顿会变得毫无规律。
> 模板、缓存、临时目录尽量放 SSD。

## 外部导入模型（STEP / IGES / 厂商件）

1. **Import Diagnostics**（评估页）修掉所有错误面
2. **Check**（评估页）查无效面/边
3. **Defeature**（工具）删掉螺纹、Logo、小孔、与本次设计无关的内部件
4. **Delete/Keep Body** 删掉不需要的实体

## 出图侧

- 大装配工程图用**分离的工程图（Detached Drawing）**，打开不依赖装配体加载
- 视图能用**草稿品质**就用
- 少用剖视图、局部视图、断裂剖——它们最贵

## 诊断工具

- **性能评估**（评估页）：打开时间、重建时间、最慢的零件
- **装配体可视化**（工具 → 评估）：按文件大小、图形三角面数、重建时间排序，一眼看出是谁拖后腿
