## 子概念的拆分

```
不能用确定的数学关系式来表达的信号称为非确定性信号，又称随机信号。它可分为平稳性随机信号和非平稳性随机信号两类。
如果描述随机信号特征的统计数学参数（如平均值、均方根值、概率密度函数等）都不随时间推移而变化，称为平稳性随机信号；若在不同采样时间内测得的统计参数不能看成常数，则称为非平稳性随机信号。
工程测试中随机信号大量存在，如汽车行驶时的振动信号、环境噪声信号等。
```

如果文中出现这种格式可将其拆分为三个文件 1.非确定性信号 2.平稳性随机信号 3.非平稳性随机信号，例如：
非确定性信号：
```
不能用确定的数学关系式来表达的信号称为非确定性信号，又称随机信号。它可分为[[平稳性随机信号]]和[[非平稳性随机信号]]两类。

```

平稳性随机信号：
```
如果描述随机信号特征的统计数学参数（如平均值、均方根值、概率密度函数等）都不随时间推移而变化，称为平稳性随机信号。
```

非平稳性随机信号：
```

```
