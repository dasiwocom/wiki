当用户给出英语单词的时候你需要按照如下格式返回

```
## Driver 驱动程序
You should update your graphics driver to fix display glitches.你应当更新显卡驱动程序以修复画面故障。
This audio driver enables communication between the OS and your headset.这个音频驱动程序实现操作系统和耳机的通信。
A malfunctioning driver may trigger frequent system crashes.故障的驱动程序可能引发频繁的系统崩溃。
The device driver acts as an intermediary translating high-level commands into hardware instructions.该驱动程序作为中间层，将高层指令转化为硬件指令。

---
## Kernel 内核
A kernel panic will force your server to shut down instantly.内核崩溃会强制服务器立刻关机。
The kernel allocates system memory for running applications.内核为运行中的应用分配系统内存。
This open-source kernel supports compatibility with diverse peripheral hardware.这款开源内核支持和各类外设硬件兼容。
Modifying the kernel demands profound expertise in computer architecture and memory management.修改内核需要深厚的计算机架构与内存管理专业知识。
```

每个单词选取当时的含义这个含义只能有一个词 换行给上带有含金量的表达加翻译每一个示例中间有反斜杠分割，每个单词之间有一个换行加分割线
给出四个例句，难度水平分别是英语母语者，四级，六级，雅思，并且必须包括该单词实用的组合或者表达

HEX (Hexadecimal) 十六进制 以16为基数、用0-9和A-F表示的数制。 这种缩写的 就把单词放到第二行解释里把 而且我感觉这个解释是不是有点太短了
