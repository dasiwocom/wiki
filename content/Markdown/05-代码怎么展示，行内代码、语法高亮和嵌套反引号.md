# 代码怎么展示，行内代码、语法高亮和嵌套反引号

技术笔记离不开代码。Markdown 里有两种展示代码的方式，用哪一种取决于**这段代码是嵌在句子里，还是单独成块**。

## 行内代码

在句子里提到一个命令、文件名、变量名、函数名时，用一对反引号包起来。反引号在键盘左上角，和数字 1 挨着。

````md
用 `npm run build` 就能构建项目。
````

↓ 渲染出来是这样：

用 `npm run build` 就能构建项目。

行内代码的好处不只是"变个字体"，更重要的是里面的内容不会被当成 Markdown 语法。

比如你写 `` `snake_case_name` ``，里面的下划线不会被当成斜体；写 `` `**` ``，它不会开始一段粗体。这对写技术文档来说是刚需。

## 代码块

上下各三个反引号，把代码夹在中间：

````md
```
这是代码块
```
````

开场那三个反引号后面写上语言名，就会有语法高亮：

````md
```c
#include <REGX52.H>
void main()
{
    P2 = 0xFE;
}
```
````

↓ 渲染出来是这样：

```c
#include <REGX52.H>
void main()
{
    P2 = 0xFE;
}
```

常用的语言标识：

| 标识 | 语言 |
| --- | --- |
| `c` | C 语言 |
| `python` | Python |
| `bash` | 终端命令 |
| `yaml` | YAML 配置 |
| `json` | JSON |
| `html` | HTML |
| `css` | CSS |
| `js` | JavaScript |
| `markdown` / `md` | Markdown |
| `mermaid` | Mermaid 图表（见 [[11-Mermaid 图表和数学公式|Mermaid 图表]]） |

不写语言也行，就是一个纯色块，没有高亮。多数编辑器和高亮主题都自带亮/暗两套配色，代码块右上角通常还有复制按钮。

## 缩进式代码块（不推荐）

还有一种老写法：每行前面空四个空格。

```md
    这是缩进四个空格的代码
```

它确实能生效，但不推荐，原因有两个：

- 容易和列表的缩进搞混，一不小心就变成"列表项的续行"
- 空行不好处理，复制粘贴时容易丢缩进

用三个反引号的写法，什么都清楚。

## 代码里要写反引号怎么办

这是个经典问题：你想展示的代码里本身就有三个反引号（比如你想教别人"怎么写代码块"），外面的围栏就分不清哪三个是结束。

规则很简单：外面的围栏比里面多一层。里面最多用到三个反引号，外面就用四个：

`````md
````
```md
这里面的三个反引号会被当成普通文字
```
````
`````

如果里面要出现四个，外面就用五个。以此类推。

其实整篇笔记里到处都是这种写法——你要展示"怎么写代码块"，就得用比它多一层的围栏。

## 代码块里的空行和缩进

代码块内部原样保留，包括：

- 空行
- 行首的空格
- 多个连续空格

所以粘贴代码进去的时候不用担心格式被压缩。另外，代码块里的换行和正文的换行规则是两套：你写几行就是几行，不会被额外插入换行。

## 行内代码里的反引号

想在行内代码里显示一个反引号，用两个反引号包一个：

````md
`` 这是 ` 一个反引号 ``
````

↓ 渲染出来是这样：

`` 这是 ` 一个反引号 ``

（外侧双反引号，内侧单反引号。）

## 什么时候该用哪个

| 场景 | 用什么 | 理由 |
| --- | --- | --- |
| 句子里提到命令、文件名、变量 | 行内代码 | 不打断阅读 |
| 一段完整的代码 | 代码块 + 语言标识 | 有高亮，能复制 |
| 终端的一行命令 | 代码块标 `bash` | 读者好复制 |
| 配置文件 | 代码块标 `yaml` / `json` | 高亮能看出层级 |
| 代码里的某个词 | 行内代码 | 精准 |

一个实用建议：写教程时，把能直接复制的命令单独成块，别包在句子里。读者会感谢你。

## 反引号、围栏和语言名

**用了中文的反引号或引号。** `` ｀代码｀ ``（全角）不生效。必须是 ASCII 的反引号 `` ` ``。

**围栏没配对。** 开场三个反引号，结尾忘了写，后面所有内容都会被当成代码。

**语言名写错。** ` ```c++ ` 是对的，但 ` ```cpp ` 也可能不认（取决于高亮器支持的名字）。写错不会报错，只是没有高亮。常见的安全选择：`c`、`python`、`bash`、`json`、`yaml`、`html`。

**代码块前后没空行。** 紧贴着上一段写 ``` ，有时候不会生效。代码块上下都空一行。

**在代码块里想强调某行。** Markdown 代码块里没法加粗某一行（里面的 `**` 会原样显示）。想强调就在代码块外面用文字说明，或者用注释：

```c
P2 = 0xFE;  // 就是这一行点亮了 LED
```
