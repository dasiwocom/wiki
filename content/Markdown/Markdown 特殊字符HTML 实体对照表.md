> Markdown 不能直接插入特殊符号（如 ©、®、π），但可以**复制粘贴符号本身**，或使用 **HTML 实体编码**。
> 实体编码格式：`&名称;`（命名实体）或 `&#数字;`（数字实体）。
> 注意：HTML 实体只在 **HTML 网页** 中生效；在 Obsidian 等 Markdown 编辑器里写 `&copy;` 会按代码原样显示（除非用反引号包裹）。

## 八、使用说明

1. **在 HTML 网页中使用**：直接写实体代码，浏览器会自动渲染成符号
   ```html
   <p>版权符号：&copy; | 乘号：&times; | 圆周率：&pi;</p>
   ```
2. **在 Obsidian / Markdown 中使用**：`&copy;` 这类代码不会自动变成 ©（Obsidian 不解析 HTML 实体），需**直接复制粘贴符号本身**：© × π
3. **命名实体 vs 数字实体**：
   - 命名实体：`&copy;`（好记，但个别符号没有命名实体）
   - 数字实体：`&#169;`、`&#960;`（所有 Unicode 字符都有数字编号，通用性最强）
4. **在 Markdown 代码块中展示实体代码**：用反引号包裹（如 `` `&copy;` ``），避免被解析
