> [!note] 这是 note
> 最常用的基础款。

```
>[!提示框]
>这是提示框
```

>[!提示框]-
>这是一个默认关闭的提示框

```
>[!提示框]-
>这是一个默认关闭的提示框
```

>[!提示框]+
>这是一个默认关闭的提示框

```
>[!提示框]+
>这是一个默认关闭的提示框
```

全部类型：`note` `abstract` `summary` `info` `todo` `tip` `success` `question` `warning` `failure` `danger` `bug` `example` `quote`
