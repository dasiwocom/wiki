## 无序列表

无序列表使用星号()、加号(+)或是减号(-)作为列表标记，这些标记后面要添加一个空格，然后再填写内容：

```
* 第一项
* 第二项
* 第三项

+ 第一项
+ 第二项
+ 第三项


- 第一项
- 第二项
- 第三项
```

* 第一项
* 第二项
* 第三项

+ 第一项
+ 第二项
+ 第三项


- 第一项
- 第二项
- 第三项

## 有序列表

有序列表用于展示有顺序要求的步骤或项目。有序列表使用数字并加上 . 号来表示，如：

```
1. 第一项
2. 第二项
3. 第三项
```

1. 第一项
2. 第二项
3. 第三项

## 任务列表

任务列表是 GitHub 风格 Markdown 的扩展功能，现在被广泛支持

```
- [ ] 未完成的任务
- [x] 已完成的任务
- [ ] 另一个未完成的任务
```

- [ ] 未完成的任务
- [x] 已完成的任务
- [ ] 另一个未完成的任务
