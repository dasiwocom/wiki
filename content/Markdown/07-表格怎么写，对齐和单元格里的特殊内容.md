# 表格怎么写，对齐和单元格里的特殊内容

表格是 Markdown 里写起来最"手工"的语法——要自己对齐竖线。但它也是最值得学的，因为横向对比这件事没有别的语法能替代。

## 基本结构

用竖线 `|` 分列，第二行用 `-` 把表头和内容隔开：

```md
| 元件 | 数量 | 单价 |
| --- | --- | --- |
| 电阻 | 10 | 0.05 |
| LED | 5 | 0.2 |
```

↓ 渲染出来是这样：

| 元件 | 数量 | 单价 |
| --- | --- | --- |
| 电阻 | 10 | 0.05 |
| LED | 5 | 0.2 |

拆解一下这个结构：

- 第一行是表头（列名）
- 第二行是分隔符，必须有，它告诉渲染器"上面是表头，下面是内容"
- 第三行起是数据

分隔符那一行至少要有两个 `-`。`| --- | --- |` 是最常见的写法，多写几个 `-` 只是为了源码看着整齐，不影响显示。

左右最外侧的竖线可以省略，但写上更清楚，也不容易出错。

## 对齐

分隔符那一行加冒号，就能控制这一列的对齐方式：

| 写法 | 含义 |
| --- | --- |
| `:--` | 左对齐 |
| `:-:` | 居中 |
| `--:` | 右对齐 |
| `--` | 默认（通常左对齐） |

```md
| 左对齐 | 居中 | 右对齐 |
| :-- | :-: | --: |
| a | b | c |
| 长一点的内容 | 内容 | 100 |
```

↓ 渲染出来是这样：

| 左对齐 | 居中 | 右对齐 |
| :-- | :-: | --: |
| a | b | c |
| 长一点的内容 | 内容 | 100 |

经验是文字靠左、数字靠右，看起来最舒服。

## 单元格里能放什么

单元格里不是纯文本，大部分行内语法都能用：

| 类型 | 例子 |
| --- | --- |
| 加粗 | `**重点**` |
| 行内代码 | `` `P2 = 0xFE` `` |
| 链接 | `[文字](https://example.com)` |
| 双链 | `[[笔记名]]` |
| 图片 | `![[图片.png\|100]]` |
| 删除线 | `~~废弃~~` |

实际效果：

| 语法 | 渲染结果 |
| --- | --- |
| 加粗 | **重点** |
| 行内代码 | `P2 = 0xFE` |
| 双链 | [[01-换行到底怎么回事，回车、两空格、空行有什么区别|换行到底怎么回事]] |
| 删除线 | ~~废弃~~ |

## 竖线转义

这是表格独有的坑：竖线在表格里是"分列"的意思，所以你想在单元格里显示一个 `|`，直接写会把表格切断。

解决办法是写成 `\|`：

```md
| 语法 | 用途 |
| --- | --- |
| `\|` | 在单元格里显示竖线 |
```

↓ 渲染出来是这样：

| 语法 | 用途 |
| --- | --- |
| `\|` | 在单元格里显示竖线 |

最常遇到这个的场景是在表格里写双链别名，因为别名语法本身就带一个竖线：

```md
| 链接 | 说明 |
| --- | --- |
| [[笔记名\|显示成这个]] | 带别名的双链 |
```

中间那个 `\|` 必须转义，否则表格会多出一列。

## 单元格里换行

表格里没法用回车换行——你按回车，整个表格就乱了。

唯一的办法是写 `<br>`：

```md
| 项目 | 说明 |
| --- | --- |
| 地址 | 北京市海淀区<br>中关村大街 1 号 |
```

↓ 渲染出来是这样：

| 项目 | 说明 |
| --- | --- |
| 地址 | 北京市海淀区<br>中关村大街 1 号 |

硬换行、行尾两空格在表格里都不管用——这是为数不多 `<br>` 不可替代的场景。

## 表格做不到的，用 HTML

Markdown 表格有个硬伤：没法合并单元格，也没法控制列宽。

真需要这些，就直接写 HTML 表格：

```html
<table>
  <tr>
    <th colspan="2">跨两列的标题</th>
  </tr>
  <tr>
    <td>左</td>
    <td>右</td>
  </tr>
</table>
```

它能正常渲染，但大多数时候用不上——能用简单表格说清的，就别上 HTML。

## 什么时候该用表格

表格的价值是横向对比。判断标准：

- 几条内容有相同的几个属性，要并排看 → 用表格。比如"三种换行方式的区别""共阴和共阳的对照"
- 只是罗列几条并列项 → 用列表就够了，见 [[04-列表怎么写，嵌套、任务列表和列表里塞内容|列表怎么写]]
- 内容是一段一段的解释 → 用标题分段

一个反例：把"三个步骤"写成表格，读起来反而比有序列表累。

## 表格散架、列数错位

**分隔符行缺了。** 只有表头没有 `---` 那一行，整个表格不会渲染，会变成一堆带竖线的文字。

**分隔符行太短。** `| - | - |` 只有一个 `-` 也能生效，但为了保险写三个以上。

**表格太宽。** 列数太多时，窄屏上会挤成一团或者横向溢出。经验是不超过 4~5 列，列多了就拆成两个表，或者改成列表。

**表头为空。** 第一行的某一列什么都不写，渲染出来表头是空的，读者不知道这列是什么。宁可写个"备注"。
