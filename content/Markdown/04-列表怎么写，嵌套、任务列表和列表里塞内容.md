# 列表怎么写，嵌套、任务列表和列表里塞内容

列表看起来简单，但"在列表项里塞别的东西"这件事，是很多人卡住的地方——尤其是缩进到底该空几格。

## 无序列表

`-`、`*`、`+` 三个符号都能用，挑一个用到底就行（用 `-` 的人最多）。符号后面要有空格。

```md
- 苹果
- 香蕉
- 橘子
```

↓ 渲染出来是这样：

- 苹果
- 香蕉
- 橘子

## 有序列表

数字加点，或者数字加右括号，都行：

```md
1. 第一步
2. 第二步
3. 第三步
```

↓ 渲染出来是这样：

1. 第一步
2. 第二步
3. 第三步

一个很实用的技巧：数字可以全写成 1。

```md
1. 第一步
1. 第二步
1. 第三步
```

渲染出来照样是 1、2、3——序号是渲染时自动数的，不是照抄你写的数字。这么写的好处是，中间插入一条新项时，不用把后面所有数字都改一遍。

## 嵌套

在子项前面缩进，就能套一层：

```md
- 水果
  - 苹果
  - 香蕉
    - 红香蕉
- 蔬菜
```

↓ 渲染出来是这样：

- 水果
  - 苹果
  - 香蕉
    - 红香蕉
- 蔬菜

缩进几格？两个或四个都行，只要同一个列表里保持一致。用 Tab 最省事：

> [!tip] 让编辑器帮你缩进
> 在列表项末尾按 `Enter`，会自动续一行同级的项；按 `Tab` 把当前项缩进一级，`Shift+Tab` 反过来。比手敲空格快得多。

有序和无序可以混着套：

```md
1. 第一步
   - 注意点一
   - 注意点二
2. 第二步
```

↓ 渲染出来是这样：

1. 第一步
   - 注意点一
   - 注意点二
2. 第二步

## 任务列表

在 `-` 后面加一对方括号，就是待办项：

| 写法 | 显示 |
| --- | --- |
| `- [ ] 内容` | 未勾选 |
| `- [x] 内容` | 已勾选 |

```md
- [x] 已经做完的事
- [ ] 还没做的事
```

↓ 渲染出来是这样：

- [x] 已经做完的事
- [ ] 还没做的事

方括号里必须有内容：未完成是 `[ ]`（一个空格），已完成是 `[x]`（字母 x，大小写都行）。写成 `[]` 就只是普通文字，不会变成复选框。

要留意的是，复选框在网页上通常只是显示用，点击不会保存状态——只有在 Obsidian 里点它，才会真的改你本地文件里的 `[ ]`。

## 列表项里塞别的内容

规则只有一条：缩进到和列表文字对齐。

### 塞第二个段落

```md
- 这是第一项

  这是第一项的第二段。
  前面空了两格，和"这"字对齐。

- 这是第二项
```

↓ 渲染出来是这样：

- 这是第一项

  这是第一项的第二段。
  前面空了两格，和"这"字对齐。

- 这是第二项

要点是中间要空一行，然后缩进。这样它属于上一个列表项，而不是变成新的一段。

### 塞代码块

同样的道理，缩进到对齐位置：

````md
- 用这个命令构建项目：

  ```bash
  npm run build
  ```

- 下一项
````

↓ 渲染出来是这样：

- 用这个命令构建项目：

  ```bash
  npm run build
  ```

- 下一项

### 塞子列表

前面嵌套那节已经演示过了，直接缩进就行。

### 塞引用

```md
- 一个要点

  > 这里是引用，同样缩进对齐

- 另一个要点
```

↓ 渲染出来是这样：

- 一个要点

  > 这里是引用，同样缩进对齐

- 另一个要点

## 列表和换行的配合

列表里也有换行的问题，规则和正文一样（详见 [[01-换行到底怎么回事，回车、两空格、空行有什么区别|换行到底怎么回事]]）：

- 列表项之间没有空行 → 项与项紧凑排列
- 列表项之间空一行 → 项与项之间会有额外空隙（部分主题下）

如果编辑器开了硬换行，在一个列表项里按回车就会真的换行。想让一个列表项里出现两行，直接回车即可。

## 什么时候用列表，什么时候不用

列表的语义是并列的几条。判断标准很简单：这几条能不能换顺序？

- 能换顺序（比如几种水果）→ 用无序列表
- 不能换顺序（比如操作步骤的先后）→ 用有序列表
- 根本不是并列关系（比如一首诗的三行）→ 别用列表，直接回车换行就好

第三种情况很常见。用软换行的工具（比如 GitHub）写的时候，很多人为了让几行内容分行，硬写成列表——结果多了一堆没必要的圆点。换了硬换行，直接回车就行，语义还更准确。

## 列表没渲染对，先看这几处

**缩进用了 Tab 和空格混着来。** 源码里看着对，渲染出来层级乱掉。同一个列表里统一用一种。

**列表前后没空行。** 紧贴着上一段写 `- xxx`，可能不会变成列表。列表上下都空一行是最保险的习惯。

**有序列表从 0 开始或者跳号。** `0. 第一项` 在某些渲染器下会渲染成从 0 开始。想让它从 1 开始，就写 `1.`。
