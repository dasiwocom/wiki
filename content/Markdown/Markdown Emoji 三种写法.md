
> 适用场景：Obsidian 笔记、Markdown 写作、HTML 网页开发
> 核心结论：写笔记用 **Unicode 字符（直接粘贴表情）**；写网页用 **HTML 实体编码**；短码语法 Obsidian 原生不支持，慎用。

---

## 一、三种写法总览

| 写法 | 示例 | 本质 | Obsidian 笔记 | HTML 网页 |
| ---- | ---- | ---- | ---- | ---- |
| 1. Markdown 短码 | `:rocket:` | 扩展 Markdown 语法 | ❌ 原样显示文字 | ⚠️ 部分平台支持 |
| 2. Unicode 字符 | 🚀 | 普通文字字符 | ✅ 直接显示 | ✅ 正常显示 |
| 3. HTML 实体编码 | `&#128640;` | 浏览器专用字符代号 | ❌ 原样显示代码 | ✅ 浏览器渲染成表情 |

---

## 二、写法 1：Markdown 短码 `:emoji:`

语法：`:表情英文名:`

```markdown
:smile: :fire: :rocket: :+1:
```

特点：
- 输入方便，直接敲英文单词，不用复制粘贴表情
- 属于**扩展 Markdown**，不是标准语法
- ✅ 支持：GitHub、Notion、部分在线编辑器
- ❌ **Obsidian 默认不支持**，写了只会原样显示 `:smile:` 这串文字

---

## 三、写法 2：Unicode 字符（推荐写笔记用）

直接粘贴表情本身：🚀 😄 👍

```markdown
测试：🚀 😄 👍
```

特点：
- Emoji 本质上就是**一个文字字符**，和汉字、字母同属 Unicode 字符集
- ✅ Obsidian、WordPress、浏览器、数据库全都通用，**兼容性最好**
- ✅ 文件里保存的就是表情本身，所见即所得
- ❌ 键盘没有对应按键，无法直接输入，只能复制粘贴
- ⚠️ 旧系统 / 旧字体可能显示成方框 □

---

## 四、写法 3：HTML 实体编码 `&#数字;`（网页专用）

语法：`&#十进制编号;`

```html
<p>测试：&#128640; &#128516; &#128077;</p>
```

特点：
- 全部由普通字母和数字组成，**键盘可以直接敲**，不用复制表情
- 本质是"给浏览器看的字符代号"：浏览器读到这串代码，去 Unicode 编码表查到编号，翻译成对应表情
- ✅ 在 HTML 网页里，浏览器自动渲染成表情
- ❌ **在 Obsidian、记事本等 Markdown 编辑器里，原样展示这串代码，不会变成表情**
- 适合：网页开发、导出 HTML、需要键盘手输表情的场景

> 类比理解：
> - `👍` = 表情本身，像汉字"好"，任何软件打开都能直接看
> - `&#128077;` = 一段指令"请把编号 128077 对应的表情画出来"，只有浏览器能读懂

---

## 五、三种写法对比表

| 写法 | 例子 | Obsidian 笔记 | HTML 网页 | 优点 | 缺点 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| Markdown 短码 | `:rocket:` | ❌ 原样文字 | ⚠️ 部分平台 | 输入快 | 扩展语法，兼容性差 |
| Unicode 字符 | 🚀 | ✅ 直接显示 | ✅ 正常显示 | 全平台通用 | 键盘不能直接输入 |
| HTML 实体编码 | `&#128640;` | ❌ 原样代码 | ✅ 浏览器渲染 | 键盘可直接敲 | 仅限 HTML 环境 |

## 七、使用建议

1. **写 Obsidian 笔记**：优先用 **Unicode 字符（直接粘贴表情）**，兼容性最好
2. **写 HTML 网页**：可以用 **HTML 实体编码**，键盘可直接输入
3. **Markdown 短码**：Obsidian 原生不支持，不要在 Obsidian 里使用；GitHub、Notion 等平台可用
4. **格式别写错**：HTML 实体编码格式是 `&#数字;`，开头 `&#`、末尾分号 `;` 都不能少，少一个就失效

---

## 八、常见问题

**Q1：在 Obsidian 里写 `&#128077;` 为什么不显示表情？**
A：Obsidian 不是浏览器，不会翻译 HTML 实体代码，只会原样显示这串文字。要显示表情，直接粘贴 👍 字符。

**Q2：`:rocket:` 在 Obsidian 里为什么显示为文字？**
A：`:emoji:` 短码是 GitHub 等平台的扩展语法，Obsidian 原生没有内置解析器，需要装插件才支持。

**Q3：网页开发用哪个？**
A：推荐 HTML 实体编码，键盘可输入、不依赖复制粘贴；也可以直接粘贴 Unicode 表情，浏览器同样正常显示。

**Q4：旧电脑上表情显示成方框 □？**
A：说明系统或字体缺少该 emoji 字符，属于显示环境问题，不是写法问题。更新系统 / 换字体即可。
