# STC 芯片型号怎么看

## 一句话

芯片表面印的那串字就是它的型号，把它按段拆开读，就能知道这颗芯片的电压、容量和功能，也知道烧录软件里该选哪一条。

## 逐段拆解 `STC89C52RC`

| 段 | 含义 |
| --- | --- |
| **STC** | 厂商名（宏晶科技） |
| **89** | 内核系列：8051 内核、片内带 Flash |
| **C** | 供电电压：**5V 版**；写成 **LE** 则是 3V 低压版 |
| **52** | 程序空间（Flash）大小：**52 = 8KB**（51=4K、53=13K、58=32K、516=64K） |
| **RC** | 内部 RAM 大小：**512 字节**（RD+ 是 1280 字节） |

连起来读就是：**宏晶 · 8051 内核 Flash 系列 · 5V · 8KB 程序 · 512B 内存**。

## 那一杠后面的 `/LE52RC` 是什么

`STC89LE52RC` 是它的孪生版本，**除了供电电压是 2.0~3.6V 之外，Flash、RAM、定时器、串口全都一样**。因为两者烧录方式完全相同，烧录软件干脆把它们合并成一条，写成 `STC89C52RC/LE52RC`。

- 用 USB 的 5V 供电 → 对应的就是前半段
- 做 3V 电池供电的产品 → 才用后半段

> [!tip] 老版本软件里没有这一杠
> 旧版烧录软件里这条就叫 `STC89C52RC`，新版才把低压版合并进来。**指的是同一颗芯片**，选哪个都行，效果完全一样。

## 为什么不能只写 `STC89C52`（没有 RC）

那是**更早一代**的条目，内部 RAM 更小、也缺少后来增强的功能（ISP 升级、看门狗、双倍速等）。名字只差两个字母，但不是同一代产品，握手、擦除、校验的算法参数都不一样，选错可能表现为握手失败、擦除不全或校验不过。

## 怎么确认自己选对了

**看芯片表面的丝印**，和下拉框里的名字对得上就行。丝印是厂家打在芯片上的，比任何教程截图都可靠。

> [!note] 丝印要连着读全
> 芯片上通常还印有一行生产批次（如日期、产地代码），那不是型号。找带 `STC` 开头、含数字字母组合的那一行。
