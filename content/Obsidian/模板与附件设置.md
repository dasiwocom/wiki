# 模板与附件设置

> 本仓库的 Obsidian 侧配置：模板从哪来、附件存哪、frontmatter 哪些可省。

## 模板

- 核心插件「**模板**」需要手动开启：设置 → 核心插件 → 模板
- 模板目录设为 `templates`（配置文件 `.obsidian/templates.json` 里已写 `"folder": "templates"`）
- 当前只有一个模板：`templates/笔记模板.md`

用法：`Ctrl+P` →「从模板新建笔记」→ 选 `笔记模板` → 输入文件名。建议在「设置 → 快捷键」里给这个命令绑个键。

模板内容：

```markdown
---
title: "{{title}}"
date: {{date:YYYY-MM-DD}}
tags: []
draft: false
---

# {{title}}
```

`{{title}}` 会填成文件名，`{{date:YYYY-MM-DD}}` 会填成当天日期。这两个是 Obsidian 的变量，插入模板时自动展开。

## 附件

`.obsidian/app.json` 里设了 `attachmentFolderPath: "Attachments"`，粘贴图片会自动存到 `content/Attachments/`。

- `Attachments\` **不在 `.gitignore` 里**，图片会正常提交并发布到网站
- 笔记里用 `![[图片名.png]]` 嵌入，Quartz 的 `obsidian-flavored-markdown` 插件负责解析

⚠️ **暗色模式坑**：透明背景的 SVG 在网站暗色主题下会看不见（深色线条 + 深色背景）。导出时勾选**带背景色**，或者直接用 PNG。

## frontmatter 哪些可以省

| 字段 | 不写会怎样 |
| --- | --- |
| `title` | Quartz 直接用文件名，正常显示 |
| `date` | 用文件的创建时间排序，效果一样 |
| `tags` | 只是不做标签聚合，不影响别的 |
| `draft` | 默认发布 |

**唯一值得记的是 `draft`**：写了半成品不想公开时，把 `draft` 改成 `true`，Quartz 构建时会跳过它，只留在本地 Obsidian 里。

所以模板只是省事，不是必需——直接新建空白笔记写正文也完全没问题。
