# 变量和数据类型

程序要处理数据，数据得先有个名字存着。

## 三种声明方式

```javascript
let count = 0;      // 可以改
const PI = 3.14;    // 不能改
var old = "过时了"; // 老写法，别用
```

| | 能改吗 | 作用范围 | 现在用吗 |
| --- | --- | --- | --- |
| `let` | 能 | 当前代码块 | 用 |
| `const` | 不能 | 当前代码块 | 优先用 |
| `var` | 能 | 整个函数 | 不要用 |

**默认写 `const`**，只有确实要改的时候才换成 `let`。

这样做的好处是：一个变量写完之后不会被人随手改掉，出了 bug 少一个怀疑对象。

`var` 是 ES6 之前唯一的选择，它有两个毛病：作用范围不受代码块限制、允许重复声明。看到老代码里有它正常，新代码就别写了。

## 改了会怎样

```javascript
const PI = 3.14;
PI = 3.15;
// 报错：Assignment to constant variable.
```

报错不会让整个页面崩溃，只是这一句之后就不再执行了。

## 命名规则

```javascript
let userName = "张三";     // 小驼峰，推荐
let user_name = "李四";    // 下划线，也常见
let 用户名 = "王五";        // 中文能用，但别这么写
```

- 只能由字母、数字、`$`、`_` 组成
- **不能以数字开头**：`2name` 是错的
- 不能和保留字重名：`let`、`const`、`class`、`return`
- 区分大小写

名字要能看出它是什么。`d` 不如 `days`，`days` 不如 `remainingDays`。

## 七种数据类型

```javascript
let n = 42;                 // number   数字
let s = "你好";             // string   字符串
let b = true;               // boolean  布尔
let empty = null;           // null     空
let notSet;                 // undefined 未赋值
let obj = { a: 1 };         // object   对象
let sym = Symbol("id");     // symbol   符号（很少手写）
```

前六种加上 `symbol`，就是 JavaScript 的全部类型。

**注意没有"整数"和"小数"的区分**，`42` 和 `42.5` 都是 number。

## number

```javascript
let a = 42;
let b = 3.14;
let c = 1e6;        // 科学计数法，等于 1000000
let d = 0b1010;     // 二进制，等于 10
let e = 0xff;       // 十六进制，等于 255
```

有个出了名的坑：

```javascript
0.1 + 0.2
// 0.30000000000000004
```

这是所有编程语言的浮点数通病，不是 JavaScript 独有的。要比较小数，先转成整数算，或者比"差值是否足够小"。

## string

单引号、双引号都可以：

```javascript
let s1 = "你好";
let s2 = '你好';
```

模板字符串用反引号，这是最常用的写法：

```javascript
let name = "张三";
let age = 18;

let msg = `我叫 ${name}，今年 ${age} 岁。`;
// "我叫 张三，今年 18 岁。"
```

`${}` 里面可以放任何表达式：

```javascript
console.log(`${2 + 3} 除以 2 等于 ${(2 + 3) / 2}`);
// "5 除以 2 等于 2.5"
```

模板字符串还能直接换行，不需要 `\n`：

```javascript
let html = `
  <div>
    <p>多行内容</p>
  </div>
`;
```

拼接字符串的时候，模板字符串比一串 `+` 好读太多。

## boolean

```javascript
let isReady = true;
let isEmpty = false;
```

它的用处在下一篇（比较和条件）里讲。

## null 和 undefined

这两个都是"没有值"，但来源不同：

```javascript
let a;              // undefined：声明了但没赋值
let b = null;       // null：我主动把它设成空
```

记住一句话：**`undefined` 是系统给的，`null` 是你给的。**

读取一个不存在的对象属性会得到 `undefined`；将来要返回"空"的时候，按约定返回 `null`。

## typeof：看看是什么类型

```javascript
typeof 42          // "number"
typeof "abc"       // "string"
typeof true        // "boolean"
typeof undefined   // "undefined"
typeof null        // "object"  ← 历史遗留的错，记住就好
typeof {}          // "object"
typeof []          // "object"  ← 数组也是 object
typeof function(){} // "function"
```

`typeof null` 返回 `"object"` 是 JavaScript 最著名的一个 bug，1995 年就存在，改不动了，只能记住。

想知道一个值是不是数组，用 `Array.isArray(x)`，别用 `typeof`。

## 类型转换

JavaScript 会自动转换类型，这是它的特点也是坑的来源：

```javascript
"5" + 1      // "51"   ← 加号遇到字符串就拼接
"5" - 1      // 4      ← 减号强制转数字
"5" * "2"    // 10
true + 1     // 2
"abc" - 1    // NaN（Not a Number）
```

`+` 号是最容易出问题的一个，因为它既能加又能拼。

手动转换更稳妥：

```javascript
Number("42")      // 42
parseInt("42px")  // 42，遇到非数字就停
parseFloat("3.14")// 3.14
String(42)        // "42"
(42).toString()   // "42"
Boolean("")       // false
```

`parseInt` 和 `Number` 的区别：`Number("42px")` 得到 `NaN`，`parseInt("42px")` 得到 `42`。

从输入框拿到的值永远是字符串，用之前记得转：

```javascript
let input = document.getElementById("age").value;  // "18"，是字符串
let age = Number(input);                            // 18，这才是数字
```
