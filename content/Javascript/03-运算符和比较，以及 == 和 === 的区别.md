# 运算符和比较，以及 == 和 === 的区别

这一篇里有 JavaScript 最著名的一个反直觉设计。

## 算术运算符

```javascript
5 + 2    // 7
5 - 2    // 3
5 * 2    // 10
5 / 2    // 2.5   ← 不像别的语言会取整
5 % 2    // 1     ← 取余数
5 ** 2   // 25    ← 乘方
```

`%` 取余数，判断奇偶、循环计数都用它：

```javascript
7 % 2 === 1   // true，奇数
8 % 2 === 0   // true，偶数
```

自增自减：

```javascript
let n = 1;
n++;     // n 变成 2
n--;     // n 变回 1
```

`n++` 和 `++n` 在单独一行时没区别，混在表达式里就有区别：

```javascript
let a = 1;
console.log(a++);   // 1，先取值再自增
console.log(a);     // 2

let b = 1;
console.log(++b);   // 2，先自增再取值
```

这种写法可读性差，建议自增单独写一行。

## 赋值运算符

```javascript
let n = 10;

n += 5;   // 等价于 n = n + 5，n 变成 15
n -= 3;   // 12
n *= 2;   // 24
n /= 4;   // 6
n %= 4;   // 2
```

写累加的时候很常用。

## 字符串拼接

```javascript
"你好" + "世界"       // "你好世界"
"共 " + 3 + " 项"     // "共 3 项"
```

注意加号和数字混用：

```javascript
1 + 2 + "3"    // "33"   ← 先算 1+2=3，再和 "3" 拼接
"1" + 2 + 3    // "123"  ← 碰到字符串之后全变拼接
```

从左往右算，碰到字符串就当拼接。这种不确定性就是为什么推荐用模板字符串：

```javascript
`${1 + 2}3`    // "33"，但意图清清楚楚
```

## 比较运算符

```javascript
5 > 2      // true
5 < 2      // false
5 >= 5     // true
5 <= 4     // false
5 === 5    // true   全等
5 !== 4    // true   不全等
5 == "5"   // true   ← 松散相等，别用
5 === "5"  // false  ← 类型不同，不相等
```

## == 和 === 的区别

这是 JavaScript 最该早点知道的一条。

`==` 在比较之前会**自动转换类型**，`===` 不会。

```javascript
1 == "1"        // true   （"1" 被转成数字 1）
1 === "1"       // false  （类型不同）
0 == false      // true
0 === false     // false
null == undefined  // true
null === undefined // false
"" == 0         // true
[] == 0         // true
[] == false     // true
```

后面几条已经很难预测了。更离谱的：

```javascript
NaN == NaN      // false  ← 自己不等于自己
NaN === NaN     // false
```

判断一个值是不是 `NaN`，要用 `Number.isNaN(x)`，不能用 `==`。

**结论：永远用 `===` 和 `!==`。** 只有判断 `x == null` 这一个场景是例外（它能同时匹配 `null` 和 `undefined`，是有意这么用的）。

## 逻辑运算符

```javascript
true && false    // false   与：两个都真才真
true || false    // true    或：一个真就真
!true            // false   非：取反
```

`&&` 和 `||` 有"短路"特性，这是它们最实用的地方：

```javascript
// && ：左边为假，右边不执行
isLogin && loadUserData();

// || ：左边为真，右边不执行，常用于给默认值
let name = inputName || "匿名";

// 判断存在再取属性，防止报错
user && user.address && user.address.city;
```

## ?? 和 ?.

这两个是后来加上去的新写法，专门解决上面最后两条的老问题。

```javascript
// ?? 只在左边是 null 或 undefined 时才用右边
let count = 0;
count || 10    // 10  ← 错了！0 是合法的值
count ?? 10    // 0   ← 对

// ?. 左边是空就整个返回 undefined，不报错
user?.address?.city    // 一路为空都不会崩
```

`||` 会把 `0`、`""`、`false` 都当成"没有"，`??` 只认 `null` 和 `undefined`。要处理数字和布尔值时，用 `??` 更准。

## 三元运算符

一个简写的 `if...else`：

```javascript
let msg = age >= 18 ? "成年" : "未成年";
```

格式是 `条件 ? 条件为真时的值 : 条件为假时的值`。

一行能做判断很方便，但别嵌套：

```javascript
// 别这么写，读不懂
let r = a ? b ? c : d : e ? f : g;
```

嵌套超过一层，就老老实实写 `if`。

## 真假值

在 `if` 里，下面这些都会被当成 `false`：

```javascript
false
0
-0
0n        （BigInt 的零）
""        （空字符串）
null
undefined
NaN
```

**其他所有值都是 `true`**，包括：

```javascript
"0"       // true，非空字符串就是真
"false"   // true
[]        // true，空数组也是真
{}        // true，空对象也是真
-1        // true
```

`[]` 和 `{}` 是真，这点和很多人的直觉相反。想判断数组是不是空的，要写 `arr.length === 0`。
