# 事件，用户做了什么就响应什么

页面上的"互动"就是事件：点一下、输个字、滚一下、提交表单。

## 监听一个事件

```javascript
const btn = document.querySelector("#btn");

btn.addEventListener("click", () => {
  console.log("被点了");
});
```

三个参数：

```text
addEventListener("事件名", 要执行的函数, 可选配置)
```

监听可以加多个，都会执行；也可以只写一次 `onclick` 属性，但那样再加第二个就会覆盖第一个。

**优先用 `addEventListener`**，它更可控。

## 常见事件

**鼠标**

| 事件 | 什么时候触发 |
| --- | --- |
| `click` | 点击 |
| `dblclick` | 双击 |
| `mouseenter` / `mouseleave` | 移入 / 移出（不冒泡，推荐） |
| `mouseover` / `mouseout` | 移入 / 移出（会冒泡，容易触发多次） |
| `mousedown` / `mouseup` | 按下 / 松开 |

**键盘**

| 事件 | 什么时候触发 |
| --- | --- |
| `keydown` | 按下某个键 |
| `keyup` | 松开某个键 |
| `input` | 输入框内容变化（**推荐，实时生效**） |
| `change` | 内容变完且失去焦点（下拉框、复选框常用） |
| `focus` / `blur` | 获得 / 失去焦点 |

**其他**

| 事件 | 什么时候触发 |
| --- | --- |
| `submit` | 表单提交 |
| `scroll` | 滚动 |
| `load` | 资源加载完 |
| `DOMContentLoaded` | HTML 解析完 |

## 事件对象

回调函数的第一个参数是事件对象，里面全是这次事件的细节：

```javascript
document.querySelector("a").addEventListener("click", e => {
  console.log(e.target);          // 真正被点到的元素
  console.log(e.currentTarget);   // 绑事件的那个元素
  console.log(e.type);            // "click"
});
```

键盘事件：

```javascript
input.addEventListener("keydown", e => {
  console.log(e.key);        // "a"、"Enter"、"Escape"
  console.log(e.code);       // "KeyA"，物理按键位置
  if (e.key === "Enter") { submit(); }
});
```

鼠标位置：

```javascript
box.addEventListener("click", e => {
  console.log(e.clientX, e.clientY);   // 相对视口
  console.log(e.offsetX, e.offsetY);   // 相对元素
});
```

## 阻止默认行为

有些元素自带行为，比如链接会跳转、表单会提交、右键会弹出菜单。

```javascript
form.addEventListener("submit", e => {
  e.preventDefault();      // 阻止提交（不刷新页面）
  // 自己处理数据
});

a.addEventListener("click", e => {
  e.preventDefault();      // 阻止跳转
});
```

`preventDefault()` 是"别做你本来要做的事"。

`e.stopPropagation()` 是另一回事——它是"别再往上层传了"，见下面。

## 事件冒泡

点击一个按钮，事件会从按钮开始，一层层往上冒到它的父元素、祖父元素……直到 `document`。

```html
<div id="outer">
  <button id="inner">点我</button>
</div>
```

```javascript
outer.addEventListener("click", () => console.log("外层"));
inner.addEventListener("click", () => console.log("按钮"));

// 点按钮时，两个都会打印：
// 按钮
// 外层
```

想让它只触发最里面那个：

```javascript
inner.addEventListener("click", e => {
  e.stopPropagation();
  console.log("只打印这一条");
});
```

`stopPropagation` 能不用就别用，它会让事件流变得难以预测。

## 事件委托

冒泡最有用的地方：**给一组动态生成的元素绑事件，不用一个个绑，绑在父元素上就行。**

```html
<ul id="list">
  <li data-id="1">张三</li>
  <li data-id="2">李四</li>
</ul>
```

```javascript
document.querySelector("#list").addEventListener("click", e => {
  const li = e.target.closest("li");
  if (!li) return;

  console.log("点了", li.dataset.id);
});
```

好处：

- 只用绑一个监听器，不是一百个
- 以后新加进来的 `<li>` **自动就有事件**，不用重新绑

`e.target` 是真正被点到的最深层元素（可能是 `<li>` 里的一个 `<span>`），`closest("li")` 往上找最近的 `<li>`，很常用。

列表、菜单、表格这类结构，一律用事件委托。

## 移除监听

```javascript
function onClick() {
  console.log("点了");
}

btn.addEventListener("click", onClick);
btn.removeEventListener("click", onClick);   // 必须传同一个函数引用
```

匿名函数没法移除——因为拿不到引用。需要移除时，把函数写在外面。

一次性监听可以用 `once`：

```javascript
btn.addEventListener("click", handle, { once: true });   // 只触发一次
```

## 取消订阅的时机

页面上元素被删掉了，绑在它上面的事件监听器一般会被一起回收，不用手动清。

但**绑在 `window`、`document` 上的监听不会**，比如滚动、`resize`。反复切换页面时这类监听会越积越多：

```javascript
function onScroll() { /* ... */ }

window.addEventListener("scroll", onScroll);

// 不用了要记得
window.removeEventListener("scroll", onScroll);
```

## 一个完整的例子

点一下按钮，给列表加一条，再点那条能删掉：

```html
<ul id="list"></ul>
<button id="add">加一条</button>

<script>
  const list = document.querySelector("#list");
  let id = 0;

  document.querySelector("#add").addEventListener("click", () => {
    const li = document.createElement("li");
    li.dataset.id = ++id;
    li.textContent = `第 ${id} 条（点我删掉）`;
    list.appendChild(li);
  });

  // 事件委托：绑在 ul 上，所有 li（包括以后加的）都能响应
  list.addEventListener("click", e => {
    const li = e.target.closest("li");
    if (!li) return;
    li.remove();
    console.log("删掉了第", li.dataset.id, "条");
  });
</script>
```

页面一刷新就能用，加多少条都能删。这段代码用到了这一篇里的全部知识点。
