# 对象，把相关的数据装在一起

数组是"一串同类的东西"，对象是"一个东西的各个部分"。

## 定义和取值

```javascript
const user = {
  name: "张三",
  age: 18,
  isAdmin: false
};

user.name;         // "张三"   点号
user["name"];      // "张三"   方括号
```

两种取值方式，点号更常用。

**方括号的用处**是"键存在变量里"或者"键名里有特殊字符"：

```javascript
const key = "age";
user[key];              // 18

const data = { "user-name": "李四" };
data["user-name"];      // "李四"
data.user-name;         // 报错
```

属性名可以是字符串，但如果是合法的标识符，写的时候引号可以省。

## 改、加、删

```javascript
user.age = 19;              // 改
user.city = "上海";         // 加
delete user.isAdmin;        // 删

"age" in user;              // true，判断有没有这个键
user.phone === undefined;   // 另一个判断办法
```

## 嵌套

```javascript
const order = {
  id: 1001,
  customer: {
    name: "张三",
    address: { city: "上海", street: "南京路" }
  },
  items: ["键盘", "鼠标"]
};

order.customer.address.city;   // "上海"
order.items[0];                // "键盘"
```

一层层点下去就行。

但访问嵌套对象要小心：

```javascript
const empty = {};
empty.customer.name;      // 报错：Cannot read properties of undefined

// 安全写法
empty.customer?.name;     // undefined，不报错
```

`?.` 遇到 `undefined` 就停下来返回 `undefined`，不会继续往下点。从接口拿到的数据，字段有没有并不确定，这种地方都该用 `?.`。

## 对象里的函数叫方法

```javascript
const counter = {
  count: 0,
  add() {
    this.count++;   // this 指向这个对象
    return this.count;
  }
};

counter.add();   // 1
counter.add();   // 2
```

方法里用 `this` 指自己。注意**方法不要写成箭头函数**，箭头函数的 `this` 不指向对象（见 [[07-作用域和 this，变量能被谁看见|作用域和 this]]）。

## 遍历对象

```javascript
const user = { name: "张三", age: 18, city: "上海" };

// 拿键的数组
Object.keys(user);      // ["name", "age", "city"]

// 拿值的数组
Object.values(user);    // ["张三", 18, "上海"]

// 拿键值对的数组
Object.entries(user);   // [["name", "张三"], ["age", 18], ["city", "上海"]]
```

配合解构遍历：

```javascript
Object.entries(user).forEach(([key, value]) => {
  console.log(`${key}：${value}`);
});
```

还有 `for...in`（见 [[05-循环，重复的事情交给代码|循环那篇]]），但它会把原型链上的属性也带出来，用 `Object.keys` 系列更稳。

## 解构：把属性拿出来

```javascript
const user = { name: "张三", age: 18, city: "上海" };

// 老写法
const name = user.name;
const age = user.age;

// 解构
const { name, age } = user;
```

还能改名、给默认值：

```javascript
const { name: userName, phone = "未填" } = user;
// userName 是 "张三"，phone 是 "未填"
```

函数参数里解构最常用：

```javascript
function greet({ name, age = 18 }) {
  return `${name}，${age} 岁`;
}

greet(user);
```

## 展开运算符

```javascript
const base = { a: 1, b: 2 };
const more = { ...base, c: 3 };
// { a: 1, b: 2, c: 3 }

// 覆盖某一项（常用于"改一个字段，其余不动"）
const updated = { ...base, b: 99 };
// { a: 1, b: 99 }
```

后面的同名属性会覆盖前面的。

**注意这是"浅复制"**：只复制第一层，嵌套的对象还是共享的。

```javascript
const a = { list: [1, 2] };
const b = { ...a };
b.list.push(3);
console.log(a.list);   // [1, 2, 3]  ← a 也被改了
```

要深复制，用 `structuredClone(obj)`，或者 `JSON.parse(JSON.stringify(obj))`（后者会丢掉函数和 `undefined`）。

## 数组和对象的互转

```javascript
// 对象 → 数组
Object.entries({ a: 1, b: 2 });   // [["a", 1], ["b", 2]]

// 数组 → 对象
Object.fromEntries([["a", 1], ["b", 2]]);   // { a: 1, b: 2 }
```

`Object.fromEntries` 配 `map` 很好用：

```javascript
const pairs = [["name", "张三"], ["age", 18]];
Object.fromEntries(pairs);   // { name: "张三", age: 18 }
```

## JSON 不是对象

经常有人把这两个当一回事。

```javascript
// 这是一个 JS 对象
const obj = { name: "张三", greet() { return "hi"; } };

// 这是一段 JSON 字符串
const json = '{"name":"张三"}';
```

区别：

| | JS 对象 | JSON |
| --- | --- | --- |
| 是什么 | 内存里的数据结构 | 一串文本 |
| 键名 | 可以不加引号 | **必须加双引号** |
| 值 | 可以是函数、undefined | 只能是字符串、数字、布尔、null、数组、对象 |
| 末尾逗号 | 允许 | 不允许 |

互转：

```javascript
JSON.stringify(obj);              // 对象 → 字符串，发请求时用
JSON.parse('{"name":"张三"}');    // 字符串 → 对象，收到响应时用
```

浏览器里存东西（`localStorage`）只能存字符串，所以要先把对象 `stringify` 再存，读出来再 `parse`。

```javascript
localStorage.setItem("user", JSON.stringify(user));

const saved = JSON.parse(localStorage.getItem("user"));
```

`JSON.parse` 遇到不合法的字符串会直接抛错，从外部拿到数据时记得用 `try...catch` 兜一下。
