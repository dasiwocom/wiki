# 数组，以及几个好用的数组方法

一串数据的容器。JavaScript 里有几个数组方法，学会之后能省掉大量循环。

## 创建和取值

```javascript
const fruits = ["苹果", "香蕉", "橘子"];

fruits[0];        // "苹果"  ← 下标从 0 开始
fruits[2];        // "橘子"
fruits[3];        // undefined，越界不报错
fruits.length;    // 3
fruits[fruits.length - 1];   // "橘子"，取最后一个
```

**下标从 0 开始**，所以最后一项是 `length - 1`。

越界读不会报错，只会得到 `undefined`。这是 bug 的一个常见来源。

取最后一个也可以用 `fruits.at(-1)`，负数下标从后往前数。

## 改和增删

```javascript
const arr = [1, 2, 3];

arr[0] = 99;            // 改：[99, 2, 3]

arr.push(4);            // 尾部加一个 → [99, 2, 3, 4]
arr.pop();              // 尾部删一个 → [99, 2, 3]
arr.unshift(0);         // 头部加一个 → [0, 99, 2, 3]
arr.shift();            // 头部删一个 → [99, 2, 3]

arr.length = 1;         // 截断 → [99]
```

这些方法**都会改变原数组**。

`push` 和 `pop` 的返回值要注意：`push` 返回新的长度，`pop` 返回被删掉的那个元素。

```javascript
const a = [1, 2];
const len = a.push(3);   // len 是 3，不是数组
```

## splice：任意位置增删

```javascript
const arr = ["a", "b", "c", "d"];

arr.splice(1, 2);            // 从下标 1 开始删 2 个 → ["a", "d"]
arr.splice(1, 0, "x");       // 从下标 1 开始删 0 个，插入 "x" → ["a", "x", "d"]
arr.splice(1, 1, "y", "z");  // 删 1 个再插入两个 → ["a", "y", "z", "d"]
```

参数是 `(从哪开始, 删几个, 要插入的东西…)`。

它会改变原数组，返回值是被删掉的那些元素组成的数组。

## slice 和 splice 容易搞混

```javascript
const arr = [1, 2, 3, 4, 5];

// slice：截取一段，不改原数组
arr.slice(1, 3);    // [2, 3]，从下标 1 到 3（不含 3）
arr.slice(-2);      // [4, 5]，最后两个
arr.slice();        // 复制一份整个数组

// splice：会改原数组
arr.splice(1, 2);   // 原数组变成 [1, 4, 5]
```

一个字母的差别，行为完全不同：**`slice` 是"切一份给你的"，`splice` 是"从原数组里挖走"。**

想复制数组，最省事的写法是：

```javascript
const copy = [...arr];      // 展开运算符
const copy2 = arr.slice();
```

## 查找

```javascript
const list = ["苹果", "香蕉", "橘子", "香蕉"];

list.indexOf("香蕉");        // 1，第一次出现的下标
list.lastIndexOf("香蕉");    // 3，最后一次出现的下标
list.indexOf("西瓜");        // -1，没找到

list.includes("橘子");       // true，只要判断有没有，用这个
```

`indexOf` 找不到返回 `-1`。判断"有没有"用 `includes`，比 `indexOf(...) !== -1` 好读。

找对象数组里的某一项：

```javascript
const users = [
  { id: 1, name: "张三" },
  { id: 2, name: "李四" }
];

users.find(u => u.id === 2);      // { id: 2, name: "李四" }
users.findIndex(u => u.id === 2); // 1
```

`find` 返回第一个匹配的元素本身，`findIndex` 返回它的下标，都没有就返回 `undefined` / `-1`。

## 拼接和转字符串

```javascript
const a = [1, 2];
const b = [3, 4];

a.concat(b);        // [1, 2, 3, 4]
[...a, ...b];       // 一样的效果，现在更常用这个

const words = ["你好", "世界"];
words.join("");     // "你好世界"
words.join("、");   // "你好、世界"
```

`join` 是数组转字符串最方便的办法，把列表渲染成一行文字时常用。

## 排序

```javascript
const nums = [10, 9, 100, 2];

nums.sort();                  // [10, 100, 2, 9]  ← 按字符串排，不是你要的
nums.sort((a, b) => a - b);   // [2, 9, 10, 100]  ← 升序
nums.sort((a, b) => b - a);   // [100, 10, 9, 2]  ← 降序
```

**默认的 `sort()` 是把元素当字符串比的**，所以 `10` 排在 `2` 前面。排序数字一定要给比较函数。

`sort` 会改变原数组。要在不改原数组的前提下排序：

```javascript
const sorted = [...nums].sort((a, b) => a - b);
```

从数组里找最大最小值：

```javascript
Math.max(...nums);   // 100
Math.min(...nums);   // 2
```

## map：每一项都变一下

```javascript
const nums = [1, 2, 3];

nums.map(n => n * 2);         // [2, 4, 6]
nums.map(n => `第${n}项`);    // ["第1项", "第2项", "第3项"]
```

**长度不变，一一对应**，生成一个新数组。原数组不动。

最常见的用途：把数据渲染成 HTML。

```javascript
const items = ["苹果", "香蕉"];
const html = items.map(f => `<li>${f}</li>`).join("");
```

## filter：筛出符合条件的那几个

```javascript
const nums = [1, 2, 3, 4, 5, 6];

nums.filter(n => n % 2 === 0);   // [2, 4, 6]
nums.filter(n => n > 3);         // [4, 5, 6]
```

回调返回 `true` 的留下，返回 `false` 的丢掉。长度会变，元素本身不变。

## reduce：把一整个数组缩成一个值

```javascript
const nums = [1, 2, 3, 4];

nums.reduce((total, n) => total + n, 0);   // 10，求和
```

`reduce` 有两个参数：一个累计函数和一个初始值。

累计函数每轮拿到"目前累计的结果"和"当前这一项"，返回新的累计结果。

不写初始值的时候，会拿数组第一项当初始值，从第二项开始遍历。**建议永远写初始值**，不写容易在空数组上出错。

除了求和，还能做很多事：

```javascript
// 求最大值
nums.reduce((max, n) => n > max ? n : max, -Infinity);

// 按字段分组
const users = [
  { name: "张三", city: "上海" },
  { name: "李四", city: "北京" },
  { name: "王五", city: "上海" }
];

users.reduce((groups, u) => {
  (groups[u.city] ??= []).push(u.name);
  return groups;
}, {});
// { 上海: ["张三", "王五"], 北京: ["李四"] }
```

## 三个方法连起来

这是日常写得最多的一种"流水线"：

```javascript
const orders = [
  { item: "键盘", price: 300, paid: true },
  { item: "鼠标", price: 100, paid: false },
  { item: "显示器", price: 1200, paid: true }
];

const total = orders
  .filter(o => o.paid)        // 只留已付款的
  .map(o => o.price)          // 取出价格
  .reduce((sum, p) => sum + p, 0);   // 求和

// 1500
```

**筛 → 变 → 合**，三步走。比写一个循环加几个 `if` 清楚得多。

## 别忘了 forEach

```javascript
nums.forEach((n, i) => {
  console.log(i, n);
});
```

`forEach` 只做遍历，**不返回新数组**，也就不能接着往下链。

它和 `map` 的区别：`map` 是为了拿到结果，`forEach` 是为了做动作（打印、写页面、发请求）。

## 判断是不是数组

```javascript
Array.isArray([1, 2]);   // true
Array.isArray("abc");    // false
typeof []                // "object"  ← 所以不能靠 typeof
```
