# 字符串和数字的常用方法

这两类数据每天都要处理，把常用的方法记熟能省下大量查文档的时间。

## 字符串

字符串是不可变的——所有方法都返回新字符串，原字符串不动。

### 长度和取字符

```javascript
const s = "Hello 世界";

s.length;        // 8，空格也算一个字符
s[0];            // "H"
s.at(-1);        // "界"，最后一个
s.charAt(1);     // "e"
```

### 查找

```javascript
const s = "Hello World";

s.indexOf("o");            // 4，第一次出现的下标
s.lastIndexOf("o");        // 7，最后一次
s.includes("World");       // true，有没有
s.startsWith("Hello");     // true，开头是不是
s.endsWith("World");       // true，结尾是不是
```

`includes`、`startsWith`、`endsWith` 都比 `indexOf(...) !== -1` 直观，优先用。

### 截取

```javascript
const s = "Hello World";

s.slice(0, 5);       // "Hello"，从 0 到 5（不含 5）
s.slice(6);          // "World"，从 6 到结尾
s.slice(-5);         // "World"，最后 5 个
```

`substring` 效果类似，但不支持负数下标，新代码用 `slice` 就行。

### 大小写和去空格

```javascript
"Hello".toUpperCase();      // "HELLO"
"Hello".toLowerCase();      // "hello"

"  a b  ".trim();           // "a b"    去掉两头空格
"  a b  ".trimStart();      // "a b  "  只去左边
"  a b  ".trimEnd();        // "  a b"  只去右边
```

`trim()` 最常用的场合是处理用户输入——从输入框拿到的值总是带着用户不小心敲的空格：

```javascript
if (input.value.trim() === "") {
  alert("不能为空");
}
```

### 替换

```javascript
"a-b-c".replace("-", "+");        // "a+b-c"，只换第一个
"a-b-c".replaceAll("-", "+");     // "a+b+c"，换全部

"2026-10-03".replace(/-/g, "/");  // "2026/10/03"，正则写法，效果同 replaceAll
```

`replace` 默认只替换第一处，这是最容易踩的坑。要全换就 `replaceAll` 或者用带 `g` 标志的正则。

### 切分和合并

```javascript
"苹果,香蕉,橘子".split(",");      // ["苹果", "香蕉", "橘子"]
"abc".split("");                  // ["a", "b", "c"]
"a b  c".split(" ");              // ["a", "b", "", "c"]  ← 连续空格会切出空串

["苹果", "香蕉"].join("、");       // "苹果、香蕉"
```

`split` 和数组的 `join` 是一对反操作，处理 CSV 之类的数据时全靠它们。

### 补位和重复

```javascript
"5".padStart(3, "0");   // "005"，前面补零
"5".padEnd(3, "0");     // "500"
"ab".repeat(3);         // "ababab"
```

`padStart` 做时间格式化很好用：

```javascript
const h = String(9).padStart(2, "0");   // "09"
```

## 转换

```javascript
String(42);        // "42"
(42).toString();   // "42"
Number("42");      // 42
parseInt("42px");  // 42
parseFloat("3.14abc");  // 3.14
+"42";             // 42，一元加号也能转数字，但可读性差
```

记住几组诡异的结果：

```javascript
Number("")          // 0
Number("  ")        // 0
Number("abc")       // NaN
Number(null)        // 0
Number(undefined)   // NaN
Number(true)        // 1
parseInt("")        // NaN   ← 和 Number 不一样
parseInt("0x10")    // 16
parseInt("10", 2)   // 2，第二个参数是进制
```

`Number("")` 是 `0` 但 `parseInt("")` 是 `NaN`，这两个的差异在很多表单校验里咬过人。

## 数字

### 判断和取整

```javascript
Number.isInteger(5);      // true
Number.isInteger(5.5);    // false
Number.isNaN(NaN);        // true，判断是不是 NaN

Math.round(4.5);          // 5   四舍五入
Math.floor(4.9);          // 4   向下取整
Math.ceil(4.1);           // 5   向上取整
Math.trunc(4.9);          // 4   直接砍掉小数
Math.abs(-3);             // 3   绝对值
```

### 格式化小数

```javascript
(3.14159).toFixed(2);     // "3.14"  ← 注意返回的是字符串
(3).toFixed(2);           // "3.00"
```

`toFixed` 返回**字符串**，别直接拿去做加减法：

```javascript
1 + (1.005).toFixed(2);   // "11.00"，拼接了
```

还有个精度问题：

```javascript
(1.005).toFixed(2);       // "1.00"，不是 "1.01"
```

因为 `1.005` 在计算机里其实是 `1.00499...`。真要精确运算（金额），用整数分做单位，或者用专门的小数库。

### 其他常用

```javascript
Math.max(1, 5, 3);        // 5
Math.min(1, 5, 3);        // 1
Math.max(...[1, 5, 3]);   // 5，配合展开运算符处理数组
Math.random();            // 0 到 1 之间的随机小数

// 1 到 10 的随机整数
Math.floor(Math.random() * 10) + 1;

Math.pow(2, 10);          // 1024
2 ** 10;                  // 1024，现在更常用这个
```

## 日期

```javascript
const now = new Date();          // 当前时间
new Date("2026-10-03");          // 从字符串创建
new Date(2026, 9, 3);            // 年月日，注意月份从 0 开始！
```

**月份是 0 到 11**，所以 10 月要写 `9`。这是 JavaScript 日期里最著名的坑。

常用的取值方法：

```javascript
d.getFullYear();     // 2026
d.getMonth();        // 0 ~ 11
d.getDate();         // 1 ~ 31，注意不是 getDay
d.getDay();          // 0 ~ 6，0 是周日
d.getHours();
d.getMinutes();
d.getSeconds();

d.getTime();         // 时间戳（毫秒）
d.toLocaleDateString("zh-CN");   // "2026/10/3"
d.toLocaleTimeString("zh-CN");   // "13:42:35"
```

时间戳是"从 1970 年 1 月 1 日到现在过了多少毫秒"，两个时间相减就能算出间隔：

```javascript
const start = Date.now();
// ...做点什么...
const cost = Date.now() - start;   // 毫秒
```

`Date.now()` 比 `new Date().getTime()` 更直接。

日期计算要小心：

```javascript
const d = new Date("2026-10-03");
d.setDate(d.getDate() + 7);   // 一周后，跨月跨年它会自己处理
```

格式化输出最省事的是 `toLocaleDateString`，要自定义格式就手动拼：

```javascript
const fmt = d => `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, "0")}-${String(d.getDate()).padStart(2, "0")}`;
fmt(new Date());   // "2026-10-03"
```
