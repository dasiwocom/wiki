# 循环，重复的事情交给代码

要处理一百条数据，就写一百行代码——这是人干的活。循环是给机器干的。

## for：最常用的一个

```javascript
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

输出：

```text
0
1
2
3
4
```

圆括号里是三段，用分号隔开：

```text
for ( 初始值 ; 条件 ; 每轮之后做什么 )
      let i=0   i<5    i++
```

执行顺序是：先跑初始值（只跑一次）→ 判断条件 → 成立就执行花括号 → 执行 `i++` → 再判断条件 → ……

**条件不成立就结束**，所以是 `0` 到 `4`，五次。

`i++` 是"每循环一轮加一"，是循环能结束的原因。忘了写它，条件永远成立，就是死循环，页面直接卡死。

## 遍历数组

```javascript
const fruits = ["苹果", "香蕉", "橘子"];

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
```

`fruits.length` 是数组长度，写成 `i < fruits.length` 而不是写死 `3`——数组改了长度，循环不用改。

## for...of：更干净的遍历

只要数组里的每个值，不需要下标：

```javascript
for (const fruit of fruits) {
  console.log(fruit);
}
```

比上面那种写法清爽得多，**遍历数组时优先用它**。

需要下标的时候再用经典的 `for`，或者：

```javascript
fruits.forEach((fruit, i) => {
  console.log(i, fruit);
});
```

## for...in：遍历对象的键

```javascript
const user = { name: "张三", age: 18, city: "上海" };

for (const key in user) {
  console.log(key, user[key]);
}
```

输出：

```text
name 张三
age 18
city 上海
```

**`for...in` 是给对象用的，不是给数组用的。**

用 `for...in` 遍历数组会拿到字符串类型的下标，还可能把数组的额外属性也遍历出来，是常见错误。

| 想要什么 | 用什么 |
| --- | --- |
| 数组的每个值 | `for...of` |
| 数组的值和下标 | `forEach` 或经典 `for` |
| 对象的每个键 | `for...in`，或 `Object.keys(obj)` |

## while：条件成立就一直转

```javascript
let n = 0;

while (n < 5) {
  console.log(n);
  n++;
}
```

和 `for` 的区别只是写法：`for` 把初始值、条件、步进写在一起，适合"知道要循环几遍"；`while` 只有一个条件，适合"不知道几遍，够了就停"。

```javascript
let input = "";

while (input !== "quit") {
  input = prompt("输入内容，quit 退出");
}
```

## do...while：至少执行一次

```javascript
let n = 10;

do {
  console.log(n);
  n++;
} while (n < 5);
```

条件一开始就不成立（`10 < 5` 是假），但循环体还是执行了一次，输出 `10`。

**它是"先做再判断"**，`while` 是"先判断再做"。用到的场合很少。

## break 和 continue

```javascript
// break：立刻跳出整个循环
for (let i = 0; i < 10; i++) {
  if (i === 3) break;
  console.log(i);   // 输出 0 1 2
}

// continue：跳过这一轮，继续下一轮
for (let i = 0; i < 5; i++) {
  if (i === 2) continue;
  console.log(i);   // 输出 0 1 3 4
}
```

一句话记住：**`break` 是不干了，`continue` 是这次不算。**

用 `continue` 过滤数据很常见：

```javascript
for (const item of list) {
  if (!item.active) continue;   // 跳过不活跃的
  process(item);
}
```

这比在里面套一层 `if (item.active) { ... }` 少一层缩进。

## 死循环的三个常见原因

**忘了 `i++`**：

```javascript
for (let i = 0; i < 5; ) {      // 少了 i++
  console.log(i);                // 永远输出 0
}
```

**条件永远成立**：

```javascript
let n = 10;
while (n > 0) {
  console.log(n);   // 忘了 n--
}
```

**数组在循环里变长了**：

```javascript
for (let i = 0; i < arr.length; i++) {
  arr.push(arr[i]);   // 边遍历边加，永远追不上
}
```

浏览器遇到死循环会弹"页面无响应"，只能关掉标签页。所以写循环的时候，先想清楚"它靠什么停下来"。

## 循环嵌套

```javascript
for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= 3; j++) {
    console.log(`${i} × ${j} = ${i * j}`);
  }
}
```

外层走一次，内层走完一整遍，所以一共 9 次。

嵌套两层还能忍，三层以上就该抽成函数了，否则很快读不懂。

注意里面的 `break` 只跳出**当前这一层**，不会一起跳出外面那层。要跳出多层，用标签：

```javascript
outer: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) break outer;
  }
}
```

这个语法能不用就不用，一般用函数和 `return` 代替。
