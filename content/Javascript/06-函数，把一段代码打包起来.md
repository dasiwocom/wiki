# 函数，把一段代码打包起来

同一段逻辑写上三遍，就该打包成函数了。

## 定义和调用

```javascript
// 定义
function greet(name) {
  console.log(`你好，${name}`);
}

// 调用
greet("张三");   // 你好，张三
greet("李四");   // 你好，李四
```

定义的时候不执行，**调用的时候才执行**。

`name` 是参数（一个占位符），`"张三"` 是实参（真正传进去的值）。

## 返回值

```javascript
function add(a, b) {
  return a + b;
}

let sum = add(3, 5);
console.log(sum);   // 8
```

`return` 做两件事：**把结果送出去，同时立刻结束函数**。

```javascript
function check(n) {
  if (n < 0) {
    return "负数";    // 到这里就结束了，下面不执行
  }
  return "非负数";
}
```

只在 `console.log` 里打印、不 `return` 的函数，结果拿不出来，没法参与后续计算。

没有 `return` 的函数，返回值是 `undefined`：

```javascript
function log(msg) {
  console.log(msg);
}

let r = log("你好");
console.log(r);   // undefined
```

## 参数

参数可以有默认值：

```javascript
function greet(name = "陌生人") {
  return `你好，${name}`;
}

greet();          // "你好，陌生人"
greet("张三");    // "你好，张三"
```

参数多的时候，用对象传是更常见的做法：

```javascript
function createUser({ name, age, city = "未知" }) {
  return { name, age, city };
}

createUser({ name: "张三", age: 18 });
// { name: "张三", age: 18, city: "未知" }
```

好处是调用的时候能看出每个值是什么意思，参数顺序也不重要了。

## 不定数量参数

```javascript
function sum(...nums) {
  return nums.reduce((total, n) => total + n, 0);
}

sum(1, 2);
sum(1, 2, 3, 4, 5);
```

`...nums` 把传进来的所有参数收成一个数组。

## 函数表达式

函数也可以当值来用：

```javascript
const add = function (a, b) {
  return a + b;
};

add(1, 2);   // 3
```

区别：函数声明会被"提升"（写在调用之后也能用），函数表达式不会。

```javascript
sayHi();                     // 能用

function sayHi() {
  console.log("hi");
}
```

```javascript
sayHi();                     // 报错

const sayHi = function () {
  console.log("hi");
};
```

这个差别造成过无数"为什么上面能跑下面不能"的困惑。**习惯上，把函数写在调用它之前**，就不用记这条规则了。

## 箭头函数

现在最常用的写法：

```javascript
const add = (a, b) => {
  return a + b;
};
```

只有一个表达式时，可以更短——`return` 和花括号都能省：

```javascript
const add = (a, b) => a + b;
const double = n => n * 2;
const sayHi = () => console.log("hi");
```

注意最后这条：返回对象字面量的时候，要用圆括号包起来，否则 `{}` 会被当成函数体：

```javascript
const makeUser = name => ({ name });   // 对
const bad = name => { name };          // 错，返回 undefined
```

箭头函数和普通函数的区别：

| | 普通函数 | 箭头函数 |
| --- | --- | --- |
| 写法 | `function () {}` | `() => {}` |
| `this` | 调用时决定 | 跟着外面的作用域 |
| 能被 `new` 吗 | 能 | 不能 |
| 有 `arguments` 吗 | 有 | 没有 |

日常写页面逻辑，**用箭头函数就够了**。只有当函数需要自己的 `this`（比如对象的方法）时，才用普通函数。

## 回调函数

把函数当参数传给另一个函数，就叫回调：

```javascript
const nums = [1, 2, 3, 4];

nums.forEach(n => {
  console.log(n);
});

nums.filter(n => n % 2 === 0);   // [2, 4]
nums.map(n => n * 10);           // [10, 20, 30, 40]
```

这三个是最常用的数组方法（[[08-数组，以及几个好用的数组方法|第 8 篇]]里细讲）。

`setTimeout` 也吃回调：

```javascript
setTimeout(() => {
  console.log("两秒后执行");
}, 2000);
```

## 事件里全是回调

写网页的时候，函数最常见的用法就是"等某件事发生再执行"：

```javascript
button.addEventListener("click", () => {
  console.log("被点了");
});
```

这不是我主动调用 `按钮被点击`，而是**把函数交给浏览器，让它需要的时候调**。

理解这一点，JavaScript 就跨过了一个坎。

## 该不该抽成函数

判断标准：

- 同一段逻辑写了第二遍 → 抽
- 一个函数超过一屏（大概 40 行）→ 拆
- 一段代码需要一行注释才能看懂 → 抽出来给它起个名字，注释就不用了

```javascript
// 抽之前
if (user.age >= 18 && !user.banned && user.verified) { }

// 抽之后
function canVote(user) {
  return user.age >= 18 && !user.banned && user.verified;
}

if (canVote(user)) { }
```

函数名本身就是最好的注释。
