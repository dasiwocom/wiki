# 表单验证，在提交之前拦住错误

验证要在"用户提交"之前做完，别等数据发到服务器再报错——那会让用户白填一遍。

## 完整流程

```javascript
const form = document.querySelector("#login");
const nameInput = document.querySelector("#name");
const phoneInput = document.querySelector("#phone");

form.addEventListener("submit", e => {
  e.preventDefault();              // 先拦下默认提交

  const name = nameInput.value.trim();
  const phone = phoneInput.value.trim();

  if (name === "") {
    alert("请填姓名");
    nameInput.focus();
    return;                        // 有错就退出，不再往下走
  }

  if (!/^1[3-9]\d{9}$/.test(phone)) {
    alert("手机号格式不对");
    phoneInput.focus();
    return;
  }

  // 全部通过，自己处理数据
  console.log("提交", { name, phone });
});
```

四个要点，缺一不可：

1. **`e.preventDefault()`** 拦下浏览器默认的表单提交
2. **`.trim()`** 去空格，用户很容易不小心多敲一个
3. **`return` 提前退出**，不要用一堆 `else` 套起来
4. **`focus()`** 把光标送回出错的那个框

## 取值的三种写法

```javascript
// ① 单个取值
const name = document.querySelector("#name").value;

// ② 用 form 元素直接按 name 取（最省事）
// <input name="phone">
const phone = form.phone.value;

// ③ 一次取全部（FormData）
const data = new FormData(form);
const name = data.get("name");
```

第三种在处理多字段表单时最干净。

## 必填和长度

```javascript
if (name === "") return "姓名不能为空";
if (name.length < 2) return "姓名至少 2 个字";
if (message.length > 200) return "留言最多 200 字";
```

## 用正则校验格式

正则写在一对斜杠里，`.test(字符串)` 返回布尔值。

```javascript
const patterns = {
  phone: /^1[3-9]\d{9}$/,                    // 11 位手机号
  email: /^[\w.-]+@[\w-]+\.[a-zA-Z]{2,}$/,   // 邮箱
  idCard: /^\d{17}[\dXx]$/,                  // 18 位身份证
  postcode: /^\d{6}$/                         // 6 位邮编
};

patterns.phone.test("13800138000");   // true
patterns.phone.test("12345");         // false
```

几个符号的意思：

| 符号 | 意思 |
| --- | --- |
| `^` `$` | 开头、结尾 |
| `\d` | 一个数字 |
| `[3-9]` | 3 到 9 中的任意一个 |
| `{9}` | 恰好 9 次 |
| `{2,}` | 至少 2 次 |
| `\.` | 字面的点（不加反斜杠表示"任意字符"） |
| `\w` | 字母、数字、下划线 |

**别忘了 `^` 和 `$`**。只写 `/1[3-9]\d{9}/` 的话，`"abc13800138000xyz"` 也会通过。

正则的完整语法见 [菜鸟教程的正则表达式教程](https://www.runoob.com/regexp/regexp-tutorial.html)，或者用 [Regex101](https://regex101.com/) 在线调，左边写正则会实时告诉你每一段的含义。

## 实时提示

只在提交时报错体验一般，输入的时候就提示更好：

```javascript
phoneInput.addEventListener("input", () => {
  const ok = patterns.phone.test(phoneInput.value.trim());
  phoneInput.classList.toggle("error", !ok && phoneInput.value !== "");
});
```

`classList.toggle(类名, 条件)` —— 第二个参数为 `true` 就加上，为 `false` 就去掉。一行搞定。

条件的后半段 `&& phoneInput.value !== ""` 是为了"还没开始输入的时候不要标红"。报错要等到用户真的输了东西再报。

配合 CSS：

```css
input.error {
  border-color: #c0392b;
  background: #fdf2f2;
}
```

## 失焦时校验

`input` 是每敲一个字都触发，`blur` 是离开这个框才触发。

组合起来体验最好：输入时不打断，离开时给结论。

```javascript
phoneInput.addEventListener("blur", () => {
  if (phoneInput.value.trim() === "") return;   // 空着不算错，留给提交时检查
  if (!patterns.phone.test(phoneInput.value.trim())) {
    showError(phoneInput, "手机号格式不对");
  } else {
    clearError(phoneInput);
  }
});
```

## 两次密码是否一致

```javascript
if (pwd.value !== pwd2.value) {
  return "两次输入的密码不一样";
}
```

这种跨字段的校验，只能等两个框都填完才能做，一般放在提交时。

## 浏览器自带的那套

HTML 的属性其实已经能做一部分验证，而且不用写 JS：

```html
<input type="text" required minlength="2" maxlength="10">
<input type="email">
<input type="number" min="1" max="100" step="1">
<input type="text" pattern="^1[3-9]\d{9}$">
```

浏览器会自动拦截不合法的提交，并弹出自带的提示。

**先用自带的，盖不住的再用 JS 补。**

缺点有二：提示文字不好看、样式没法改；`pattern` 在部分浏览器上表现不一致。所以重要的字段还是自己校验一遍。

想关掉浏览器自带的校验（比如要统一用自己的提示样式）：

```html
<form novalidate>
```

## 表单验证的几条原则

**客户端验证是为了体验，服务端验证才是为了安全。**

前端的校验能被绕过（改一下 HTML 或者直接发请求就跳过了），所以后端必须再验一遍。少这一步，等于没验。

**提示要说清楚怎么改。**

"格式错误"不如"手机号应该是 11 位数字"。

**别在用户还没填完的时候就报错。**

刚点进输入框就飘红，是最让人烦躁的交互。

**给成功的反馈。**

填完正确的之后，给个绿色的对勾或者边框变绿，用户才知道这一步过了。
