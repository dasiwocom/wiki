网卡还没装驱动，识别不了网络，不要点安装驱动程序，我们直接跳过联网这一步，先进桌面，进系统之后再装网卡、显卡驱动。
## 操作步骤
1. 在这个页面，键盘按下 Shift + F10  
如果没弹出黑框，笔记本就按：Fn + Shift + F10  
2. 弹出黑色命令窗口，复制输入这一行，直接敲回车：
```
OOBE\BYPASSNRO
```
命令解释  
OOBE：Windows开箱初始化设置界面（当前装机向导）  
BYPASSNRO：Bypass Network Requirement Override，绕过联网强制校验  
OOBE\BYPASSNRO：调用系统内置脚本，写入注册表标记，重启OOBE并解锁离线安装选项，属于微软自带功能，并非破解。
3. 电脑会自动重启，重新回到这个联网界面。
4. 这时候页面多出选项：我没有 Internet 连接，点它 → 继续执行受限设置，就可以创建本地账户进入Windows桌面了。
进桌面之后要做的两件大事
5. 先装主板网卡驱动（你现在上不了网就是缺这个）
6. 再装显卡驱动  
## 小提示
• 输入命令的时候大小写无所谓，但是符号不能错。
• 重启完如果没看到“我没有Internet连接”，就重新再执行一遍命令。
