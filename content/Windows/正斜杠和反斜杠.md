## 正斜杠`/` 

Unix、Linux、网页、URL、HTML全部用**正斜杠 `/`**

```
https://www.baidu.com/img/xxx.png
```

##  反斜杠`\`

Windows资源管理器（此电脑）用 **反斜杠 `\`** 分割文件夹。 例子：

```
C:\Users\windows\Pictures
```

这是微软当年定的老传统，**只在Windows操作系统本地文件路径使用**。

历史原因：早期 Windows 3.x 只是运行在 DOS（微软早期系统）之上的图形外壳，类似 Linux 的桌面环境。DOS最初没有目录功能，并且`/`已经被用作命令参数。为了避免符号冲突，新增目录功能时，微软选择`\`作为目录分隔符。后来微软开发出独立的 NT 内核（XP、Win7、Win10/11），不再依赖 DOS，但为了兼容旧软件，保留了`\`这个历史习惯。现代 Windows 其实也支持正斜杠/写路径，只是系统默认显示反斜杠。



## 3. 重点：为什么在Markdown、HTML里面`\`特别麻烦？

在**字符串、代码、Markdown**里，`\` 叫做 **转义字符（escape character）**。 👉 它的作用不是代表一个“斜杠符号本身”，而是**用来改变后面字符的含义**。

举例子：

- `\n` 不是 `\` + `n`，代表**换行**
- `\"` 代表一个英文双引号

所以当你写：

```
![图](C:\Users\test.png)
```

解析器看到 `\U`，会尝试把 `\U`当成转义序列，**不再当成文件夹分隔符**，直接把路径搞乱，图片读取失败。

> ✅ 一句话： Windows的`\`在Markdown/HTML里**被当成转义符**，不是文件夹分隔符，所以会出错。 网页、Markdown统一改用`/`，就不会触发转义。
